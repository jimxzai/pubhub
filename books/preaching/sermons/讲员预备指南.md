# 「破碎中的荣耀」讲员预备指南

**讲道风格 · 时间控制 · 呼召技巧 · 每讲要点**

---

> *"务要传道，无论得时不得时，总要专心。"*
> *—— 提摩太后书 4:2*

## 一、讲道风格定位

本系列融合两大传统，缺一不可：

### 1. 葛培理（Billy Graham）的布道风格——外在的"肉"

葛培理一生向超过两亿人面对面传福音。他的布道会标志是什么？不是华丽的修辞，不是学术的深度，而是**简单、真诚、直击人心的福音呼召**。

本系列从葛培理借鉴的核心元素：

- **直接**：不绕弯子。每篇讲道都在前30秒抓住听众。不是"今天我们来翻到哥林多前书……"而是一个问题、一个场景、一个痛点。
- **紧迫**：每一晚都带着"今晚就是你做决定的时刻"的张力。不是"回去好好想想"，而是"现在就回应"。
- **清晰的福音呼召**：无论当晚的主题是什么——苦难、婚姻、金钱、恩赐——每一讲都必须回到十字架和福音。没有例外。
- **感性但不操控**：葛培理从不用情绪伎俩。他的感染力来自真诚，不是技巧。你可以动情，但绝不能煽情。
- **圣经权威**：葛培理最常用的一句话是"The Bible says..."（圣经说……）。在本系列中，讲员的权柄不来自个人魅力，来自经文本身。

### 2. MacArthur 的释经深度——内在的"骨"

John MacArthur 花了23年（1975-1998）讲完哥林多书信。他的特点是**逐节释经、希腊文分析、神学精准、历史背景丰富**。本系列的每一篇讲道都建立在他的释经基础上。

本系列从 MacArthur 借鉴的核心元素：

- **逐节推进**：不是随意跳跃经文，而是跟着保罗的论证逻辑走。
- **希腊文词汇分析**：每讲至少有1-2个关键希腊文词汇的解释（如 *paraklesis*、*ostrakinos*、*kaine ktisis*），帮助听众看到中文翻译背后更丰富的含义。
- **神学精准**：不说模糊的属灵话。每一个神学陈述都有经文支撑。
- **历史文化背景**：哥林多的商业文化、罗马帝国的社会阶层、犹太教与希腊哲学的冲突——这些背景让经文活过来。

### 3. 甜蜜点：Seminary Education, Coffee Shop Delivery

**MacArthur 的内容是骨架，葛培理的传递是血肉。**

每一篇讲道应该让听众感觉：他们在跟一个既深刻又温暖的朋友聊天。这个朋友读了很多书、研究了原文、了解历史——但他说话像正常人，不像教授。

实操原则：

- **不要在台上炫耀你知道希腊文**。提到 *paraklesis* 的时候，态度是"我发现了一个特别有意思的事情，跟你们分享"，不是"让我来教你们一个词"。
- **不要把 MacArthur 的注释直接念出来**。消化它，用你自己的话说出来。MacArthur 是你的备课材料，不是你的讲稿。
- **多用比喻和画面感的语言**。保罗说"瓦器里的宝贝"——你可以把它展开成一幅古代商人用破陶罐运金子的画面。让听众"看到"经文，不只是"听到"经文。
- **控制学术内容的密度**。一篇35分钟的讲道中，纯释经部分不超过12分钟。剩下的时间用来讲故事、做应用、连接当代生活。
- **语速和节奏**。释经部分可以慢一些、深一些。应用部分加快节奏、提高能量。呼召部分放慢、降低音量、留出安静的空间。

> **一句话总结**：讲台上的你，应该像一个在咖啡厅里跟好朋友分享改变了你生命的发现的人——有深度、有热情、没有距离感。

## 二、时间框架

每晚聚会建议总时长约80分钟。以下是推荐的时间结构：

```
┌──────────────────────────────────────────────────────────────┐
│                    每晚聚会时间框架                            │
├──────────┬───────────────────────────────────────────────────┤
│ 0:00-0:03│ 见证分享（3分钟）                                  │
│          │ 每讲前邀请一位职场人分享3分钟真实见证。             │
│          │ 主题对应当晚讲道内容。真实 > 完美。                │
│          │ 提前排练，严格控3分钟。                            │
├──────────┼───────────────────────────────────────────────────┤
│ 0:03-0:18│ 敬拜（15分钟）                                    │
│          │ 3-4首诗歌。从欢快到安静，逐步把人带到神面前。      │
│          │ 最后一首要柔和、预备人心进入信息。                 │
│          │ 参考《敬拜诗歌推荐》中每讲的诗歌建议。            │
├──────────┼───────────────────────────────────────────────────┤
│ 0:18-0:20│ 过渡/祷告（2分钟）                                │
│          │ 敬拜带领者做简短的过渡祷告。                       │
│          │ 不要长篇大论。一个安静、聚焦的祷告即可。           │
│          │ 讲员此时上台，安静站立，等候。                     │
├──────────┼───────────────────────────────────────────────────┤
│ 0:20-0:55│ 讲道（35分钟）                                    │
│          │ 这是核心环节。详见下方"讲道结构模板"。             │
│          │ 严格控时。超过40分钟会失去听众注意力。             │
│          │ 建议在讲台上放一个不显眼的计时器。                 │
├──────────┼───────────────────────────────────────────────────┤
│ 0:55-1:05│ 呼召 + 回应诗歌（10分钟）                         │
│          │ 讲道自然过渡到呼召（不要说"现在进入呼召环节"）。   │
│          │ 敬拜团队轻声奏乐。详见下方"呼召技巧"。            │
├──────────┼───────────────────────────────────────────────────┤
│ 1:05-1:20│ 台前祷告服事（15分钟）                            │
│          │ 为走上前来的人一对一祷告。                         │
│          │ 祷告团队提前培训。参考《祷告服事指南》。           │
│          │ 准备决志卡和跟进材料。                             │
└──────────┴───────────────────────────────────────────────────┘
                     总时长：约80分钟
```

**时间控制贴士：**

- 排练时用手机计时，确保讲道在35分钟内完成。
- 如果释经部分讲深了导致超时，**砍释经，不要砍应用和呼召**。应用和呼召是听众最需要的。
- 见证分享超时是最常见的问题。提前跟分享者排练，给他们明确的3分钟限制。必要时安排一个人在台下举牌提醒。

## 三、讲道结构模板

本系列15篇讲道遵循统一的七段式结构。以下是每一段的说明和时间分配：

### 1. 开场/破冰（3-4分钟）

**目标：在前30秒抓住听众。**

开场决定了整篇讲道的成败。如果前一分钟失去了他们，后面34分钟都在追赶。

有效的开场方式：
- **提问**："你们当中有多少人今天早上起来第一件事是看手机？"（第一讲）
- **场景描绘**："你有没有经历过这样的时刻——周日在教会笑容满面，周一在办公室跟不信的同事活法一样？"（第二讲）
- **思想实验**："假设，只是假设——耶稣没有复活。"（第六讲）
- **直入痛点**："苦难。"——一个词开场，然后安静两秒。（第八讲）

**不要做的事**：
- 不要以笑话开场（这不是脱口秀）。
- 不要以"今天我们来看哥林多前书第X章"开场（太学术了）。
- 不要以道歉开场（"我没有准备好"、"我很紧张"——这会立刻削弱你的权柄）。

### 2. 背景/经文引入（4-5分钟）

**目标：把听众带进两千年前的世界，然后拉回今天。**

这一段要做两件事：
- **设立历史和文化背景**：哥林多是什么样的城市？保罗写信的时候处于什么情况？听众（哥林多教会）面对什么挑战？
- **建立古今桥梁**：哥林多的商业竞争 = 今天的996/内卷。哥林多的名人追捧 = 今天的网红文化。让听众感到："原来两千年前的人跟我一样。"

### 3. 经文释义（10-12分钟）

**目标：MacArthur 环节——逐节释经、原文分析、神学深度。**

这是讲道的"硬核"部分。要做到：
- **逐节推进**，跟着保罗的论证逻辑走。
- **每讲至少1-2个希腊文词汇**的解释——但要自然地融入，不要变成语言课。
- **引用 MacArthur 的洞见**，但用自己的话表达。格式可以是："MacArthur 在讲解这段的时候特别指出……"
- **用比喻和画面来解释抽象的神学概念**。例如："律法就像X光片——它能照出骨折，但不能接骨头。"（第七讲）

**节奏提示**：这一段语速可以稍慢、语气可以更沉稳。你在带领听众进入经文的深处。但不要变成学术讲座——每讲到一个深入的点，就用一个比喻或一句应用把它"接地"。

### 4. 生活应用（5-6分钟）

**目标：架桥——"这对我们今天意味着什么？"**

从两千年前的经文走向今天的生活。这一段要回答一个问题：**"So what?"（那又怎样？）**

- 用"第二人称"说话："你有没有……"、"当你……的时候"。让每个人觉得你在跟他/她一个人说话。
- 给出具体的、可操作的应用。不是"我们要更爱主"，而是"这周关掉朋友圈一周，每天早上对自己说：我是神新造的人。"（第一讲）
- 这一段的能量要比释经部分更高。你在从"教导"模式切换到"劝勉"模式。

### 5. 当代应用：这一代人的挣扎（5-6分钟）

**目标：直击这一代华人青年职场人士的核心痛点。**

这是本系列最独特的部分。每一讲都有一个专栏，直接面对25-40岁华人在当代社会中的真实挣扎：

- 996/内卷/倦怠
- 身份焦虑/简历崇拜/朋友圈比较
- 面子文化/"我没事"/有毒正能量
- 婚姻压力/剩女污名/春节审讯
- 心理健康污名/信仰解构
- 色情/约炮文化/孤独

**讲这一段的关键**：
- **不要居高临下**。你不是在审判他们的生活方式，你是在说"我理解你的挣扎，而且经文对此有话说"。
- **用他们的语言**。说"内卷"、说"KPI"、说"朋友圈焦虑"——不要翻译成属灵术语。
- **勇敢地讲别的讲员不敢讲的**。心理咨询不是不属灵（第八讲）。单身不是有问题（补充第一讲）。安息不是懒惰（第八讲）。

### 6. 福音连接（3-4分钟）

**目标：无论当晚主题是什么，都回到十字架。**

这是葛培理的核心原则：**每一次站在讲台上，都是一次传福音的机会。**

即使是讲给基督徒听的"成圣"主题（如第五讲关于爱），也要把福音讲清楚——因为你不知道在座有没有人还没有真正信主。

福音连接的方式：
- 第一讲：基督是你的智慧、公义、圣洁、救赎——你一辈子追求的，在祂里面一次性给你了。
- 第六讲：如果基督没有复活，一切都完了——但祂复活了，所以一切都成了。
- 第八讲：那位要求你信靠的神，自己的手上有钉痕——祂比你更懂苦难。
- 第十讲：你不只是被拯救的人，你是被差遣的人——带着福音进入世界。

### 7. 呼召（3-5分钟）

**目标：清晰、具体地邀请回应。**

详见下方"呼召技巧"。这是每晚的最高点。不要匆忙，不要跳过，不要因为超时而压缩呼召。**如果你只有时间做一件事，做呼召。**

## 四、呼召技巧（葛培理模式）

呼召是本系列每一晚的高潮。以下是基于葛培理布道会方法论的实操指南：

### 1. 过渡要自然

不要说"现在我们进入呼召环节"。呼召应该从讲道的最后一段自然流出。讲道的结尾就是呼召的开始——它们之间没有分割线。

### 2. 要具体

葛培理从不说模糊的"让我们来回应神"。他总是说清楚他要你做什么：

> "如果你今晚愿意把你的人生方向盘交给耶稣基督，我要请你做一件事——我要请你从你的座位上站起来，走到台前来。"

具体的邀请包括：
- 站起来
- 举手
- 走到台前
- 在心里做一个决定并默祷

**本系列建议**：前几讲可以先用"低门槛"的回应（闭眼举手、默祷），随着系列推进，在第六讲（复活）和第十讲（总结呼召）时使用"高门槛"的回应（走到台前）。

### 3. 绝不操控

这是最重要的原则。**你不是推销员，你是信使。**

- **不用情绪施压**："如果你不回应，你今晚出去可能就再也没有机会了"——这是恐吓，不是呼召。
- **不用社会压力**："看看你旁边的人都站起来了"——这是从众心理操控。
- **不用内疚**："耶稣为你死了，你连站起来都不愿意吗？"——这是道德绑架。
- **要做的是**：清楚地陈述福音，清楚地发出邀请，然后把结果交给圣灵。

### 4. 音乐配合

呼召开始时，敬拜团队轻声演奏。不要唱歌词（歌词会分散注意力），只弹旋律或和弦。

建议诗歌：
- 《照我本相》（Just As I Am）——葛培理布道会的标志性回应诗歌
- 《我需要你》
- 《奇异恩典》（Amazing Grace）

音量要低到讲员不用麦克风放大就能盖过音乐。音乐是背景，不是主角。

### 5. 等待——不要催

这是最违反直觉但最重要的技巧。

发出邀请之后，**安静等待60-90秒**。不要说话。不要填补沉默。圣灵在沉默中工作。

对讲员来说，这90秒会感觉像9分钟。但对正在内心争战的听众来说，这90秒是他们做出人生最重要决定所需要的空间。

**不要怕冷场。冷场是圣灵的工作时间。**

### 6. 重复邀请

葛培理总是把邀请发出2-3次。第一次之后等待，然后说：

> "如果你还没有回应，但你心里知道你需要做这个决定——门还是开的。现在就来。不要让今晚过去了而什么都没有改变。"

第三次：

> "我最后再说一次。如果你今晚要做这个决定，现在就是时候。不要等明天——明天有明天的顾虑。今晚，就是今晚。"

### 7. 带领决志祷告

为那些回应的人带领一个简短、清晰的决志祷告。要点：

- 用简单的语言，不用神学术语。
- 逐句带领，让他们跟着你说。
- 内容包括：承认自己的罪、相信耶稣为你死并复活、邀请耶稣做你的主。

示例：

> *"主耶稣，我承认我是一个罪人。我承认我靠自己没有办法救自己。我相信你在十字架上为我的罪死了，我相信你第三天从死里复活了。今晚，我愿意把我的生命交给你。请你做我的救主、做我的主。我奉耶稣的名祷告，阿们。"*

### 8. 后续跟进

决志不是终点，是起点。

- 为每位决志者准备**决志卡**（姓名、联系方式、今晚的决定）。
- 安排**跟进团队**在一周内联系每位决志者。
- 引导他们进入**四周基要真理课程**（参考《决志跟进-四周课程》）。
- 连接到**小组/团契**。

## 五、每讲要点提醒（讲员速查卡）

以下是15讲的"讲台速查卡"。建议打印出来，每晚放在讲台上备用。

---

### 第1讲：成功之后的空虚（林前1:18-31）

- **核心一句话**：十字架把所有人拉到同一个起点——你的简历在神面前归零，但基督成为你一切的一切。
- **必讲要点**：(1) 十字架的"愚拙"是神故意的设计，不是意外 (2) *exoutheneo*——神专门拣选世界看不上的人 (3) 基督=智慧+公义+圣洁+救赎，四重满足
- **情感高点**：那个站在高楼顶上俯瞰城市、眼眶湿了、心里问"然后呢"的年轻人
- **呼召角度**：如果你已经爬得够高也够累了，耶稣从天上下来就是为了回答你的"然后呢"

---

### 第2讲：别再演了（林前3:1-23）

- **核心一句话**：恩赐不等于成熟——你在教会里的那个"我"和平时的那个"我"，到底哪个是真的？
- **必讲要点**：(1) *sarkinos* vs *pneumatikos*——属肉体 vs 属灵，关键看有没有嫉妒纷争 (2) 根基只有一个就是基督，草木禾秸 vs 金银宝石 (3) 停止追捧名人牧师，跟随基督
- **情感高点**：深夜一个人的时候，你发现教会里的自己和平时的自己是两个人——那个落差感
- **呼召角度**：今晚不需要你再演了，带着你真实的样子来到基督面前

---

### 第3讲：你的身体不是你的（林前6:9-20）

- **核心一句话**：真正的自由不是"想做什么就做什么"，而是"终于可以不做那些一直捆绑你的事"。
- **必讲要点**：(1) "不要自欺"——恩典不是犯罪的许可证 (2) "从前你们中间也有人是这样"——过去不定义你 (3) 身体是圣灵的殿，是重价买来的
- **情感高点**："从前你们中间也有人是这样；但如今你们……已经洗净、成圣、称义了"——过去可以被翻篇
- **呼召角度**：无论你过去做了什么，"但如今"三个字是神给你的转折——你愿意让祂重新定义你吗？

---

### 第4讲：扛不住的时候（林前10:1-13）

- **核心一句话**：你遇到的试探不是独一无二的，而那位信实的神必为你开一条出路。
- **必讲要点**：(1) 以色列人"都"经历了神迹却"多半"倒毙——属灵特权不等于属灵免疫 (2) *pistos*——神是信实的，这是应许不是建议 (3) 出路不是"没有试探"，而是"在试探中能忍受得住"
- **情感高点**：那个深夜独自出差、在酒店房间里面对试探、快要扛不住的时刻
- **呼召角度**：如果你现在正被一个试探死死缠住，今晚把它交出来——神已经为你预备了出路

---

### 第5讲：爱不是鸡汤（林前12-13）

- **核心一句话**：林前13章不是婚礼朗诵——它是写给一群互相撕的基督徒的，没有爱，你做的一切都是零。
- **必讲要点**：(1) 身体比喻——没有一个肢体可以说"我不需要你" (2) 爱的三层结构：卓越性、品质、永恒性 (3) *agape* 不是感觉，是意志的决定——在对方不可爱的时候选择爱
- **情感高点**："爱是……不求自己的益处"——在一个人人都在争的文化里，这句话像一记重锤
- **呼召角度**：你是否愿意放下比较和争竞，在基督的身体中活出那种"不求自己益处"的爱？

---

### 第6讲：如果坟墓是终点（林前15）

- **核心一句话**：如果基督没有复活，我们就是全世界最可怜的人——但祂复活了，所以一切都改变了。
- **必讲要点**：(1) 福音的四个核心事实：死了、埋葬了、复活了、显现了 (2) 五百多人同时看见——不是幻觉 (3) 复活身体的本质：朽坏→不朽坏、软弱→强壮、天然→灵性
- **情感高点**："死啊，你得胜的权势在哪里？"——对死亡的终极宣告，如果有听众正面对失去亲人的痛苦，这里是释放的时刻
- **呼召角度**：你今晚要回答一个问题——你相不相信那个坟墓是空的？如果你信，一切都不一样了。**这一讲建议使用"走到台前"的呼召方式。**

---

### 第7讲：旧的你可以真的过去（林后3+5）

- **核心一句话**：福音不是在旧衣服上洗污渍，是扔掉旧衣服、穿上全新的——你是新造的人，旧事已过，都变成新的了。
- **必讲要点**：(1) MacArthur 的七重新旧约对比——新约在每个维度上超越旧约 (2) 林后5:17 *kaine ktisis*——不是修补，是全新创造 (3) 林后5:21——十五个字的盼望，双重归算
- **情感高点**：那个洗不掉污渍的比喻——你花了多少年试图"改好"自己却发现旧痕迹还在？福音说：不用洗了，全新的。
- **呼召角度**：你不需要再修补旧的自己了。今晚，接受那个全新的身份——新造的人。

---

### 第8讲：苦难不是意外（林后1+4）

- **核心一句话**：苦难不是神走开了的证据，而是神要透过你的破碎祝福别人的管道。
- **必讲要点**：(1) 安慰的循环：受苦→被安慰→安慰别人 (2) *paraklesis* 不是温暖的毛毯，是一副战甲 (3) 瓦器里的宝贝——脆弱是设计，不是缺陷
- **情感高点**：保罗在亚细亚"连活命的指望都绝了"——如果使徒保罗都有崩溃的时刻，你也可以承认自己快撑不下去了
- **呼召角度**：如果你今晚带着很重的担子来，你不需要假装坚强——让那位"赐各样安慰的神"来托住你

---

### 第9讲：软弱是我的简历（林后12:1-10）

- **核心一句话**：真正的力量不是从强壮来的，是从软弱来的——"我的恩典够你用的，我的能力在人的软弱上显得完全。"
- **必讲要点**：(1) 保罗被提到三层天却选择不炫耀——与今天"属灵网红"文化的对比 (2) 那根刺——求了三次神没有拿走，但给了更好的：够用的恩典 (3) *dunamis en astheneia*——能力在软弱中完全
- **情感高点**："我的恩典够你用的"——神对保罗说的这句话，也是今晚对每一个正在挣扎的人说的
- **呼召角度**：你一直在藏的那个软弱——今晚可以放下了。不是你变强了，是祂的恩典够用了。

---

### 第10讲：基督的大使（总结呼召）

- **核心一句话**：你不只是被拯救的人，你是被差遣的人——带着新身份、新使命，作基督的大使进入世界。
- **必讲要点**：(1) 三个身份宣告——新造的人、和好的使者、基督的大使 (2) *presbeuo*——大使的职分，你在哪里就代表基督在哪里 (3) 凡事荣耀神（林前10:31）——不是圣俗二分，而是全人全时间的使命
- **情感高点**：回顾十个晚上的旅程——从第一讲的空虚到第十讲的使命，每一步都是神在预备你
- **呼召角度**：这是整个系列最大的呼召——不只是"信主"，而是"被差遣"。你愿不愿意带着这十个晚上领受的一切，走出去，成为基督的大使？**这一讲使用最隆重的呼召形式：走到台前、跪下、被差遣。**

---

### 补充第1讲：一个人也可以很好（林前7）

- **核心一句话**：单身不是有问题，婚姻不是终极目标——无论哪种状态，关键是"殷勤服事主"。
- **必讲要点**：(1) 保罗说单身是 *charisma*（恩赐），不是缺陷 (2) 婚姻是好的，但不是偶像——华人文化把婚姻放得太高了 (3) 无论婚否，你的身份在基督里，不在婚姻状况里
- **情感高点**：过年回家被亲戚催婚的场景——直击每一个单身华人基督徒的痛处
- **呼召角度**：今晚把你对婚姻（或单身）的焦虑交给神——祂给你的状态就是最好的状态

---

### 补充第2讲：为福音我什么都愿意放下（林前9）

- **核心一句话**：真正的自由不是抓住你有权拥有的一切，而是为了福音甘心放下。
- **必讲要点**：(1) 保罗的权利清单——他有权拿工资、有权结婚，但他都放弃了 (2) *adokimos*——保罗怕自己被淘汰，属灵自律不是可选的 (3) "向什么人就作什么人"——灵活不是妥协
- **情感高点**：保罗说"恐怕我传福音给别人，自己反被弃绝了"——连保罗都有这种紧迫感
- **呼召角度**：有什么"合法的权利"是神在呼召你为福音放下的？你愿意吗？

---

### 补充第3讲：规矩不是束缚（林前14）

- **核心一句话**：圣灵是秩序的神，真正的自由在规矩之内才能绽放。
- **必讲要点**：(1) 先知讲道优于说方言——造就教会的恩赐优先于造就个人的 (2) "神不是叫人混乱，乃是叫人安静"——秩序不是压制圣灵 (3) 数字时代的应用：注意力涣散时代，更需要操练专注敬拜
- **情感高点**：在混乱和嘈杂中渴望安静和秩序——很多年轻人被"属灵嘉年华"搞得疲惫
- **呼召角度**：你愿不愿意放下对"属灵体验"的追求，转而追求在安静中遇见那位秩序的神？

---

### 补充第4讲：慷慨不是被迫的（林后8-9）

- **核心一句话**：慷慨的驱动力不是律法的命令，而是恩典的回应——"祂本来富足，却为你们成了贫穷。"
- **必讲要点**：(1) 马其顿教会在"深渊般的贫穷"中涌出慷慨——这是恩典掌管人心的样子 (2) 林后8:9——基督成为贫穷的神学根基 (3) *hilaros*（甘心乐意的）——神爱的不是勉强给的人
- **情感高点**：马其顿教会"再三求我们准他们有份"——穷到底还在恳求奉献的机会，完全颠覆我们对"给"的理解
- **呼召角度**：今晚不是要你的钱——是要你的心。你的钱跟着你的心走。你的心在哪里？

---

### 补充第5讲：分辨真假（林后11）

- **核心一句话**：假教师不会穿着写着"我是假教师"的T恤来——他们传的是"另一个耶稣、另一个灵、另一个福音"。
- **必讲要点**：(1) "另一个耶稣"——不是否定耶稣，而是重新定义耶稣 (2) 撒但装作光明天使（11:14）——假教导总是"看起来很属灵" (3) 真使徒以伤疤为凭据，假使徒以成功为包装
- **情感高点**：保罗的"愚妄人的自夸"——列出他的苦难清单，跟假使徒的光鲜对比，震撼人心
- **呼召角度**：你跟随的是真正的基督，还是一个被包装过的"另一个耶稣"？今晚回到那个被钉十字架、带着钉痕的真耶稣面前。

## 六、讲员灵性预备

讲道不只是技术，更是属灵争战。以下是讲员个人灵性预备的建议：

### 1. 禁食祷告

在系列开始前，建议至少有一天的禁食祷告。不是因为禁食能"赚取"神的恩膏，而是因为禁食帮助你把心完全对准神。系列期间，每次讲道前当天建议简食（不必完全禁食），保持灵里的敏锐。

### 2. 让讲章先讲你

**不要只研读讲章——让讲章研读你。**

在准备每一讲的时候，问自己：
- 这段经文在挑战我自己的什么？
- 我自己是否活出了我要讲的？
- 如果我是台下的听众，这篇讲道会改变我什么？

如果一篇讲道没有先改变讲员自己，它不太可能改变听众。

### 3. 对付未认的罪

讲台是一个极其暴露的地方。未对付的罪会削弱你的权柄——不是因为神"惩罚"你，而是因为你的良心不清洁会让你在呼召的时候底气不足。

每次讲道前，安静在神面前，求圣灵光照。如果有需要认的罪，认了。如果有需要修复的关系，去修复。清洁的器皿才能盛装神的话语。

### 4. 提前到场，为场地祷告

讲道前至少提前30分钟到场。走遍会场的每一个角落，为每一个将要坐在那里的人祷告。不需要大声，安静地走、安静地祷告就好。

祷告的内容：
- 求神预备每一个听众的心
- 捆绑一切拦阻人听见福音的属灵势力
- 求圣灵充满这个空间
- 把你自己完全交在神手中

### 5. 记住你的身份

你是一个**信使**，不是信息本身。

你的口才不能救人。你的学识不能救人。你的感染力不能救人。**只有福音能救人。** 你的工作是把信息忠实地传递出去，然后交给圣灵。

如果某一晚讲得很好、很多人回应——荣耀归神，不归你。
如果某一晚讲得不理想、没什么人回应——责任也不在你，在神的主权里。

**你负责忠心，神负责果效。**

> *"我栽种了，亚波罗浇灌了，惟有神叫他生长。可见栽种的算不得什么，浇灌的也算不得什么，只在那叫他生长的神。"*
> *—— 哥林多前书 3:6-7*
