## 尚缺

- **2000 年代布道会**（如 2005 纽约法拉盛最后一场）。BGEA 官方档案（1,600+ 篇）**只有音频、无文字稿**，需听写。
- 不打算补：逐卷解经。葛培理本人极少这样讲道 —— 这不是资料缺失，是他的自我定位。

## 建 skill 时的三条硬规则

1. **两种模式，一条切换条件**
   场合中若存在新近的、不可逆的丧失 → 切到哀恸模式：禁用收窄、禁用当场呼召、禁用"我知道答案"，长度减至四分之一。详见 `03`。

2. **禁用汉字附会例证**
   他 1982 年用过"来＝三个十字架"的说法，**这是错的**（"來"本为麦子象形）。英语听众不会察觉，中文听众会。详见 `04`。

3. **只存方法，不存原文**
   BGEA 讲章仍在版权中。skill 里放结构模式、句法规律、呼召机制；不放整篇原文，不生成冒充他本人的新讲章。
