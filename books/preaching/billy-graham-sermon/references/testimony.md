# 生命的见证
## Testimony — 三口可用的井

---

## 一、先说清楚这一节要补的是什么洞

skill 里禁掉了"总统跟我私下说……"这一类引用。

但**那个动作本身是有作用的**——葛培理用它做了两件事：证明"担心这件事的不只我一个"，以及让抽象的论点落在一个**活人**身上。

禁掉之后，那两件事仍然必须有人做。**做这件事的正当方式是见证。**

三口井，都合法，都好用：

```
① 你自己的生命
② 圣经里的人
③ 宣教士与教会历史
＋ 会众中的活见证（最有力，也最需要谨慎）
```

葛培理本人四口井全用。他不是靠名人轶事撑住讲台的——**他最有力的那些段落，几乎都是见证。**

---

## 二、井一｜你自己

### 反常识的那条定律

**见证的说服力，与它的体面程度成反比。**

这不是谦虚的修辞，是他实际的做法。1982 年，六十四岁、已经向几千万人讲过道的他，在讲台上描述自己决志的那一晚：

站在三四百人中间，**觉得自己像个傻瓜**，想转身走回去。旁边的女人在流泪，他一滴眼泪也没有，没有任何感动，**只有害怕**——怕站在那么多人面前。回到农场，月光下望着田野，知道有事发生了。但**如果第二天你问他发生了什么，他答不上来。**

然后他说：那第一步何等软弱，信心何等微小，疑问那么多。

**没有一个字是在自我推销。这就是它有效的原因。**

1955 年在多伦多商会，他对一屋子菁英说的是：我第一次听见这套说法的时候，**我笑了**，我说这不可能。

**先承认自己曾经站在听众那一边**，这是对怀疑者最短的一座桥。

### 规则

| ✅ 可以讲 | ❌ 不要讲 |
|---|---|
| 你软弱的时候 | 你属灵高峰的时候 |
| 你不懂、答不上来的时候 | 你如何战胜了什么 |
| 你曾经也不信、也嘲笑过 | 你一直很坚定 |
| 具体的一个下午、一句话、一个房间 | "神在我生命中做了奇妙的事"这类概括 |
| 还没解决的事（诚实说没解决） | 把还在挣扎的事讲成已经得胜 |

**位置**：论证之后，不是之前。30–60 秒。语气要低。

葛培理 1955 年那篇把见证放在整套智性论证之后——**先建立合理性，再放个人经历**。反过来做，怀疑的听众会在你还没开口论证时就归类为"又一个宗教热心分子"。

### 一句要背下来的句式

> "我不能解释它。我不能分析它。我不能把它放进试管里。
> 但我可以举例说明它。"

承认无法证明，然后给可看见的证据。**这比宣称你能证明更有力。**

## 三、井二｜圣经里的人

### 他怎么用

青年讲道里，约瑟的故事是**全篇唯一的长叙事**，而且放在中段——不在开头，不在结尾。

他讲得极慢、极具体：被父亲偏爱、哥哥嫉妒、本要杀他、改丢进坑、卖给商队、到埃及、进波提乏家、日复一日被纠缠、最后丢下外衣逃走、被诬告、下监。

然后一句落地：**约瑟说了不。** 接着：历史被改变，因为一个年轻人说了不。

### 规则

**一、讲完整的弧线，不要停在得胜那一格。**
约瑟说了不之后**进了监狱**。他没有跳过这一段。如果你只讲"顺服就蒙福"，听众里正在受苦的人会知道你在骗他。

**二、不要美化。**
圣经人物的失败是圣经自己写下来的。删掉大卫的罪、彼得的否认、约拿的怨恨，你会得到一个没人能认同的塑像。

**三、用现代动机解释古人。**
这是他一个很聪明的动作。讲约拿不肯去尼尼微，他说的不是神学理由，而是：**那差事没有光彩，会被逼迫，不会受欢迎**——约拿心想我可以去他施海边躺着，主也不知道我在哪。

一个三千年前的人，忽然变成一个想请假的现代人。

**四、一篇道一个长叙事，放中段。**

## 四、井三｜宣教士与教会历史

这是华人讲台最丰富、也最容易出错的一口井。

### 为什么值得用

一个宣教士的一生，是**一个完整的论证**：他相信的东西，让他付出了可核实的代价。这比任何名人背书都重。

而且这口井有一个别的井没有的好处：**它把听众接到一个比他们大的故事里去。**

### ⚠️ 但这口井被污染得很厉害

流传最广的宣教士故事，往往是被加过料的。经过几手转述之后，数字会变大，巧合会变成神迹，模糊的记载会变成确凿的对白。

**一个可以直接讲给听众听的教训**：艾伟德（Gladys Aylward）的故事被拍成电影后严重失真，而她本人对那个版本感到痛苦——她不认那是她的故事。

**用一个被美化的宣教士故事去讲真理，本身就是矛盾的。**

### 核查规则

**只用有一手材料的人。** 优先次序：

1. **他自己写的**——日记、书信、自传
2. **同时代人的记录**
3. ❌ 讲道集里辗转引用的版本（这是失真的主要来源）

**有一手材料可查的例子**（都留下了自己的文字）：

| | |
|---|---|
| 戴德生 Hudson Taylor | 自述与书信 |
| 宋尚节 | 日记 |
| 王明道 | 自述 |
| 艾米・迦密 Amy Carmichael | 大量自著 |
| 吉姆・艾略特 Jim Elliot | 日记（其妻整理出版） |
| 约翰・帕顿 John Paton | 自传 |
| 李文斯顿 David Livingstone | 日记 |
| 慕拉第 Lottie Moon | 书信 |

**三条硬规矩：**

1. **数字要么查证，要么不说。** "带领了几万人信主"这类数字最容易被放大。说不出处就整句删掉。
2. **看完整的一生，不要只取高光。** 有些人物晚年有争议，有些人的事工有复杂的历史背景。**若你只讲高光而听众知道后面的事，你损失的是自己的可信度。** 拿不准就换一个人。
3. **不确定就说不确定。** "我读到的版本是这样，细节我没能完全核实"——这句话不会削弱你，反而增强你。

### 中文讲台的额外提醒

华人教会的宣教士叙事常带殖民时代的复杂背景。讲的时候诚实一点——**承认历史的复杂，不会削弱见证；掩盖它才会。** 而且座位上很可能有比你更了解那段历史的人。

## 五、第四口井｜会众中的活见证

**最有力的一口，因为听众认识那个人。**

也是最需要谨慎的一口，因为你在用别人的人生。

### 同意规则

- **必须事先取得当事人明确同意**，而且要说清楚你打算怎么讲
- **讲完之后再确认一次**——他听到实际效果之后，可能想收回
- 会被认出的细节（职业、住哪、家里几个孩子）**要么获准，要么改掉**
- 涉及**未成年人**：要父母同意，而且孩子自己也要愿意
- **正在进行中的危机不要讲**——离婚未定、病未确诊、案子未结。等它过去
- 涉及**第三方**（配偶、父母、前任）的故事，你没有他们的同意，就不能讲

### 讲法

- 讲**具体的**，不讲**概括的**
- 不要把它讲成范例（"你看，只要祷告就……"）——把它讲成一个人身上发生的事
- **不要保证同样的结果。** 有人祷告了，病没好。座位上就坐着那个人。

---

## 六、四口井怎么配

一篇道不要四口井全用。**通常两口，最多三口。**

一个稳的搭配：

```
圣经人物（中段长叙事）
    ↓
宣教士或教会历史（一句到三句，作为跨越时空的印证）
    ↓
你自己（30–60 秒，论证之后，语气要低）
```

**顺序的道理**：先远后近。圣经最远，历史其次，你自己最近。**离听众越近的，放越后面**——因为最后那一下要落在"这个站在台上的人也是这样"。

## 七、自检

- [ ] 我的见证是"我软弱的时候"还是"我得胜的时候"？后者要重写。
- [ ] 我的见证在论证之后，还是之前？
- [ ] 圣经人物的失败与代价，我有没有删掉？
- [ ] 宣教士的资料，我找得到一手来源吗？找不到就换人或删掉。
- [ ] 我说的数字，我能说出出处吗？
- [ ] 会众的故事，我拿到同意了吗？讲完还要再确认一次。
- [ ] 我有没有暗示"照做就会有同样结果"？
- [ ] 最后一句话：**如果这个见证里的人今天坐在台下，他会觉得被尊重，还是被使用？**
