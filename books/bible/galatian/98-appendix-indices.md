## 附錄二：主題索引 (Key Themes Index)

| 主題 | 簡述 | 主要章節 |
|----------------------|----------------------|------------------------------------|
| 只有一個福音 | 加添任何條件（割禮、律法的行為）在信心以外，就不再是福音 | 01、02 |
| 福音啟示的來源 | 保羅所傳的福音直接從耶穌基督啟示而來，不是從人領受、也不是人教導的 | 01、02 |
| 因信稱義，不因行律法 | 全書立場句（2:16）——人稱義的根據是信基督，不是行律法 | 02、03、04、07 |
| 與基督同釘十字架 | 「現在活著的不再是我，乃是基督在我裏面活著」——稱義帶來身分的置換 | 02、08 |
| 應許先於律法 | 神與亞伯拉罕所立的應許之約，早於西奈山的律法之約四百三十年，律法不能廢棄應許 | 04 |
| 律法是訓蒙的師傅 | 律法的功用是暫時的看守與引導，等候那蒙應許的子孫（基督）來到，任務完成即退下 | 03、04 |
| 亞伯拉罕的福臨到外邦人 | 因信而非因血統，外邦人也成為亞伯拉罕屬靈的子孫，一同得福 | 03、04 |
| 時候滿足 | 神按自己所定的時候差遣兒子，成就從應許到律法漫長等候的終點 | 05 |
| 兒子的名分與阿爸父 | 從奴僕變成兒子；聖靈使人能親密呼叫神為父 | 05 |
| 夏甲與撒拉的寓意 | 兩約、兩座耶路撒冷的對比：血氣所生為奴，應許所生自主 | 06 |
| 基督裏的自由 | 基督釋放人脫離律法的軛，這自由不是放縱，是靠愛心彼此服事 | 07 |
| 聖靈與肉體相爭 | 兩種原則彼此相敵，順著聖靈而行才不放縱肉體的情慾 | 07 |
| 聖靈的果子 | 仁愛、喜樂、和平等九樣德行，是聖靈內住生命自然結出的果子，非律法所能禁止 | 07 |
| 彼此擔當與各人的擔子 | 屬靈群體既要溫柔挽回跌倒的肢體，也要各人為自己的行為負責 | 08 |
| 撒種與收成 | 順著情慾撒種收敗壞，順著聖靈撒種收永生——屬靈定律不可自欺 | 08 |
| 只誇基督的十字架 | 保羅拒絕在割禮或任何外在憑證上誇口，只以主耶穌基督的十字架為誇口的根據 | 02、08 |
| 新造的人 | 受割禮或不受割禮都無關緊要，要緊的是在基督裏成為新造的人 | 08 |
| 耶穌的印記 | 保羅身上因傳福音所受的傷痕，是他所屬何人的記號，與割禮的記號相對 | 08 |
| 加拉太書與羅馬書 | 同一場因信稱義的辯詞，一急一緩，一重人的一面一重神的一面 | 卷首、02、04 |
