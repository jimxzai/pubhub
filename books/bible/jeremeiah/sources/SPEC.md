# 耶利米書研讀 — 章節撰寫規格（給每位撰寫者；2026-10-26）

先讀：`sources/PLAN.md`（骨幹、卷次、章檔名）、本檔、範例章 `01-before-i-formed-you.md`（**完整讀一遍，照它的體例**）。
體例＝約翰福音 11 節章節模板（`.claude/skills/eat-bible/references/chapter-template.md`）。你只寫**分到的章**，不改其他檔、不改範例章、不 commit。

## 一、檔案骨架（11 個 `## `，順序固定，與範例章逐項同構）

YAML 七行（與範例章逐字相同）→ `# 章題 (English Title)` → 參照行（`耶利米書 a:b-c:d`）→ `**經文核對**：[ai-eden.com/bible/jeremiah/N](…)`（跨章用第一章的連結）→
`## 基督焦點` · `## 配詩 (Opening Hymn)` · `@@SCRIPTURE a:b-c:d@@`（單獨一行，代表 `## 經文`）· `## 背景` · `## 原文研讀` · `## 領受要點` · `## 歷代注疏` · `## 詩篇與聖詩` · `## 老弟兄查經` · `## 生命應用` · `## 與其他經文的關聯` · 結尾斜體一行。
**H1 不加真實章節範圍**（真實範圍只在參照行與座標行）。範例章含 `---` 分隔；`---` 前後必須有空行（否則被 pandoc 吞成 Setext 標題）。

`@@SCRIPTURE a:b-c:d@@` 由 `python3 books/bible/jeremeiah/sources/scripture/inject_scripture.py <章檔>` 展開成 CUV＋NASB 1995 經文區塊——**你不手打任何經文區塊**；寫完章檔後自己跑一次，確認展開成功（章檔會被改寫，這是預期）。範圍跨章寫 `2:1-3:5`。
**8:23 陷阱**：Sefaria 希伯來文（`sources/hebrew/jer-N.json`）採希伯來節號，**耶 8 有 23 節、耶 9 有 25 節**（希伯來 8:23＝中文 9:1；希伯來 9:n＝中文 9:(n+1)）。凡引耶 8–9 的希伯來文必須換算，正文一律用和合本節號。

## 二、基督焦點（必備）

`> **本章鑰詞：<原文> 「中譯」（出處）** \` + `> **全書座標**：啟示的次序·第 N 步——…`（見下表）＋一至二段 hook。座標句要說出**這章在全書骨幹上的位置與作用**，不可只複述章節大意；不可與別章的座標句雷同。

啟示的次序（全書五步，定案，用詞照抄）：
1. 話先於人（耶1）
2. 先呼喚、後審判（耶2–6）
3. 代求被關上，眼淚沒有關（耶7–20）
4. 審判藉巴比倫，盼望種在審判裏（耶21–33）
5. 話語勝過刀與火；審判者亦受審；燈未熄滅（耶34–52）

貫穿全書的兩條線（每章用得上就點出，不要硬塞）：**שׁקד「留意」**（1:12 → 31:28 → 44:27，神守著自己的話，拔出與栽植用同一個動詞）；**「主耶和華啊」的四次呼喊**（1:6 推辭、4:10 控告、14:13 訴苦、32:17 圍城中的信心）。

## 三、不可越過的線（違反即退件）

1. **經文**：正文中任何「」＋（出處）的經文引句，必須逐字出自 `sources/scripture/cuv.tsv`（耶利米書）或用 `python3 -c "import sys;sys.path.insert(0,'books/bible/jeremeiah/sources/scripture');import cuv_lookup as c;..."` 查他書（和合本，FHL）。**引句裏不可插括號譯注**（範例章曾因 `「我已派（給）你…」` 被抓）；要說明就把說明放在引句外。同一節的引句與出處節號必須對得上（範例章曾把出4:12 的話標成4:10）。**寫完跑**：`python3 scripts/verify-prose-citations.py books/bible/jeremeiah --self 耶`（0 MISS 才算過）。
2. **注疏引文**：只用已下載來源，**沒有可定位原文就不加引號**。可用來源（皆在 `sources/commentary/`）：亨利 `henry/jer-page-<羅馬數字>.txt`（`ii`＝耶1，`iii`＝耶2 … `liii`＝耶52；即羅馬數字＝章號+1）；加爾文 `calvin/calcom17-21.txt`（耶1-9／10-19／20-29／30-47／48-52）；摩根 `《The Message of Jeremiah》` 在 `../../nehemiah/sources/commentary/m-livingmessagesof01morgiala.txt`（約 pp.109-117，**只有全書概論，沒有逐章**；頁碼依 OCR 頁眉）；教父 `fathers/INDEX.md`（已列每條可逐字引用的句子與出處）；麥克阿瑟 `gty/INDEX.md`（若存在；找不到的章**不立該節**）。合併語料 `commentary/corpus.txt`（亨利＋加爾文＋摩根）。引文格式與範例章逐字相同：`> "English quote"` 換行 `> — 作者, *書名*, 章節 (來源)`；引文前一段中文導讀是撮述不是翻譯。**寫完跑**：`python3 scripts/verify-citations.py books/bible/jeremeiah --source books/bible/jeremeiah/sources/commentary/corpus.txt`（教父與麥克阿瑟條目另核其原檔；OK/DRIFT/MISS 都要看）。
   - 某位解經者在本章沒有可查的專論，**就不立該節**（體例說明已寫明），不補位、不改寫成像是他說的話。
   - 加爾文英譯本內有編者按語（`— Ed.`）；引文只取加爾文本人的句子。
   - 摩根《耶利米書的信息》是全書概論：只能挑**確實切題**的句子，不可每章硬引；用不上就不立摩根一節。
3. **不杜撰老弟兄的話**：倉庫沒有耶利米書的黃長老／老弟兄第一手材料。「老弟兄查經」一節只用他的**方法**（提問、全經連線、落到每日祭壇、回到耶穌），**不加引號歸給他任何話**。稱呼一律「老弟兄」，不寫「黃長老」。
4. **不編史料**：年代、人名、地名、數字，只用經文與已下載注疏支持的；推測要寫明「推測」。**全稱斷言（「全書只有」「每一次」「從不」）必須先用程式數過**（`sources/scripture/cuv.tsv`、`sources/hebrew/*.json`）。字頻若報數字，註明依據與計法（和合本中文字面？希伯來字根？）。
5. **原文研讀**：希伯來詞形一律從 `sources/hebrew/jer-N.json`（耶利米書）或 `python3 books/bible/jeremeiah/sources/heb.py <Book> <chap> [verse]`（他書）**複製**，不憑記憶打 niqqud；希伯來字在中文行文裏前後各留一個空格；表格欄寬照範例章。不確定的詞義，寫「字面是…」並指出出處（亨利／加爾文／已下載來源），不要靠記憶斷言詞源。
6. **不硬說預表**：「耶利米是基督的預表」之類，必須有經文本身的連結（如太16:14、太21:13、太2:17-18、太26:28、來8、來10:16-17、林後3:6、啟18:21）才可說；其餘只寫「本書的對照，經文沒有互相引用」。**不抹平張力**：耶利米的詛咒（20:14-18）、「不能勝你」（1:19）與淤泥坑（38:6）、7:22 的字面難解、23:5-6 的名字、31:31 的「以色列家／猶大家」、36:23 王的小刀、44 章埃及婦女的辯駁，都要讓它們保持張力。
7. **版本**：經文塊只由腳本產生；散文中的經文引句用和合本（CUV，FHL 版，字形用「裏／甚麼／那裏」），英文詞若引 NASB 1995 須與 `nasb1995.tsv` 逐字相同。
8. **不可有**：空洞屬靈套話、AI 腔、過多 emoji（不用）、「值得注意的是」這類墊字、同一點在同章講三次以上。「活在今天」不編造 AI／時事案例；寫不出真實觸點就寫具體的生活處境。

## 四、章節內容規格

- 長度：每章 18–26 KB（範例章 ≈ 22 KB，含經文區塊）；經文區塊由腳本展開所以你寫的部分約 9–13 KB。
- 背景 2–3 個 `###`；原文研讀 5–8 列（每列都能用資料核對）；領受要點 **3–4 條**，各自只屬於本章（搬到別章會不通順才算數）；
- 歷代注疏：`### 教父時期`（有可用條目才立）／`### 改革宗時期 (加爾文)`／`### 清教徒 (亨利)`／`### 摩根`／`### 麥克阿瑟`——有哪個立哪個，每節 1–3 條逐字引文；
- 詩篇與聖詩：一至二篇詩篇（逐字 CUV 引句）＋「配詩（見上）」一段說明；
- 老弟兄查經：`**精義一句話**`（一句，記得住）→ `### 全經連線`（3–5 條，每條出處對得上、引句逐字）→ `### 提問式對話`（先問／再問／追問／落到自己）→ `### 活在今天` → `### 今天的祭壇`（早晨／晚上／一個行動）→ **`**你看見耶穌了嗎**？`** 一段收尾（只用有經文連結的線）；
- 生命應用：默想問題 ≤3（角度不與提問式對話重複）＋禱告回應（奉主耶穌基督的名，阿們）；
- 與其他經文的關聯：表格 8–12 列；
- **配詩**：用 `sources/hymns/NN-*.txt`（NN＝本書章序）。把英文兩節逐字抄入（含該檔標頭給的作者與年份；年份欄寫「not stated on source page」的，出處行只寫作者名），自己寫繁體中文意譯（逐行對照），版式與範例章相同。若該檔有已知瑕疵（如 07 的 `That in , thy sun-shine's blaze`、10 的大小寫來自 1989 版本），在撰寫報告中註明，不要默默改歌詞。**配詩的「說明句」必須誠實**：不可說經文與聖詩互相引用；不可把聖詩裏沒有的意思寫進去。
- 全章不得出現：`TODO`、`@@`（除單行的 `@@SCRIPTURE …@@` 展開前）、`需verify`、`待補`。

## 五、寫作流程（避免停滯）

1. 讀範例章與本檔；讀你章節範圍的 `cuv.tsv` 行、`hebrew/jer-N.json`、亨利／加爾文相關段落、`fathers/INDEX.md` 與 `gty/INDEX.md` 對應列。
2. **分段寫入**：先 Write 骨架前半（到「領受要點」），再 Edit／append 後半。**不要一次寫整檔**。
3. 跑：`inject_scripture.py`、`verify-prose-citations.py … --self 耶`、`verify-citations.py …`、`python3 scripts/lint-chapter-markup.py <章檔>`、`python3 scripts/check-prose-scripture-quotes.py <章檔>`。全部乾淨才回報。
4. 回報（≤300 字）：檔名、大小、11 節核對、各檢查結果、**你不確定／可能有誤的地方清單**（尤其詞義、字頻、史實、歸屬）。誠實：做不到的標明，不要含糊帶過。

## 七、已知不可踩的坑（來自全庫歷史）

- 範例章的檢查器曾抓出：引句內插括號、節號標錯、引文歸屬錯置——這是**人眼讀不出、檢查器才抓得到**的錯，所以一定要跑腳本。
- 注疏引文最常見的三類錯：查無此句／立場說反／推論相左（馬可卷112條抽查）。不確定就不加引號。
- 配詩說明、書卷結語最容易「說得比來源多」。
- 同章同一個點只講一次；默想問題不要與「提問式對話」重複。
- 專有名詞：和合本譯名（如 尼布甲尼撒、約雅敬、西底家、約雅斤、基大利、以實瑪利、巴錄、尼利亞）一律照 `cuv.tsv`，不用現代譯名。
