# 燈與真光 (The Lamp, and the True Light)

> 列王紀上的最後一章，以一個壞王的登基收尾（22:51-53）。這本書沒有給出結局，只給了一盞還點著的燈——它的回答，要等到另一本書。

---

## 一、燈在哪裏

讀完二十四個研讀單元，回頭看這盞燈走過的地方：

| 處境 | 燈在哪裏 |
|------------------------------------------|------------------------------------------|
| 亞多尼雅自立為王（1） | 在大衛起過的誓裏：「你兒子所羅門必接續我作王」（1:30） |
| 神對所羅門說話（3；6；9） | 在每一次的條件句背後，都有「你父親大衛」 |
| 所羅門墮落（11） | 判決的當口：「還留一個支派給他的兒子，使我僕人大衛……長有燈光」（11:36） |
| 王國分裂（12） | 「除了猶大支派以外，沒有順從大衛家的」（12:20） |
| 亞比央的惡（15） | 「然而耶和華─他的　神因大衛的緣故，仍使他在耶路撒冷有燈光」（15:4） |
| 北國換了又換 | 燈不在那裏——王朝靠刀劍更替 |

## 二、燈沒有答案的地方

這盞燈只是「燈光」（נִיר），不是太陽。它照亮一個家，沒有說這個家會變好；列王紀上結束時，猶大的王有好有壞，北國一路向下。它回答的是「約沒有廢」，沒有回答「那個永遠的王是誰」。

## 三、真光

新約開卷，用家譜把這條線接上：所羅門、羅波安、亞比雅、亞撒、約沙法（太 1:6-8）。天使對馬利亞說：「主　神要把他祖大衛的位給他。他要作雅各家的王，直到永遠；他的國也沒有窮盡」（路 1:32-33）。耶穌說：「我是世界的光。跟從我的，就不在黑暗裏走，必要得著生命的光」（約 8:12）。啟示錄的最後一幅圖：「那城內又不用日月光照；因有　神的榮耀光照，又有羔羊為城的燈」（啟 21:23）；「不再有黑夜；他們也不用燈光、日光，因為主　神要光照他們。他們要作王，直到永永遠遠」（啟 22:5）。

**列王紀上的燈，是為大衛的緣故；啟示錄的燈，是羔羊自己。**

## 四、讓話語住在裏面

1. **你生命裏的「燈」是甚麼？**不是你配得的，是因另一個人的緣故留下的——你承認過嗎？
2. **你在等的，是一座更好的殿，還是那一位？**
3. **今天你願不願意把你自己的那點光，交給那位真光？**
