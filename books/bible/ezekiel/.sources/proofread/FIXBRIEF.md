# 修訂簡報（所有修訂者必讀）

你要把獨立校對者的報告落實到章節檔。你的報告檔與負責章節在你的指派裏。**只改你負責的章節檔**（不改 `.sources`、腳本、模板、別人的章、`00b`／`00c`／附錄）。不執行 git。

## 流程
1. 讀 `.sources/BOOK-SPEC.md` §0、§2；讀你的報告（`.sources/proofread/Pn.md`）**全文**。
2. 對報告中的**每一條 A 與 B**：**先自己向原始來源重新取證**（不要只信報告），確認屬實後才改；報告若錯（校對者也會錯），在你的回報中說「不成立」並寫明證據，不改。改法優先順序：改正 → 改為不加引號的轉述 → 刪除該句。**不可為了補洞而新增未查證的事實。**
3. C 級：錯字、標點、過程用語（見下）、明顯重複，能改就改；「精簡」與長度不在本輪處理。
4. 改完逐章跑 `python3 books/bible/ezekiel/.sources/check_chapter.py <檔>`（須 0 errors），並 `python3 scripts/lint-chapter-markup.py <檔>`。**經文區不得改動**（它必須與 units 檔一致）。
5. 回報：每條 A／B 的處置（已改／報告不成立＋證據／無法處理＋原因），以及你另外發現並處理的問題。

## 全書統一規則（本輪必須套用）
**(1) 直接／間接的唯一標準。**「直接」只用於：新約明引以西結書；或新約文字**重用了獨特的字詞或意象**，而且書中引的注疏或倉庫材料也這樣認定（例：啟 4 的寶座與四活物、啟 7:3 與 9:4 的額上印記、啟 21:3、啟 22:1-2 的河與樹、約 10 論好牧人與結 34 的對照）。其餘一律「間接」——包括：約 3:5 與結 36:25-27（同詞，但約 3:5 沒有明引，倉庫材料只說是最可能的讀法）、約 11 與結 37、約 7:37-39 與結 47、約 1:14/1:18 與結 1、來 9–10 與 40–48 的祭祀、彼前 4:17 與結 9、太 1:23 與結 48:35。同一個連結在全書只能有一個標示；若你的章內自相矛盾（例：基督焦點寫「直接」、全經連線寫「間接」），以本標準統一，並在句中老實說明為甚麼是間接（例如「約翰沒有引用以西結書」）。
**(2) 33:22 的措辭。**能確定的是：手在逃來的人**到達的前一晚**降在先知身上（和合本與 NASB 同）。「口是在消息到達之前就開了」是**一種讀法**——和合本的語序與多數注疏（K&D、JFB、Gill、Pulpit、Skinner）如此讀；NASB 譯作「在他們早晨來的時候開了我的口」，劍橋聖經在不同的注裏兩種說法都有。凡把它寫成毫無爭議的事實處，改為「手在前一晚降下；開口的時間，和合本與多數注疏讀作在消息之前，NASB 讀作消息到時」。第 24 章的「Qal／Niphal 兩個動詞」之分是本書自己的推論，須標明為推論（K&D 把第二個動詞視為重述）。
**(3) 「知道我是」只說嚴格字串：**和合本 61 節，6:7–39:28；5:13 等有變體（見 BOOK-SPEC §4）。
**(4) 日期：**希伯來文 26:1 與 32:17 沒有月序（和合本補「十一月」「十二月」，NASB 不補）；40:1 用「年初」。引用這兩處的月份時須註明這一點；全書帶日期的神諭共 13 處（1:1-2 算一處；29:17 在內）。
**(5) 加引號的經文必須逐字等於和合本**（用 `aieden/aieden-NN.json` 或 `xref.py` 核對，只允許「裡」→「裏」）；不是和合本字句的，去掉引號或改為轉述。**不要引用 `.sources` 內不存在的 BDB／LXX 內容**：標為「BDB」的詞義若無法在 biblehub 的 Strong's／BDB 頁核到，就刪去「BDB」二字，只保留你核到的來源。
**(6) 印出來的書不得出現工具與內部檔名：**行文中的 `xref.py`、`calvin-11.txt`、`.sources`、`check_quotes`、`QUOTE-LEDGER`、`units/`、repo 路徑（`books/bible/...`）一律改成讀者看得懂的說法（例：「加爾文論 11:16 的注」「倉庫中的老弟兄約翰福音材料（〈七個「我是」〉一章）」）。「我檢查…」「我逐節算…」之類第一人稱過程語，改成一句不帶人稱的事實說明（例：「依和合本逐節檢查，…」），且每個論點最多保留一次方法說明。
**(7) 「同上」只能指向緊接在前面的同一位注疏者；**若前一條是別人，寫出完整出處。
**(8) 用字：**裏／甚麼／著；經文區內的字形不動。

## 不要做的事
不要加新的注疏引文（除非為了取代被刪的一條，且必須通過 check_quotes.py，並先 grep `.sources/QUOTE-LEDGER.tsv` 確認未被他章用過，用後追加一行）；不要擴寫；不要改標題與章號；不要動 YAML 與十一節標題。
