# 精簡後校對補充簡報（與 BRIEF.md 一起讀；BRIEF.md 的鐵則與格式仍然有效）

這些章節剛被精簡過（刪重複論述、刪約四成注疏引文、改寫過渡句）。你的**首要任務**是找「精簡造成的缺陷」，其次才是 BRIEF.md 的一般檢查。你沒有看過精簡前的版本；精簡前的版本在 git 的 HEAD~1（`git show HEAD~1:books/bible/ezekiel/<檔>`），你**可以**用它對照，但不必信任它。

## 精簡特有的缺陷（逐章逐條找）
1. **孤兒指向**：「見〈歷代注疏〉」「如下」「前述」「第 N 點」「上表」指向已不存在的內容；〈領受要點〉提到某注疏者的立場、但〈歷代注疏〉已無該立場的引文且行文沒有交代。
2. **斷掉的過渡句**：引言句與其後引文不相接、引言說「兩段」但只剩一段、某小節只剩一句引言沒有內容、列舉項數與實際不符（「三條都是…」但剩兩條；「四個動詞」但表只剩三列）。
3. **「同上」歸屬**：每個「— 同上」所指的上一條來源，是否真是同一位作者同一書？每位注疏者小節的第一條是否有完整出處？
4. **失去支撐的斷言**：刪掉引文後，行文仍寫「X 說…」，注疏檔裏查得到嗎？（轉述 vs 杜撰）刪除零碎子句後，剩下的句子是否變成過度斷言（例如原本有限定語被刪了）？
5. **數字與計數**：精簡後的計數（「共 N 處」「四次」）是否仍與文本相符？表格行數被刪後的「N 列」描述。
6. **體例說明與章末「本章研讀整合」**：列出的注疏者是否與該章實際有引文／有提及的一致？
7. **老弟兄一節**：結構是否仍完整（有「你看見耶穌了嗎」收尾段；不得出現不存在的引號語錄；方法性撮述聲明仍在）？
8. **敏感段落**：第 11、17、18 章的謹慎說明與第 18 章喪親語句是否仍在、有無被精簡成冷漠或誤導。
9. **33:22**：第 24、18 章等凡涉及，確定的只有「手在前一晚降下」；開口時間是一種讀法。有無被精簡改成斷言？
10. 引文本身：每條**仍存在**的英文引文仍須是來源檔逐字（腳本已查過，你抽查即可），中譯忠實。
