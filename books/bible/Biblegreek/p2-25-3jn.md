## 本系列在這卷查過的字

| 詞目 | 意思（原註） | 位置 | 原註解 |
|------------------------|------------------|----------------|------------------------------------------|
| ἀγαθοποιέω | 行善 | 1:11 | 多見於路加福音與彼得前書；可 3:4「在安息日行善行惡，救命害命，哪樣是可以的呢？」同時用了這兩個字 |
| ἀγαπητός | 親愛的、蒙愛的 | 1:1; 1:2 | 全部是對該猶說的；每次都開啟一個新段落 |
| ἀξίως τοῦ θεοῦ | 配得過神地 | 1:6 | 副詞，修飾「送行」；同一片語見帖前 2:12「對得起……神」 |
| ἀσπάζομαι | 問安 | 1:15 | 英譯本把它譯成 "salute" 與 "greet" 兩個字，並不必要 |
| διὰ μέλανος καὶ καλάμου | 用墨與蘆葦筆 | 1:13 | 只有這裏指筆；其餘都指蘆葦（如太 11:7） |
| ἔγραψά τι | 我寫了一點東西 | 1:9 | 韋斯科特說約翰「輕描淡寫」這封信；梵蒂岡抄本作 ἔγραψας（「你寫了」），另有抄本加 ἄν（「我本想寫」） |
| ἐθνικός | 外邦人 | 1:7 | 新約另見太 5:47、6:7、18:17，都指教會以外的人；普盧默據此認為這裏不是指外邦信徒 |
| εἰρήνη σοι | 願你平安 | 1:15 | 主耶穌復活後向門徒的問安（約 20:19、21、26） |
| ἐκ τοῦ θεοῦ ἐστιν | 屬乎神、出於神 | 1:11 | 介系詞 ἐκ 表示來源：他的生命出於神 |
| ἐκβάλλω | 趕出、丟出去 | 1:10 | 約 9:34-35 瞎子被「趕出去」用的是同一個字 |
| ἐν ἀληθείᾳ | 在真理中 | 1:1 | 和合本譯「誠心」 |
| ἐξέρχομαι | 出去 | 1:7 | 韋斯科特指出這些人為真理「出去」，正如另一些人為謬誤「出去」（約二 7、約一 2:19） |
| ἐπιδέχομαι | 接納、承認 | 1:9; 1:10 | 第 9 節指不承認使徒的權柄，第 10 節指不接待弟兄 |
| ἐργάζομαι | 做工、勞力 | 1:5 | 和合本「所行的」 |
| εὐοδόομαι | 興盛、順利 | 1:2 | 同一個動詞，新約另見羅 1:10、林前 16:2 |
| ἡ μαρτυρία ἡμῶν ἀληθής | 我們的見證是真的 | 1:12 | 約 21:24「我們也知道他的見證是真的」幾乎同一句 |
| κακοποιέω | 行惡 | 1:11 |  |
| καλῶς ποιήσεις | 你就做得好了 | 1:6 | 麥克阿瑟指出這是當時的客氣用語，相當於「請你」 |
| κωλύω | 禁止、攔阻 | 1:10 | 現在式 |
| λόγοις πονηροῖς | 用惡言 | 1:10 | πονηρός 正是約翰一書稱「那惡者」的字（約一 3:12「該隱……屬那惡者」） |
| μαρτυρέω | 作見證、證明 | 1:3; 1:12 | 完成式被動：見證已經給出，至今仍然有效（普盧默） |
| μειζότερος | 更大的 | 1:4 | 雙重比較級（「更更大的」），普盧默指出這是語言晚期的形式，類似弗 3:8「比眾聖徒中最小的還小」的說法 |
| μηδὲν λαμβάνοντες | 一無所取 | 1:7 | λαμβάνω「取」；μηδέν 表示一種刻意持守的原則 |
| μιμέομαι | 效法、模仿 | 1:11 | 來 13:7，本節；名詞 μιμητής（效法者）見林前 4:16、11:1，弗 5:1 等 |
| ξένος | 陌生人、客旅 | 1:5 | 羅 16:23 保羅稱哥林多的該猶為 ὁ ξένος μου（「接待我的」）——同一個字，兼指客人與主人 |
| ὁ πρεσβύτερος | 長老、年長者 | 1:1 | 冠詞加上去，是「那位長老」；收信人不需要別的說明就知道是誰 |
| οἱ φίλοι | 朋友們 | 1:15 | 參約 15:13-15、約 11:11「我們的朋友拉撒路」 |
| οἶδα（οἶδας） | 你知道 | 1:12 | 單數「你」；普盧默指出有抄本作複數「你們知道」（或因把本信當作大公書信），少數作「我們知道」（受約 21:24 影響） |
| οὔτε αὐτὸς ἐπιδέχεται | 他自己不接待 | 1:10 | 與第 9 節同一個動詞；從不接待使徒的信，到不接待使徒的人 |
| περιπατέω ἐν ἀληθείᾳ | 在真理中行走 | 1:3; 1:4 | 在約翰的著作中只見於約二 4 與本信 3、4 節；「行走」是聖經描寫日常為人的慣用意象 |
| πιστὸν ποιεῖς | 你做的是忠心的（事） | 1:5 | 韋斯科特譯作「你所做的必有著落」（thou makest sure）——這樣的行為不會白費 |

| σου τῇ ἀληθείᾳ | 你的真理 | 1:3 | 和合本譯「你心裏存的真理」；普盧默指出指的是該猶的基督徒生活，不是一般意義的「福音真理」 |
| στόμα πρὸς στόμα | 口對口 | 1:14 | 新約只見於約二 12 與本節；民 12:8 希伯來文「口對口」，和合本譯「面對面」 |
| συνεργοὶ τῇ ἀληθείᾳ | 為真理／與真理同工 | 1:8 | 只有這裏接與格；其餘多接屬格，或用介系詞 εἰς（西 4:11、林後 8:23） |
| τὰ ἐμὰ τέκνα | 我自己的兒女 | 1:4 | 強調的所有格形容詞，比一般的「我的兒女」（τὰ τέκνα μου）更親 |
