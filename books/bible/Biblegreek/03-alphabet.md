# 第三章：認字母，讀出聲 (The Alphabet)

> **座標**：本書骨幹〈啟示的次序〉——第五步：人怎麼讀——從認字母開始；你第一批學會讀出聲的字裏，有 `Ἰησοῦς`、`Χριστός` 這兩個名字。

希臘字母一共二十四個。你其實早就認得不少：數學課的 α β π、科學課的 Δ Σ Ω、大學社團的 Alpha Beta，都是它們。**花一個晚上，就能把二十四個字母讀出來。**

## 二十四個字母

| 大寫 | 小寫 | 名稱 | 近似發音（以英文字母標示） |
|------|------|------|---------------------------|
| Α | α | alpha | a |
| Β | β | beta | b |
| Γ | γ | gamma | g |
| Δ | δ | delta | d |
| Ε | ε | epsilon | e（短，如 bet） |
| Ζ | ζ | zeta | z |
| Η | η | eta | e（長，如 they） |
| Θ | θ | theta | th |
| Ι | ι | iota | i |
| Κ | κ | kappa | k |
| Λ | λ | lambda | l |
| Μ | μ | mu | m |
| Ν | ν | nu | n |
| Ξ | ξ | xi | x |
| Ο | ο | omicron | o（短） |
| Π | π | pi | p |
| Ρ | ρ | rho | r |
| Σ | σ（字尾 ς） | sigma | s |
| Τ | τ | tau | t |
| Υ | υ | upsilon | u／y |
| Φ | φ | phi | ph（f） |
| Χ | χ | chi | ch（如蘇格蘭語 loch） |
| Ψ | ψ | psi | ps |
| Ω | ω | omega | o（長） |

兩點說明：

- 小寫 σ 在字的**末尾**寫成 ς（例如 θεός、λόγος）。這只是寫法，不是另一個字母。
- 現代學者讀古典與新約希臘文，發音方式有好幾種，各教材略有不同。**對讀經而言，一致比正確更重要**：選一種，用到習慣。

## 兩個你一定會遇到的符號

**氣號（breathing）** 出現在以母音開頭的字的字首：`ἀ` 與 `ἁ`。帶 `ἁ` 這種「粗氣號」的字，開頭要加一個 h 的音（例如 `ἁμαρτία` 讀作 hamartia，「罪」）；帶 `ἀ` 這種「平氣號」的字，不加。（以 `ρ` 開頭的字也帶氣號。）另外，`γ` 在 `γ`、`κ`、`ξ`、`χ` 之前讀成鼻音 ng，例如 `ἄγγελος`（天使）讀作 angelos；初學時不必在意。

**重音符號（accents）** 有三種：`ά` `ὰ` `ᾶ`。**新手可以放心忽略它們。** 它們對辨認字的意思幫助有限，只有少數情況（兩個拼寫相同的字靠重音區分）才重要。

## 練習：你已經會讀的字

試著把下面的字讀出來，再對照答案。

| 原文 | 讀作 | 意思 |
|------|------|------|
| Ἰησοῦς | Iesous | 耶穌 |
| Χριστός | Christos | 基督 |
| θεός | theos | 神 |
| ἀγάπη | agape | 愛 |
| πίστις | pistis | 信 |
| χάρις | charis | 恩典 |
| εἰρήνη | eirene | 平安 |
| ἐκκλησία | ekklesia | 教會（被召聚的群體） |
| εὐαγγέλιον | euangelion | 福音、好消息 |

其中 Χριστός 的第一個字母 Χ，就是教會藝術裏常見的 ΧΡ（Chi-Rho）標誌的來源。

## 默想與練習

1. 把二十四個字母抄寫兩遍，一邊寫一邊念名稱。
2. 打開約翰福音 1:1 的希臘文（附錄與第七章有全文），試著不看答案，把每個字母的名稱念出來——速度慢沒有關係。

> 練習題見附錄〈練習題與答案〉第 1 題。

## 你看見耶穌了嗎？

你這一章練習的第一批字裏，有 `Ἰησοῦς` 與 `Χριστός`。學會讀出這兩個名字，你就能在原文裏認出祂的名字——認出名字，只是開始，還沒有讀懂。
