# 神的總計劃：從創世記到啟示錄 (God's Whole Plan: From Genesis to Revelation)

> 這一章在六十六卷讀完以後才寫得出來。它回答三個問題：
> **整本聖經的故事走了幾步？四福音站在第幾步？每一章福音的事件，背後牽著哪一條線？**

---

## 精義一句話

（這一句是本書編者對全經的概括，不是老弟兄的原話。）

**整本聖經只有一條線：神要與人同住。創世記的園子失去了這件事，出埃及記的會幕預備了這件事，約翰福音說「住在我們中間」成就了這件事，啟示錄的新耶路撒冷完成了這件事；四福音站在這條線的正中央，是神唯一一次親自走進祂自己的計劃裏。**

---

## 一、為甚麼這一章放在耶穌的生平之前

第一次讀四福音，讀到的是一個人的故事：他出生、教導、行神蹟、被釘、復活。

讀完六十六卷再回頭，讀到的是另一件事：每一個場景的後面都站著一整卷舊約。伯利恆的馬槽後面站著彌迦書的問句；曠野四十天後面站著申命記的四十年；聖殿被潔淨的那一天，後面站著耶利米書和瑪拉基書；十字架後面站著利未記的贖罪日。這些不是巧合式的呼應，是**同一位神按著同一個次序在行事**。

本書的做法因此是：**每一章先告訴你站在哪裏，再讀事件。** 站在哪裏，有兩個座標——

| 座標 | 問的是 | 出現在哪裏 |
|---|---|---|
| **生平座標** | 這是耶穌一生的第幾站？ | 每章「基督焦點」的第二行 |
| **計劃座標** | 這是神整個計劃的第幾步？ | 每章「基督焦點」的第三行；每個分卷扉頁 |

下面先把「計劃」本身攤開。

## 二、七步：六十六卷的次序

本書把全經分成七步。這個分法是為了讀福音而用的：前五步是「等」，第六步是「來」，第七步是「差遣與完成」。

| 步 | 神做了甚麼 | 範圍 | 本系列各卷卷首自己怎麼說 |
|---|---|---|---|
| **一** | 創造與墮落——神先說話，人先背離 | 創 1–11 | 創世記不是把七十億人的故事平鋪直敘，是一路收窄的漏斗：從「萬有」收到「人類」，收到「一個家」，收到「一個支派」（《創世記》卷首〈啟示的次序與神的計劃〉）。 |
| **二** | 應許與揀選——一路收窄到一個家 | 創 12–50 | 加拉太書的骨幹是次序：神應許亞伯拉罕因信稱義，在西奈山頒布律法的四百三十年以前；律法是看守人，直到那蒙應許的子孫來到（《加拉太書》卷首）。 |
| **三** | 救贖、立約與同住 | 出–申 | 出埃及記：神拯救人，不是要把人留在自由裏，是要把人帶回來與祂同住（《出埃及記》卷首）。利未記：先給路，再提要求；先贖罪，才說「你們要聖潔」（《利未記》卷首）。申命記：把西乃山的話搬到人心裏去（《申命記》卷首）。 |
| **四** | 進入、王與殿 | 書–王、代；詩、箴、傳、歌 | 約書亞記：從「剛強壯膽」走到「沒有一句落空」。士師記：循環是往下收緊的螺旋，能終結它的只有一位王。路得記：至近的親屬與救贖者。列王紀：殿會舊、國會裂、王會倒，留下來的是神為大衛的緣故點在耶路撒冷的一盞燈，等的是一位比所羅門更大的人。詩篇：照神的次序讀，主角從頭到尾只有一位。 |
| **五** | 先知、被擄與歸回 | 賽–瑪 | 以賽亞：審判與拯救是「以色列的聖者」同一份聖潔的兩面。耶利米：神守著祂的話使得成就，新約最後落在心上。以西結：榮耀先離開殿，又從離開的方向回來。但以理：權柄從來不是奪來的，是被賜的，最後賜給那位像人子的。以斯拉：神的手在先，人才起來做事。尼希米：牆圍得住外敵，圍不住人心。 |
| **六** | **基督來臨** | **四福音（本書卷一至卷八）** | 馬太：四百年的靜默不是神忘了說話，是話已說完、在等應驗，等的那一位到了（《馬太福音》卷首）。馬可：8:29 彼得答對了名字、答錯了意思。路加：9:51「定意向耶路撒冷去」，他走的每一步都是去找一個失喪的人。約翰：進了幔子裏面的那一進。 |
| **七** | 教會與再來 | 行傳–啟（本書卷九） | 行傳：「見證」。羅馬書：神的義在福音上顯明。希伯來書：更美。彼得前書：先受苦，後得榮耀。啟示錄：約翰聽見的是獅子，轉頭看見的是羔羊。 |

這張表上每一句，都出自本系列對應那一卷自己的卷首章；各卷是各自獨立讀出來的，不是為了湊這張表才寫的。**它們湊得起來，這件事本身就是證據。**

## 三、四條穿過全經的線

本書每一章的「老弟兄查經 · 全經連線」，都是從下面四條線裏選。先把它們各自的起點與終點記住。

### 線一：同住

| 站 | 事 | 經文 |
|---|---|---|
| 園子 | 神在園子裏與人同在，人被逐出 | 創 3 |
| 會幕 | 「使我可以住在他們中間」 | 出 25:8；出 40:34-35 |
| 殿 | 榮耀充滿殿；榮耀離開殿 | 王上 8；結 10–11 |
| **道成肉身** | **「住在我們中間」——這個動詞的意思是「支帳棚」** | **約 1:14** |
| 教會 | 聖靈住在信徒裏面 | 徒 2；林前 3:16 |
| 新耶路撒冷 | 「神的帳幕在人間。他要與人同住」 | 啟 21:3 |

以西結書的骨幹正好是這條線的轉折：神的榮耀降在會幕與殿，離開了殿，在被擄之地向人顯現，又回到殿；到新耶路撒冷，連殿也不用了，因為神自己在那裏（《以西結書》卷首〈啟示的次序〉）。

### 線二：王

| 站 | 事 |
|---|---|
| 士師記 | 循環的終點是一個空缺：「那時以色列中沒有王」，只有一位王能終結循環 |
| 列王紀 | 王一個一個倒下，留下一盞為大衛點的燈 |
| 但以理書 | 國度是被賜的：神賜、神收回、最後賜給像人子的 |
| 彌迦書 | 一位從伯利恆出來的牧者（5:2） |
| **四福音** | **馬太的「王」：從家譜到「天上地下所有的權柄」** |
| 啟示錄 | 羔羊得勝，萬王之王 |

### 線三：救贖者

| 站 | 事 |
|---|---|
| 路得記 | 至近的親屬，要出代價把人贖回 |
| 利未記 | 贖罪日：先贖罪，才說聖潔 |
| 以賽亞書 | 「以色列的聖者」同時是審判者與拯救者 |
| 希伯來書 | 更美的祭司、更美的祭、更美的約 |
| **四福音** | **馬可 10:45：人子來是要捨命，作多人的贖價** |
| 啟示錄 | 羔羊被殺，是得勝的方式 |

### 線四：神先動

這條線不是一個題目，是全經的**次序**。

- 以斯拉記：每一次人起來做事之前，先有一個「神先動」的句子（《以斯拉記》卷首）。
- 帖撒羅尼迦前書：人的回應永遠排在第二位，先是揀選，後是呼召，最後是神親自成就（《帖撒羅尼迦前書》卷首）。
- 以弗所書：「天上」這個座標出現五次，第一次是白白領受的祝福，最後一次是必須站穩的戰場（《以弗所書》卷首）。
- 約翰一書：神先、人後（4:19；《約翰一書》卷首）。

四福音裏最容易讀反的地方，都是這條線被倒過來：把「門徒跟從耶穌」讀成他們的選擇（約 15:16 說相反），把「悔改」讀成換取赦免的條件。本書每一章讀的時候，會再問一次：**這裏誰先動？**

## 四、四福音在計劃中的位置

四福音不是四個版本，是同一件事的四個面。摩根引用皮爾遜（A. T. Pierson）的比喻，把四福音比成走過會幕的四個位置：馬太是全營圍繞著王，馬可是外院（服事與獻祭），路加是聖所（燈臺與陳設餅），約翰是幔子裏面的至聖所（出處與原文引文見《約翰福音研讀》卷首〈啟示的次序與組織〉）。這個比喻不是說哪一卷高低，而是說：**同一座會幕，從外院走到至聖所，要走過四個位置。**

本書因此不把四福音拆開各自讀，而是依著耶穌一生的次序，把四個面合在一起，每一站讀完整的那一面。

## 六、誠實的邊界

一條「骨幹」可以講成一篇漂亮的講章，也可以講成一本不誠實的書。為了避免後者，這一章先把邊界說清楚：

- **不是每一節舊約都是基督的預表。** 本系列各卷各自辨別過：哪些是新約自己指認的，哪些只是編者的對照。本書每章「全經連線」遵守同一個分別，並盡量標出屬於哪一種。
- **七步是編者的分法，不是聖經自己的章節。** 聖經沒有寫「第三步」；是六十六卷各自的次序，疊起來看，才顯出這個形狀。
- **有些事四福音自己就不一致，或解釋者有不同看法。** 例如兩次潔淨聖殿（站 7 與站 23）、最後晚餐的日期、橄欖山講論的應驗範圍、四本復活記載的細節。本書遇到這類地方，會把各種讀法並陳，標明哪一句是經文、哪一句是解釋，不為求整齊而強行調和。

讀的時候請帶著一個問題：**這一站，我看見耶穌是誰？**
