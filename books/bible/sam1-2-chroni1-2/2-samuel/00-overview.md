# 撒母耳記下概覽 (2 Samuel Overview)

## 書卷簡介

| 項目 | 內容 |
|------|------|
| **書名** | 撒母耳記下 (2 Samuel) |
| **作者** | 傳統認為主要由先知拿單和先見迦得寫成的資料彙編，最終編輯者不詳（代上29:29） |
| **寫作時期** | 資料約形成於主前10世紀大衛時代；最終編輯可能在所羅門時代或稍後 |
| **歷史跨度** | 約主前1010-970年（大衛在位40年：希伯崙7年半 + 耶路撒冷33年） |
| **章數** | 24 章 |
| **正典位置** | 希伯來聖經中，撒母耳記上下原為一卷（ספר שמואל），七十士譯本始分為上下兩卷 |
| **核心主題** | 大衛王朝的建立、輝煌、跌倒與神不變的約——在人的失敗中神的信實顯得更偉大 |
| **書卷弧線** | 榮耀（1-10）→ 跌倒（11-12）→ 長痛（13-20）→ 尾聲（21-24） |

**關鍵問題**：以色列需要的是更好的大衛，還是一位根本不同性質的王？

## 基督焦點 (Christ at the Center)

撒母耳記上以「誰是真正的王」收尾在大衛的受膏與逃亡；撒母耳記下則問一個更深的問題：**這位王，配得起這個位子嗎？** 答案在第7章達到頂峰——神應許大衛「你的家和你的國必在你面前永遠堅立」（7:16），這應許超越大衛本人的壽數、超越所羅門王朝四百年後的滅亡，唯有在「大衛的子孫、亞伯拉罕的後裔，耶穌基督」（太1:1）身上才完全應驗（來1:5引7:14）。

然而，這卷書同樣毫不留情地記載了大衛的跌倒——拔示巴事件（11章）、拿單的責備「你就是那人」（12:7）、以及隨之而來刀劍不離家的長期後果（13-20章）。大衛不是彌賽亞本人，只是彌賽亞的影子與預表：他能犯姦淫、能殺人、能被自己的兒子背叛；真正配得起永遠國位的那一位，要等到那位「大衛的root、又是大衛的後裔」（啟22:16）親自來到。大衛赤腳哭泣走上橄欖山（15:30），正是走向各各他之前，一幅提早畫下的苦難君王剪影。
