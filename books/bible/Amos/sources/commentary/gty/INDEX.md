# gty.org / John MacArthur material on Amos (fetched transcripts)

Fetched 2026-10-30. Every `<CODE>.txt` here is the full gty.org transcript, tags stripped (curl, full browser User-Agent, `div.expand--content`); first lines give TITLE, CODE, URL, SCRIPTURE as gty.org lists it, DATE, SPEAKER. Quotables in the table were copied programmatically and verified as exact substrings of the saved files (<= 60 words). Nothing was written from memory.

## How the set was found

- gty.org has NO Amos verse-by-verse series and NO sermon with Amos as its listed Scripture that I could find. Its Scripture filter (`/sermons/scripture/amos`) is client-rendered and returns nothing. Every file below is a sermon on another topic in which an Amos passage is read and explained.
- Method: targeted web searches restricted to gty.org (Amos 3:3, 4:1, 5:18, 5:21-24, 7:14, 8:11, 9:11 and general queries), then curl of each candidate transcript and a count/read of every `Amos` mention. 26 candidates were fetched; 11 kept. A full-site sitemap sweep (about 3,900 sermon pages) was NOT done, so lesser-known sermons that mention Amos only in passing, or that search did not surface, may exist. Treat the set as the strongest found, not provably exhaustive.
- Selection rule: kept where an Amos passage is read and explained over several consecutive paragraphs (PRIMARY) or 1-3 paragraphs (BRIEF). Only John MacArthur speaks in all kept files (numeric-code sermons from the main archive; no conference/other-speaker codes were kept).
- Not a sermon but his own written Amos material: the MacArthur Study Bible introduction to Amos (title, author/date, setting, themes, the Amos 9:11 / Acts 15 interpretive challenge, outline) is at https://shop.gty.org/library/bible-introductions/MSB30 . It was read (see `MSB30-intro-notes` below) but is not stored here as a transcript.
- NOT found: no commentary on Amos 1-2 (nations), 3:3-8 as exposition (only used as an axiom on walking with God), 5:18-20 Day of the LORD as an Amos exposition (searches returned only Thessalonians/Zephaniah-type sermons), 6:1-3, 7:1-9 visions, 7:10-17 Amaziah/7:14 call story (only the Study Bible intro and a one-line `shepherd from Tekoa` remark), 9:1-10, 9:13-15 beyond one passing paragraph.
