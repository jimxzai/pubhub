## 三、John Calvin

《創世記注釋》(*Commentary on Genesis*) 是本書歷代注疏引用最頻繁的單一出處，逐章論及對應經文：

| 論及經文 | 出現章 |
|------|------|
| 創1:1（摩西寫作方式適應普通人理解） | 01 |
| 創3:14-15（蛇被咒詛用肚子行走的屬靈象徵） | 02 |
| 創4:9（「我豈是看守我弟弟的」的心） | 03 |
| 創6-9章（挪亞信心之偉大） | 04 |
| 創11:5（耶和華「下來」的擬人與諷刺） | 05 |
| 創12:1-4（亞伯拉罕不問為甚麼只問往哪裏） | 06 |
| 創15:1-21（神獨自從切開的動物中經過） | 07 |
| 創18:23-33（亞伯拉罕從五十降到十的代求） | 08 |
| 創22:1-19（三日路程中的掙扎與順服） | 09 |
| 創25:19-34, 27章（神揀選雅各棄絕以掃的公義） | 10 |
| 創28:12（梯子作為基督的預表，惟獨基督連接天地） | 11 |
| 創32:22-32（「你不給我祝福，我就不讓你走」是信心的堅持） | 12 |
| 創37:5-11（約瑟講夢，問題不在約瑟而在哥哥們的嫉妒） | 13 |
| 創39:9（「我怎能得罪神」——一切罪最終都是得罪神） | 14 |
| 創45:1-15（約瑟的饒恕是基督饒恕的預表） | 15 |
| 創50:24-25（約瑟要求帶回骸骨是信心的行動） | 16 |

**另見**：安波羅修 (Ambrose of Milan, 339-397)，*On Joseph*（第15章與加爾文引文並列）；一般統一標註「約翰·加爾文 (John Calvin, 1509-1564)，*Commentary on Genesis*」。
