## 附錄二：主題索引 (Key Themes Index)

| 主題 | 簡述 | 主要章節 |
|------------------|--------------------------------------------------------------|--------------|
| 從聽道到行道 | 全書骨幹，1:22「你們要行道，不要單單聽道」貫穿五章 | 00c、01-05 |
| 重生在先，行道在後 | 1:18「用真道生了我們」是已成就的事實，行道是重生生命必然的果子，不是稱義的條件 | 00c、01 |
| 試煉與試探同一個字 | πειρασμός雙重意涵——外來熬煉信心，內裏私慾誘人犯罪，分別在乎人怎麼回應 | 01 |
| 信心與行為 | 真信心必然結出行為的果子；沒有行為的信心是死的，非「不夠好」 | 00a、00c、02 |
| 因信稱義的表面張力（雅各與保羅） | 保羅答稱義的根據（forensic），雅各答信心的明證（demonstrative）——互補而非矛盾 | 00a、00c、02 |
| 兩種智慧 | 屬地屬情慾屬鬼魔的智慧 vs. 從上頭來的智慧，以結出的關係果子為判準 | 03 |
| 謙卑蒙恩，驕傲遭拒 | 引箴言3:34；效法基督自己先降卑、後升高的路（腓2:6-9） | 04 |
| 忍耐等候主來 | παρουσία——全書終點，農夫等候式的忍耐，非被動麻木 | 05 |
| 彼此代求，挽回失迷的人 | 全書最後一句不是祝福語，是行動的呼籲；禱告的能力不在乎禱告者身分 | 05 |
| 雅各書的啟示次序位置 | 極可能是新約最早成文的一卷書，耶路撒冷會議之前，記錄教會最初期的樣式 | 00a、00c |
| 雅各書與登山寶訓 | 全書瀰漫耶穌口傳教訓的迴響，未曾引用成文福音書 | 00a、00c |
| 正典接納的過程 | 俄利根首引，優西比烏列為「有爭議但被接受」，367/397年確認正典地位；路德「禾稭書信」公案 | 00a |
| 約伯的忍耐 | 5:11引約伯為忍耐的榜樣；「忍耐」（ὑπομονή）不是逆來順受，是在苦難中始終不放棄與神的關係 | 05 |
