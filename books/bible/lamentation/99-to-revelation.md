# 通往啟示錄——一個還沒有回答的禱告 (To Revelation: A Prayer Not Yet Answered)

> 哀歌收在 5:22。這一章把書外的幾條線並排放在一起，看最後一卷書怎樣回到這個問號。
> 下面的連結，除非特別註明，都是**本書的對照**：經文彼此沒有明說互相引用。

---

## 一、書為什麼收在問號上

哀歌最後兩節是這樣的：

> **哀5:21-22**　耶和華啊，求你使我們向你回轉，我們便得回轉。求你復新我們的日子，像古時一樣。你竟全然棄絕我們，向我們大發烈怒？

和合本把 5:22 讀成問句；NASB 1995 把它讀成條件句：「Unless You have utterly rejected us And are exceedingly angry with us.」希伯來文是 כִּי אִם־מָאֹס מְאַסְתָּנוּ קָצַפְתָּ עָלֵינוּ עַד־מְאֹד，開頭的 כִּי אִם 兩種譯法都有人採用。本書兩種都印出來，不替它定案。這個讀法的分歧，正好說明這節為什麼難：祈求的人不知道答案是哪一個。

還有一個細節：5:22 的 מָאֹס מְאַסְתָּנוּ（「棄絕，你棄絕了我們」）是不定詞加定動詞，與 1:2 的「哭泣，她哭泣」、1:8 的「犯罪，她犯了罪」是同一種句式。眼淚、罪與棄絕，在書的頭尾用了同樣的分量說話。

## 二、三條線，走到哪裏

### 1. 安慰者的空位

| 經文 | 這一步說的 |
|------------------|----------------------------------|
| 哀1:2, 9, 16, 17, 21 | 「沒有一個安慰她的」：安慰者的位置空著五次 |
| 賽40:1 | 「你們的神說：你們要安慰，安慰我的百姓」 |
| 約14:16 | 「我要求父，父就另外賜給你們一位保惠師」 |
| 約一2:1 | 「在父那裏我們有一位中保，就是那義者耶穌基督」 |
| 林後1:3-4 | 「願頌讚歸與我們的主耶穌基督的父神，就是發慈悲的父，賜各樣安慰的神。我們在一切患難中，他就安慰我們，叫我們能用神所賜的安慰去安慰那遭各樣患難的人。」 |
| 啟7:17；21:4 | 「神也必擦去他們一切的眼淚」；「神要擦去他們一切的眼淚」 |

### 2. 寡婦與新婦

| 經文 | 這一步說的 |
|------------------|----------------------------------|
| 哀1:1 | 「現在竟如寡婦」 |
| 賽54:4-5 | 「不再記念你寡居的羞辱。因為造你的是你的丈夫」 |
| 啟18:7 | 另一座城說：「我坐了皇后的位，並不是寡婦，決不至於悲哀」 |
| 啟21:2 | 「聖城新耶路撒冷……就如新婦妝飾整齊，等候丈夫」 |

### 3. 神終於開口

| 經文 | 這一步說的 |
|------------------|----------------------------------|
| 哀5:19 | 「耶和華啊，你存到永遠；你的寶座存到萬代」 |
| 哀3:57 | 全書唯一以直接引語記下的神的話，是被回憶出來的：「不要懼怕」 |
| 來1:1-2 | 「神既在古時藉著眾先知多次多方地曉諭列祖，就在這末世藉著他兒子曉諭我們」 |
| 啟21:3 | 「有大聲音從寶座出來說：看哪，神的帳幕在人間。他要與人同住」 |
| 啟21:5 | 「坐寶座的說：看哪，我將一切都更新了！」 |

哀歌 5:19 提到的是神的**寶座**，5:21 求的是「**復新**我們的日子」（חַדֵּשׁ יָמֵינוּ）；啟 21:5 是「坐**寶座**的說」，所說的是「將一切都**更新**了」。「寶座」在兩處是同一個意象（和合本都譯作「寶座」，希伯來文與希臘文則是各自的字）；「復新」與「更新」字面不同（希伯來文 חַדֵּשׁ，希臘文另是一字），意思相近，都是使它成為新的。啟示錄沒有說它在回答哀歌；本書只指出，寶座與「使成新」在哀歌最後的禱告裏已經並排。

## 三、仍未解的事

- **啟示錄沒有取消哀歌。**啟6:10 裏被殺的人仍在喊：「聖潔真實的主啊，你不審判住在地上的人，給我們伸流血的冤，要等到幾時呢？」這與哀5:20 的「你為何永遠忘記我們？為何許久離棄我們？」是同一種問法。得勝的書卷裏，這個問題仍然在。
- **3:64-66 的報應祈求。**哀歌沒有把它軟化。新約另有「要愛你們的仇敵，為那逼迫你們的禱告」（太5:44）；本書把兩處並列，不替誰圓場。
- **神的沉默有多長。**哀歌沒有給日期；來1:1-2 說「在這末世」，啟21:5 說「看哪」。這兩個時間之間，哀歌所教的那種禱告，仍是教會的禱告。

## 讓話語住在裏面

**默想一整天的問題：**

1. 我是不是常把「神沒有說話」讀成「神不在」？哀歌的次序（3:57）給了我什麼別的讀法？
2. 我所期待的安慰，是一句話，還是一位同在的主？

**今天的祭壇：**

- **早晨**：讀 5:19 與啟21:5，各用一句話說：今天，我要在「你的寶座」前說的第一件事是什麼。
- **晚上**：想一件我仍在等神回答的事，不要替它找答案，只把它交給祂。
- **一個行動**：把 5:21 與 林後1:4 並排抄下來，找一位正在受苦的人，為他讀一遍。
