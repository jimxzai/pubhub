# 彌迦書研讀 — 章節撰寫規格（給每位撰寫者；2026-10-30）

先讀：`sources/PLAN.md`（骨幹、卷次、章檔名、已核事實）、本檔、範例章 `01-the-lord-comes-down.md`（**完整讀一遍，照它的體例**）。
體例＝約翰福音 11 節章節模板（`.claude/skills/eat-bible/references/chapter-template.md`）。你只寫**分到的章**，不改其他檔、不改範例章、不 commit。

## 一、檔案骨架（11 個 `## `，順序固定，與範例章逐項同構）

YAML 七行（與範例章逐字相同）→ `# 章題 (English Title)` → 參照行（`彌迦書 a:b-c:d`）→ `**經文核對**：[ai-eden.com/bible/micah/N](https://www.ai-eden.com/bible/micah/N?t=CUV,NASB&cols=2)`（跨章用第一章的連結）→
`## 基督焦點` · `## 配詩 (Opening Hymn)` · `@@SCRIPTURE a:b-c:d@@`（單獨一行，代表 `## 經文`）· `## 背景` · `## 原文研讀` · `## 領受要點` · `## 歷代注疏` · `## 詩篇與聖詩` · `## 老弟兄查經` · `## 生命應用` · `## 與其他經文的關聯` · 結尾斜體一行。
**H1 不加真實章節範圍**（真實範圍只在參照行與座標行）。`---` 前後必須有空行（否則被 pandoc 吞成 Setext 標題）。

`@@SCRIPTURE a:b-c:d@@` 由 `python3 books/bible/Micah/sources/scripture/inject_scripture.py <章檔>` 展開成 CUV＋NASB 1995 經文區塊——**你不手打任何經文區塊**；寫完章檔後自己跑一次，確認展開成功（章檔會被改寫，這是預期）。範圍跨章寫 `4:9-5:1`。
**節號陷阱**：Sefaria 希伯來文（`sources/hebrew/mic-N.json`，每章 `he` 陣列）採希伯來節號——**希伯來 4:14 ＝ 和合本 5:1；希伯來 5:n ＝ 和合本 5:(n+1)**；凡引彌 4–5 的希伯來文必須換算，正文一律用和合本節號。

## 二、基督焦點（必備）

`> **本章鑰詞：<原文> 「中譯」（出處）** \` + `> **全書座標**：啟示的次序·第 N 步——…`＋一至二段 hook。座標句要說出**這章在全書骨幹上的位置與作用**，不可只複述章節大意；不可與別章的座標句雷同。

啟示的次序（全書五步，定案，用詞照抄）：
1. 神先下來，先作見證（彌 1）
2. 審判從神的家、從領袖起（彌 2–3）
3. 判決與應許並排，中間沒有過渡（彌 3:12→4:1；彌 4）
4. 審判者先被擊打，君王從最小的地方來（彌 4:9–5:15）
5. 先陳恩典、後提要求；控告的神成為辯護的神；最後一問是「有何神像你」（彌 6–7）

單元對步：1→第1步；2→第2步（2:12-13 預嘗盼望）；3→第2步；4→第3步；5、6→第4步；7、8、9→第5步。

貫穿全書的線（每章用得上就點出，不要硬塞；數字全部已核，見 PLAN.md）：**שׁמע「聽」**（1:2 → 3:1 → 6:1 三次命令；最後是 7:7「我的神必應允我」＝「必聽我」）；**ריב「爭辯／辨屈」**（6:1-2 神是原告 → 7:9 神為我辯護）；**חסד「慈愛／憐憫」**（6:8 → 7:18 → 7:20）；**三輪「聽」各以盼望收**（2:12-13；4–5 章；7:7-20）。

## 三、不可越過的線（違反即退件）

1. **經文**：正文中任何「」＋（出處）的經文引句，必須逐字出自 `sources/scripture/cuv.tsv`（彌迦書）或 `python3 -c "import sys;sys.path.insert(0,'books/bible/Micah/sources/scripture');import cuv_lookup as c;..."`／`python3 books/bible/Micah/sources/scripture/cuv_lookup.py 賽 2 2-4` 查他書（和合本，FHL）。**引句裏不可插括號譯注**（要說明放在引句外）。同一節的引句與出處節號必須對得上。**注意**：`cuv.tsv` 內含 FHL 的括號小註（如 1:13「錫安民（原文是女子）的罪」）；正文引這些節時引到括號前後都可，但不要把括號小註當經文本文大段引。**寫完跑**：`python3 scripts/verify-prose-citations.py books/bible/Micah --self 彌`（0 MISS 才算過）。
2. **注疏引文**：只用已下載來源，**沒有可定位原文就不加引號**。可用來源（皆在 `sources/commentary/`、`sources/fathers/`、`sources/gty/`；各有 INDEX.md，先讀）：亨利 `commentary/henry/mic-page-<羅馬數字>.txt`（`ii`＝彌1 … `viii`＝彌7）；加爾文 `commentary/calvin/micah-only.txt`（`calvin/INDEX.md` 有講次↔節對照）；摩根〈The Message of Micah〉`commentary/morgan/message-of-micah.txt`（**全書概論，沒有逐章**，頁碼依 OCR 頁眉；用不上就不立摩根一節）；教父 `fathers/INDEX.md`（已列每條可逐字引用的句子與出處）；麥克阿瑟 `gty/INDEX.md`（**沒有彌迦書逐節講道**；找不到的章不立該節）。合併語料 `commentary/corpus.txt`。引文格式與範例章逐字相同：`> "English quote"` 換行 `> — 作者, *書名*, 章節 (來源)`；麥克阿瑟條目的出處行用 `> — John MacArthur, "<Title>" (sermon <CODE>)`。引文前一段中文導讀是撮述不是翻譯。**寫完跑**：`python3 scripts/verify-citations.py books/bible/Micah --source books/bible/Micah/sources/commentary/corpus.txt`（教父與麥克阿瑟條目另核其原檔；OK/DRIFT/MISS 都要看）；`python3 scripts/verify-sermon-quotes.py books/bible/Micah`。
   - 某位解經者在本章沒有可查的專論，**就不立該節**（體例說明已寫明），不補位、不改寫成像是他說的話。
   - 加爾文英譯本內有編者按語（`— Ed.`）；引文只取加爾文本人的句子。
   - 摩根只有概論：只能挑**確實切題**的句子，不可每章硬引。
   - **不要把兩位注疏者的話混成一句，不要把一人的立場說成另一人的**；轉述要說清楚「他主張／他提到／他承認有另一讀法」。
3. **不杜撰老弟兄的話**：倉庫沒有彌迦書的黃長老／老弟兄第一手材料。「老弟兄查經」一節只用他的**方法**（提問、全經連線、落到每日祭壇、回到耶穌），**不加引號歸給他任何話**；`voice.md` 白名單的語錄與倉庫內有出處的句子除外，且必須註明出處檔案。稱呼一律「老弟兄」，不寫「黃長老」。
4. **不編史料**：年代、人名、地名、數字，只用經文與已下載注疏支持的；推測要寫明「推測」。**全稱斷言（「全書只有」「每一次」「從不」）必須先用程式數過**（`sources/scripture/cuv.tsv`、`sources/hebrew/mic-*.json`）。字頻若報數字，註明依據與計法（和合本中文字面？希伯來字根？）。1:10-16 的地名雙關：只寫注疏已指出、或希伯來字面可核者，標明「讀音／字面」；不確定的不寫。
5. **原文研讀**：希伯來詞形一律從 `sources/hebrew/mic-N.json` 或 `python3 books/bible/Micah/sources/heb.py <Book> <chap> [verse]`（他書）**複製**，不憑記憶打 niqqud；希伯來字在中文行文裏前後各留一個空格；**只放單一希伯來字**，不放以 maqaf（־）連接或以空格連接的多字片語（XeTeX 會把它們排成亂序）；片語用音譯或拆成單字列。表格欄寬照範例章。不確定的詞義，寫「字面是…」並指出出處（亨利／加爾文／已下載來源），不要靠記憶斷言詞源。
6. **不硬說預表**：「彌迦是基督的預表」之類，必須有經文本身的連結（太 2:5-6；約 7:42；太 10:35-36；耶 26:18-19）才可說；其餘只寫「本書的對照，經文沒有互相引用」。**不抹平張力**：5:3「生產的婦人」是誰（注疏者意見分歧）、太 2:6「並不是最小的」與彌 5:2「為小」的字句差異、4:10 「到巴比倫去」的年代、3:12 是否「已」應驗（耶 26:19 王與民悔改後神「後悔」）、5:7 的露水與 5:8 的獅子、6:6-8 是否否定獻祭（奧古斯丁與亨利各怎麼讀）、7:6 是描述還是預言，都要讓它們保持張力。
7. **版本**：經文塊只由腳本產生；散文中的經文引句用和合本（CUV，FHL 版，字形用「裏／甚麼／那裏」），英文詞若引 NASB 1995 須與 `nasb1995.tsv` 逐字相同。
8. **不可有**：空洞屬靈套話、AI 腔、emoji、「值得注意的是」這類墊字、同一點在同章講三次以上。「活在今天」不編造 AI／時事案例；寫不出真實觸點就寫具體的生活處境。

## 四、章節內容規格

- 長度：每章 18–26 KB（含腳本展開的經文區塊）；你寫的部分約 9–13 KB。
- 背景 2–3 個 `###`；原文研讀 5–8 列（每列都能用資料核對）；領受要點 **3–4 條**，各自只屬於本章（搬到別章會不通順才算數）；
- 歷代注疏：`### 教父時期`（有可用條目才立）／`### 改革宗時期 (加爾文)`／`### 清教徒 (亨利)`／`### 摩根`／`### 麥克阿瑟`——有哪個立哪個，每節 1–3 條逐字引文；
- 詩篇與聖詩：一至二篇詩篇（逐字 CUV 引句）＋「配詩（見上）」一段說明；
- 老弟兄查經：`**精義一句話**`（一句，記得住）→ `### 全經連線`（3–5 條，每條出處對得上、引句逐字）→ `### 提問式對話`（先問／再問／追問／落到自己）→ `### 活在今天` → `### 今天的祭壇`（早晨／晚上／一個行動）→ **`**你看見耶穌了嗎**？`** 一段收尾（只用有經文連結的線）；
- 生命應用：默想問題 ≤3（角度不與提問式對話重複）＋禱告回應（奉主耶穌基督的名，阿們）；
- 與其他經文的關聯：表格 8–12 列；
- **配詩**：用 `sources/hymns/NN-*.txt`（NN＝本書單元序）。把英文兩節逐字抄入（含該檔標頭給的作者與年份；年份欄寫「not stated on source page」的，出處行只寫作者名），自己寫繁體中文意譯（逐行對照），版式與範例章相同。**配詩的「說明句」必須誠實**：不可說經文與聖詩互相引用；不可把聖詩裏沒有的意思寫進去。
- 全章不得出現：`TODO`、`@@`（除單行的 `@@SCRIPTURE …@@` 展開前）、`需verify`、`待補`。

## 五、寫作流程（避免停滯）

1. 讀範例章與本檔；讀你章節範圍的 `cuv.tsv` 行、`hebrew/mic-N.json`、亨利／加爾文相關段落、`fathers/INDEX.md` 與 `gty/INDEX.md` 對應列。
2. **分段寫入**：先 Write 骨架前半（到「領受要點」），再 Edit／append 後半。**不要一次寫整檔**。
3. 跑：`inject_scripture.py`、`verify-prose-citations.py … --self 彌`、`verify-citations.py …`、`python3 scripts/lint-chapter-markup.py <章檔>`、`python3 scripts/check-prose-scripture-quotes.py <章檔>`。全部乾淨才回報。
4. 回報（≤300 字）：檔名、大小、11 節核對、各檢查結果、**你不確定／可能有誤的地方清單**（尤其詞義、字頻、史實、歸屬）。誠實：做不到的標明，不要含糊帶過。完成後立刻停止，不要動別的檔案。

## 七、已知不可踩的坑（來自全庫歷史）
