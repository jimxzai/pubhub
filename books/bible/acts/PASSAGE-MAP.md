# Bilingual Passage Policy

The book contains two different kinds of Scripture presentation:

- **Parallel reference passages**: Chinese and English use the same verse set.
- **Independent reference excerpts**: each language selects a passage that serves the chapter's study argument; the two excerpts are not presented as verse-by-verse translations of one another.

The heading inside every chapter is the source of truth. The validator rejects an unequal pair unless both language headings explicitly declare the independent-reference policy.
