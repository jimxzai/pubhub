# 哈該書概覽 (The Book of Haggai Overview)

## 書卷簡介

| 項目 | 內容 |
|---------|-----------------------------------------------------------------------|
| 書名 | 哈該書 (Haggai)——希伯來文 חַגַּי，與「節期」（חַג）同一字根，辭書通常解為「節日的」 |
| 作者 | 先知哈該；書裏沒有交代他的家世。以斯拉記5:1；6:14 也提到他 |
| 對象 | 猶大省長所羅巴伯、大祭司約書亞，以及剩下的百姓（1:1；2:2） |
| 寫作年代 | 大利烏王第二年六月初一日至九月二十四日（1:1；2:20）。亨利標為主前520年 |
| 篇幅 | 兩章三十八節；OSHB 斷詞共 601 個詞 |
| 主題 | 百姓說「時候未到」，神用他們的帳目、祂的同在、祂的賜福與祂的揀選，一一回答 |
| 骨架字 | שׂים「放」（七次，其中「省察」五次）；אִתְּכֶם「與你們」（三次） |
| 日期 | 五個：1:1；1:15；2:1；2:10；2:20 |

## 全書結構：五步

本書把三十八節分成五段，每段一章，也就是〈啟示的次序與神的計劃〉所說的五步：

| 章 | 經文 | 步驟 | 神在做甚麼 |
|------|-------|---------------------|---------------------------------------------|
| 第一章 | 1:1-11 | 先翻開帳本 | 百姓說「時候未到」；神把他們的收成攤開來讀，才說「上山取木料」 |
| 第二章 | 1:12-15 | 先同在，後作工 | 百姓聽從；兩個字的信息「我與你們同在」；神激動他們的靈；動工 |
| 第三章 | 2:1-9 | 用同在回答比較 | 眼睛說「如無有」；神說「當剛強」「我的靈住在你們中間」「我就使這殿滿了榮耀」 |
| 第四章 | 2:10-19 | 祝福在收成之前 | 聖不傳染，污傳染；樹上還沒有果子，神說「從今日起，我必賜福與你們」 |
| 第五章 | 2:20-23 | 最後一句是揀選 | 震動、傾覆；「我必以你為印，因我揀選了你」 |

## 哈該書的寫法：日期與重複

這卷書喜歡兩件事：日期，與重複。讀的時候把它們圈出來，結構就清楚了：

| 手法 | 在哪裏 | 作用 |
|-----------|--------------------------------------|--------------------------------------|
| 日期 | 1:1；1:15；2:1；2:10；2:20 | 每個信息都釘在一個日子上；其中三個是「二十四日」 |
| 省察 | 1:5；1:7；2:15；2:18（2） | 同一個說法五次：前兩次看道路，後三次看「從今日」 |
| 萬軍之耶和華 | 14 次 | 全書每三節就有一次 |
| 這 | 11 次 | 這百姓、這殿、這日 |
| 我與你們 | 1:13；2:4；2:5 | 同在，與同在的根基（出埃及的約） |
| 三個神的動詞 | 2:9 我必賜平安；2:19 我必賜福；2:23 我揀選了 | 三個後半信息，各以神自己的動詞收尾 |

## 哈該書中的基督

哈該書沒有一處明說彌賽亞，新約卻把祂連到好幾個關鍵位置上（下表都是整本聖經的連線，不是原文所說）：

| 節 | 經文 | 基督是誰 |
|---------|----------------------------------|------------------------------------|
| 1:4 | 天花板的房屋，荒涼的殿 | 沒有枕頭的地方（路9:58）；為殿如同火燒（約2:17） |
| 1:13 | 我與你們同在 | 以馬內利（太1:23）；「我就常與你們同在」（太28:20） |
| 2:6-7 | 我要震動；使這殿滿了榮耀 | 「道成了肉身，住在我們中間……我們也見過他的榮光」（約1:14）；不能震動的國（來12:28） |
| 2:9 | 後來的榮耀；賜平安 | 「他使我們和睦」（弗2:14）；「我留下平安給你們」（約14:27） |
| 2:12-14 | 聖不傳染，污傳染 | 祂的手摸了大痲瘋病人，潔淨流向污穢（路5:13） |
| 2:23 | 以你為印；我揀選了你 | 父神所印證的（約6:27）；神所揀選的僕人（太12:18；賽42:1） |

## 怎樣用這本書

每一章都有同樣的十一節：基督焦點、配詩、經文、背景、原文研讀、領受要點、歷代注疏、詩篇與聖詩、老弟兄查經、生命應用、與其他經文的關聯。先讀〈啟示的次序與神的計劃〉，記住五步；每章開頭的「全書座標」會告訴你，這一章站在五步的哪一步。每章最後都問同一個問題：你看見耶穌了嗎？

讀之前，請先把哈該書一口氣從第一章讀到第二章，不要停。大約五分鐘。
