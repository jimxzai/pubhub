## 附錄二：主題索引 (Key Themes Index)

| 主題 | 簡述 | 主要章節 |
|----------------------|----------------------|------------------------------------|
| 清潔的良心 | 保羅在教牧書信反覆回到的根——衡量一切教訓真偽、一切資格是否成立的試金石；串連1:5、3:9及跨書的多1:15、提後1:3、來10:22、林後1:12 | 01、03、全書領受總綱 |
| 保羅的門訓法 | 教牧書信整體是「保羅的門訓」——不靠系統神學，靠把自己的生命攤開給提摩太看 | 01、全書領受總綱 |
| 只有一位中保 | 2:5-6是全信神學核心，排除一切人為的宗教中介 | 02、全書領受總綱 |
| 監督執事資格——品格先於恩賜 | 資格清單幾乎全是品格要求，唯一恩賜要求是「善於教導」；家庭是資格的試驗場 | 03 |
| 教會是真理的柱石和根基 | 3:15是全信結構關鍵句，教會存在的目的是持守並顯明真理 | 00、03 |
| 敬虔的奧祕 | 3:16讚美詩，六句話濃縮整個福音，是柱石所擎起的內容 | 00、03 |
| 敬虔操練 | *gymnazō*——像運動員一樣紀律性地操練敬虔；但以理、約瑟是舊約範本 | 04 |
| 三個律 | 黃長老框架：自然律、道德律、屬靈的律——人受造有身體、良心、更有靈 | 04 |
| 年輕領袖的權柄 | 靠榜樣與尊重贏得，不是靠職分壓服；「做長老和做基督徒的要求是一樣的」 | 04、05 |
| 盡職四大點（種子） | 提摩太後書完整表述前，已在提前4:14（恩賜）、6:20（託付）埋下種子 | 04、06、全書領受總綱 |
| 教會作為家庭 | 待年長者如父母、年幼者如弟兄姊妹；權柄靠關係尊重贏得 | 05 |
| 按立的鄭重 | 「不可急於給人行按手禮」；按手是同心尋求神旨意，不是儀式程序 | 03、05 |
| 知足 | 「敬虔加上知足就是大利」；知足是操練出來的，非天生 | 06 |
| 貪財是萬惡之根 | 問題不在金錢本身，在人心對金錢的貪戀 | 06 |
| 持守所託付的 | *parathēkē*——受託人有責任原封不動歸還、傳遞下去；全信收束句 | 06、全書領受總綱 |
| 三提合一 | 黃長老將提前、提後、提多視為一個整體：「串成一體：問題，盡忠，執行」 | 03、05、06、全書領受總綱 |
