## 三、教父時期與改教家 (Church Fathers and Reformers)

同樣以「指出／強調」轉述其一貫立場，未附著作書名（除加爾文《提摩太前書註釋》被具名提及）：

### 屈梭多模／金口約翰 (John Chrysostom, 約347-407)

| 出現章 | 論及經文／主題 |
|----------------------------------------|----------------------------------------|
| 01 | 保羅稱自己「罪魁」不是修辭謙卑而是真實認罪；傳道人當先知道自己何等蒙恩 |
| 02 | 為君王禱告顯明基督徒禱告心志不是報復 |
| 03 | 監督獨有「善於教導」的要求，是護衛純正教義的第一線責任 |
| 04 | 「操練自己」是像運動員反覆練習的屬靈紀律；保羅怎樣把提摩太的軟弱轉成服事動力 |
| 05 | 保羅對年長者「勸」而非「責」的用詞選擇，是給年輕領袖的榜樣 |
| 06 | 「貪財是萬惡之根」不是要信徒鄙視金錢，而是要看清貪戀之心的腐蝕 |

正文提及「屈梭多模在他對提摩太前書的講道中」（01章）、「在講論本章時」（02、05章），暗示其著作為 *Homilies on I Timothy*，惟未附篇號或逐字引句，本附錄如實不予杜撰篇號。

### 約翰·加爾文 (John Calvin, 1509-1564)

*Commentary on the Pastoral Epistles*（正文具名為《提摩太前書註釋》）：

| 出現章 | 論及經文／主題 |
|----------------------------------------|----------------------------------------|
| 01 | 1:5「命令的總歸就是愛」是檢驗一切教義的準則 |
| 02 | 2:5「只有一位中保」駁斥中世紀聖徒代求傳統 |
| 03 | 3:15「真理的柱石和根基」說明教會存在的首要職責 |
| 04 | 「作信徒的榜樣」不是自恃己義，而是教導須有生命印證 |
| 05 | 5:17「加倍的敬奉」同時包含尊重與物質供應兩層意義 |
| 06 | 奴僕與主人的教導：福音從裏面改變人心，而非立刻推翻社會結構 |
