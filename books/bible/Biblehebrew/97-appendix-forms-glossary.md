# 附錄：形態標注小字典 (Parsing Glossary) {.unnumbered}

本書第十章逐字表的「形態」欄，與各卷「原文研讀」裏的標注，用的是同一套術語。

## 詞幹（動詞）

| 名稱 | 中文 | 大致作用 |
|----------------|----------------|------------------------------------------|
| Qal | 基本 | 簡單的動作 |
| Niphal | 反身／被動 | 被動，或自己承受動作 |
| Piel | 加強 | 加強；常把「狀態」變成「動作」 |
| Pual | 加強的被動 | Piel 的被動 |
| Hiphil | 使役 | 使……去做 |
| Hophal | 使役的被動 | Hiphil 的被動 |
| Hithpael | 反身 | 自己對自己做 |

## 動詞的形式

| 名稱 | 中文 | 一般的作用 |
|----------------|----------------|------------------------------------------|
| Perfect | 完成式 | 完成的動作 |
| Imperfect | 未完成式 | 未完成、持續或將來的動作 |
| Wayyiqtol | 連續未完成式 | 敘事的骨幹：「於是……」 |
| Weqatal | 連續完成式 | 常用於描述重複、順序的動作 |
| Imperative | 命令式 | 命令（第二人稱） |
| Jussive | 祈願式 | 「讓他……」「要有……」 |
| Cohortative | 願意式 | 「讓我們……」 |
| Participle | 分詞 | 「做……的（人）」 |
| Infinitive | 不定詞 | 動詞的名詞形式（絕對式、連接式） |

## 名詞與形容詞

| 標注 | 意思 |
|------|------|
| m／f／b／c | 陽性／陰性／陰陽皆可／通性 |
| s／p／d | 單數／複數／雙數 |
| absolute（a） | 獨立形 |
| construct（c） | 連續形（後面接另一個名詞，「……的」） |
| determined（d） | 有定 |

## 前綴與詞尾

| 前綴 | 意思 |
|------|------|
| וְ | 並且、和 |
| הַ | 那個（定冠詞） |
| בְּ | 在、用 |
| לְ | 向、為 |
| כְּ | 如同 |
| מִ | 從 |
| שֶׁ | 那……的（關係詞，較少見） |

**詞尾**（pronominal suffix）：貼在名詞、動詞、介系詞後的代名詞，如 ־וֹ（他的）、־ִי（我的）、־ֵנוּ（我們的）。

## 人稱代碼

1 = 第一人稱（我、我們）；2 = 第二人稱（你、你們）；3 = 第三人稱（他、她、他們）。代碼如 3ms，就是「第三人稱、陽性、單數」。
