## 精義一句話

**王來了又走，話落在地上；人所緊貼的是甚麼，決定他的結局——而燈，比王活得久。**

**主句**：「這是因以色列人得罪那領他們出埃及地、脫離埃及王法老手的耶和華─他們的神。」（17:7）

---

## 作者的目的句——由此倒推全書

列王紀下不像先知書，不在開頭宣告目的，但作者在第17章自己停下來，把整卷書的邏輯寫成一句話：**這是因為**（17:7）。接下來十七節（17:7-23）用「因為」「所以」把北國的結局講清楚，並在17:13 點出關鍵：耶和華「藉眾先知、先見勸戒」，百姓「不聽從」（17:14）。倒推回去，整卷書的二十五章，是一個冗長的證明：**審判不是突然的政治事件，是長期不聽話的結果。**

但作者沒有停在這裏。全書最後留下一張桌子（25:27-30）——審判之後，仍有一位大衛的子孫活著。這是目的句的另一半：**因為神說過的話（8:19），這盞燈不會滅。**

## 骨架——分段結構即啟示

```
卷一  接棒（1–2）
      亞哈謝問錯了神 → 以利亞升天，以利沙接外衣

卷二  以利沙（3–8）
      三王無水 → 寡婦的油、書念婦人、毒湯 → 乃縵 → 斧頭、火車火馬 → 四個痲瘋病人 → 哈薛

卷三  衰亡（9–17）
      耶戶受膏 → 耶戶的熱心 → 亞他利雅與約阿施 → 約阿施修殿 → 以利沙之死
      → 亞瑪謝與耶羅波安二世 → 王如更替 → 亞哈斯的壇 → 撒瑪利亞淪亡

卷四  希西家（18–20）
      拉伯沙基的喊話 → 展開書信禱告 → 病、日影與巴比倫使者

卷五  瑪拿西與約西亞（21–23）
      瑪拿西 → 殿中尋見律法書 → 約西亞改革，死於米吉多

卷六  終局（24–25）
      約雅敬、約雅斤 → 耶路撒冷淪陷 → 約雅斤的桌子
```

**這個骨架本身就是啟示**：前八章是先知的書，話語活在先知身上；中間九章是王的書，話語被王晾在一邊；後面八章是話語被遺失又被尋見的書；最後兩章是那些話落地的書。書的重心，在第17章與第22章——一個回答「為甚麼亡」，一個回答「話在哪裏」。

## 這卷書在整本聖經的位置

- **創世記3:15** 的後裔應許，到大衛之約（撒下7）成為具體的家：列王紀下追問的是，這個家還剩下甚麼。
- **申命記27–28章** 的祝福與咒詛，在列王紀下全部看見應驗。
- **以賽亞書、耶利米書、以西結書** 在列王紀下的歷史背景之中說話。
- **路加福音4章** 把以利亞、以利沙的神蹟，放進耶穌的第一次講道。
- **馬太福音1章** 的家譜，回答了列王紀下留下的問題——這盞燈如何走到了人手中。

## 讓話語住在裏面

1. 「這是因為」——**你生命中，有沒有一件事，你現在還把它當作「突然發生的」，其實它背後有一條很長的「不聽」？**
2. 前八章是話語活在先知身上。**你身邊有沒有一個人，是神把話放在他身上的，你卻只當他是個「怪人」？**
3. 全書最後是一張桌子。**你願不願意相信，在你最暗的房間裏，也有一盞沒有被吹熄的燈？**

**你看見耶穌了嗎**：列王紀下所有的問題，都等同一個名字來回答。祂是話（約1:1）；祂是那位「專靠」父、一生沒有偏離的；祂是大衛的燈光所走向的那個人。
