## 二、新約直接引用申命記的段落

本書各章「基督焦點」與「全經連線」所依據、且經逐條查證的新約引用如下。申命記是新約引用最多的舊約書卷之一；下表是本書查證過的十四組對照（非窮盡清單），也是本書「妥拉不是被廢掉，是被成全」這一貫線索的骨架。

| 申命記 | 新約 | 引用者與情境 |
|------------|------------------------------|----------------------------------------------|
| 6:4-5 | 可 12:29-30；太 22:37；路 10:27 | 耶穌親口稱之為「第一，且是最大的」誡命 |
| 6:13 | 太 4:10；路 4:8 | 耶穌在曠野第三（路加為第二）次試探中引用 |
| 6:16 | 太 4:7；路 4:12 | 「不可試探主你的神」 |
| 8:3 | 太 4:4；路 4:4 | 「人活著不是單靠食物」 |
| 18:15 | 徒 3:22；徒 7:37 | 彼得與司提反同引，指認耶穌為「那先知」 |
| 18:15 | 約 6:14（參 1:21, 45） | 眾人稱耶穌「這真是那要到世間來的先知」 |
| 19:15 | 太 18:16；林後 13:1 | 兩三個人見證的定讞原則 |
| 21:23 | 加 3:13 | 「凡掛在木頭上都是被咒詛的」——基督為我們成了咒詛 |
| 24:1 | 太 19:7；可 10:4 | 論休妻，耶穌指其為「因你們的心硬」 |
| 25:4 | 林前 9:9；提前 5:18 | 「牛在場上踹穀，不可籠住牠的嘴」 |
| 27:26 | 加 3:10 | 「凡不常照律法書上所記一切之事去行的，就被咒詛」 |
| 30:12-14 | 羅 10:6-8 | 保羅以「這話離你甚近」論因信而得的義 |
| 32:35 | 羅 12:19；來 10:30 | 「伸冤在我，我必報應」 |
| 32:43 | 來 1:6（七十士譯本讀法） | 論子超越天使 |

| 那地 | הָאָרֶץ ha'arets | 全書反覆出現，是申命記的核心名詞之一 | 應許之地既是恩賜，也是順服的場域 |
| 磐石 | צוּר tsur | 作神的稱謂：32:4, 15, 18, 30, 31（另 32:37 指假神的「磐石」，32:13 指實際的磐石） | 摩西之歌對神的核心稱謂，新約以之指向基督 |
| 生命 | חַיִּים chayyim | 30:15, 19-20；8:3；32:47 | 「因為他是你的生命」——律法的終點是神自己 |

## 五、七處最值得反覆默想的經文

1. **6:4-5** 示瑪：「以色列阿，你要聽！耶和華我們神是獨一的主。」
2. **8:3** 「人活著不是單靠食物，乃是靠耶和華口裏所出的一切話。」
3. **10:12-13** 「耶和華─你神向你所要的是甚麼呢？」
4. **18:15** 「耶和華你的神要從你們弟兄中間給你興起一位先知，像我。」
5. **29:29** 「隱祕的事是屬耶和華我們神的；惟有明顯的事是永遠屬我們和我們子孫的。」
6. **30:14** 「這話卻離你甚近，就在你口中，在你心裏，使你可以遵行。」
7. **33:27** 「永生的神是你的居所；他永久的膀臂在你以下。」
