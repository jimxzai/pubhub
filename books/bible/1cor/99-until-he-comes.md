# 卷末：直等到他來 (Until He Comes)

> 一封處理麻煩的信讀完了。
> 但保羅在最後一章沒有給總結——他給了一個方向：主必要來。

---

## 老弟兄精義一句話

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 恩賜證明不了甚麼。\\ 十字架與復活，才是這封信從頭到尾的答案。}}\end{center}

---

## 一、全書其實只問了一個問題

十六章，十來類問題：結黨、告狀、淫亂、婚姻、祭偶像之物、蒙頭、主餐、恩賜、方言、復活、捐項。

看起來雜亂，其實每一次保羅的解法都繞回同一處：

| 問題 | 保羅的鑰匙 |
|--------------------------------|------------------------------------------|
| 結黨（1:12） | 「基督是分開的嗎？」（1:13） |
| 世人的智慧（1:20） | 「傳釘十字架的基督」（1:23） |
| 屬肉體（3:3） | 「那已經立好的根基就是耶穌基督」（3:11） |
| 淫亂（6:18） | 「你們是重價買來的」（6:20） |
| 祭偶像之物（8:1） | 「基督為他死的那軟弱弟兄」（8:11） |
| 主餐的混亂（11:20） | 「是表明主的死，直等到他來」（11:26） |
| 恩賜相爭（12:1-30） | 「我現今把最妙的道指示你們」（12:31） |
| 不信復活（15:12） | 「基督已經從死裏復活」（15:20） |

\textcolor{ScriptureGold}{\textbf{一把尺，量了十件事。這就是為甚麼 2:2 那句「只知道耶穌基督並他釘十字架」不是謙虛，是方法。}}

## 二、「直等到他來」——全書的時間感

11:26 那半句話，把主餐放在兩個時間點之間：

```
回頭看 ─────── 現在 ─────── 抬頭看
十字架         這一餐        祂再來
「主的死」      「表明」      「直等到他來」
```

同樣的時間感貫穿全書：

| 經文 | 指向將來 |
|------------------------------------------|------------------------------------------|
| 1:7-8 | 「等候我們的主耶穌基督顯現……在我們主耶穌基督的日子無可責備」 |
| 3:13 | 「各人的工程必然顯露……有火發現；這火要試驗各人的工程怎樣」 |
| 4:5 | 「時候未到，甚麼都不要論斷，只等主來」 |
| 11:26 | 「直等到他來」 |
| 15:23 | 「以後，在他來的時候，是那些屬基督的」 |
| 16:22 | 「主必要來！」（μαράνα θά） |

**16:22 是亞蘭文，保羅原封不動地留在希臘文書信裏——那是最早期教會的呼喊，比新約成書更早。**

## 四、13:13 為甚麼是「其中最大的是愛」

保羅在 13:8-12 給了理由：先知講道要歸於無有，方言要停止，知識也要歸於無有——**因為它們都是「有限的」，是為著「還沒有見面」的階段預備的。**

到那日：

| 現在 | 那時 |
|--------------------------------|------------------------------------------|
| 對著鏡子觀看，模糊不清 | 要面對面了 |
| 我所知道的有限 | 就全知道 |
| 信——信那看不見的 | 變成眼見 |
| 望——盼望他來 | 變成實現 |
| **愛** | **永不止息** |

\textcolor{ScriptureGold}{\textbf{信與望都會「完成任務」而退場，唯有愛跨過那條線繼續存在——因為神就是愛，而我們要與祂永遠同在。}}

## 讓話語住在裏面

**默想**：
哥林多教會「在恩賜上沒有一樣不及人的」（1:7），卻幾乎每一件事都做錯了。那麼，我用甚麼來衡量自己的屬靈光景？

**實踐**：
這一週，挑一件你正在煩惱的事——不是屬靈的事，是很實際的那種。把 2:2 那句話放在它旁邊，問：如果十字架是答案，這件事該怎麼處理？

---

## 你看見耶穌了嗎？

哥林多前書把基督放在幾個位置上：神的智慧與能力（1:24）、我們的根基（3:11）、我們逾越節的羔羊（5:7）、那磐石（10:4）、身體的頭（12:12-27，全體的原則）、初熟的果子（15:20）、末後的亞當（15:45）。

而全書最後一句呼喊，是最早期教會的原話：

> **林前 16:22**（和合本）……主必要來！

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 一封處理麻煩的信，最後一句不是「問題解決了」，\\ 是「主必要來」。}}\end{center}

**阿們。主耶穌啊，我願你來。**
