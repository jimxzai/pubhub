# 第一部：紛爭與十字架的智慧（1-4 章）——先對付根，不對付枝

## 精義

**教會分成四派，保羅沒有去調解四派，他問了一句：「基督是分開的嗎？」（1:13）——他不處理糾紛，他處理糾紛底下的東西。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 1:1-9 | 問安與感謝：他們「在恩賜上沒有一樣不及人的」 |
| 1:10-17 | 紛爭的實況：我是屬保羅的、屬亞波羅的…… |
| 1:18-2:5 | 十字架的道理與世人的智慧 |
| 2:6-16 | 神奧祕的智慧；屬靈人與屬血氣的人 |
| 3:1-23 | 屬肉體的證據；根基與工程；火的試驗 |
| 4:1-21 | 基督的執事；管家要有忠心；使徒的處境 |

## 深度探索

### 一、感謝在責備之前

1:4-9 是感謝，1:10 才開始責備。而感謝的內容是「你們在恩賜上沒有一樣不及人的」（1:7）。

\textcolor{ScriptureGold}{\textbf{這一句話讀完全書之後回頭看，是全卷最沉重的一句：一間甚麼恩賜都不缺的教會，幾乎每一件事都做錯了。}}

### 二、三種人

保羅在 2:14-3:3 分了三種人：

| 稱呼 | 特徵 | 經文 |
|----------------------------|----------------------------|----------------------------|
| 屬血氣的人 (ψυχικός) | 不領會神聖靈的事，反倒以為愚拙 | 2:14 |
| 屬靈的人 (πνευματικός) | 能看透萬事，有基督的心 | 2:15-16 |
| 屬肉體的人 (σαρκικός) | 是信徒，卻仍像嬰孩；證據是嫉妒紛爭 | 3:1-3 |

**第三種最扎人：他們是基督徒，卻活得像沒有信的人。**

### 三、根基與工程

3:11-15 分得很清楚：

- **根基**只有一個，是耶穌基督，已經立好了，不能換。
- **工程**是各人自己蓋的，材料分兩類：金、銀、寶石／草木、禾秸（3:12）。
- **火**要試驗每一個人的工程。
- **結局**：工程存得住的得賞賜；工程被燒了的受虧損，「自己卻要得救；雖然得救，乃像從火裏經過的一樣」（3:15）。

\textcolor{ScriptureGold}{\textbf{得救與賞賜是兩件事。一個人可以進天國，卻兩手空空。}}

### 四、管家只考一項

4:2「所求於管家的，是要他有忠心。」

不是有效、不是出色、不是成功——是**忠心**。而 4:5 說評分的時候還沒到：「時候未到，甚麼都不要論斷，只等主來……」

## 帶著走的問題

1. 我在教會裏那句「我是屬……的」，填的是甚麼？
2. 3:12 的兩類材料，我這一年蓋的最像哪一樣？

# 第二部：教會的紀律與身體的聖潔（5-7 章）——你們是重價買來的

## 精義

**保羅處理三件難堪的事：容讓淫亂、信徒彼此告狀、婚姻與獨身。三件事的結論都繫在同一句話上：「你們是重價買來的。」**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 5:1-13 | 容讓淫亂；一點麵酵；審判教內的人 |
| 6:1-11 | 弟兄彼此告狀；「你們中間也有人從前是這樣」 |
| 6:12-20 | 身體是聖靈的殿；重價買來的 |
| 7:1-40 | 論嫁娶、獨身、離婚、守住蒙召時的身分 |

## 深度探索

### 一、問題不只是那個人

5:2「你們還是自高自大，並不哀痛……」

**保羅責備的重點，不是那個犯罪的人，是整間教會對它無動於衷。**

而 5:5 交代了目的：「使他的靈魂在主耶穌的日子可以得救。」\textcolor{ScriptureGold}{\textbf{一切紀律若不指向恢復，就走錯了。}}

### 二、審判的界線

5:12-13：「因為審判教外的人與我何干？教內的人豈不是你們審判的嗎？至於外人有神審判他們。」

**這句話常被讀反：對外面的人嚴厲，對裏面的問題容讓。保羅說的正好相反。**

### 三、自由的兩把尺

6:12 引了哥林多人的口號「凡事我都可行」，保羅兩次頂回去：

| 口號 | 保羅的限制 |
|--------------------------------|------------------------------------------|
| 凡事我都可行 | 但不都有益處 |
| 凡事我都可行 | 但無論哪一件，我總不受它的轄制 |

\textcolor{ScriptureGold}{\textbf{自由的檢驗標準不是「可不可以」，是「誰在作主」。}}

### 四、「重價買來的」出現兩次

| 經文 | 上下文 | 結論 |
|--------------|------------------------|------------------------------------------|
| 6:20 | 論身體的聖潔 | 「要在你們的身子上榮耀神」 |
| 7:23 | 論作僕人與自主的 | 「不要作人的奴僕」 |

同一句話，一次反對放縱，一次反對受轄制。

### 五、第七章的重複句

7:17、20、24 三次說同一件事：**各人蒙召時是甚麼身分，仍要守住這身分。**

保羅在這一章反覆分辨「這是主說的」與「這是我說的」（7:10、12、25、40）——**他很小心地不把自己的判斷冒充成主的命令。**

## 帶著走的問題

1. 我有沒有一件「可以做」的事，其實已經在轄制我？
2. 我有沒有把「換一個處境」當成了「屬靈的長進」？

# 第三部：自由、良心與榜樣（8-10 章）——為別人放下權利

## 精義

**保羅同意哥林多人的知識是對的（偶像算不得甚麼），然後用整整三章告訴他們：對，不等於該。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 8:1-13 | 知識與愛心；軟弱弟兄的良心 |
| 9:1-27 | 保羅自己的例子：有權柄卻不用 |
| 10:1-13 | 以色列的鑑戒；試探中的出路 |
| 10:14-11:1 | 逃避拜偶像；凡事為榮耀神而行 |

## 深度探索

### 一、知識與愛心

8:1「知識是叫人自高自大，惟有愛心能造就人。」

然後 8:2-3 把句子轉了向：「若有人以為自己知道甚麼，按他所當知道的，他仍是不知道。若有人愛神，這人乃是**神所知道的**。」

\textcolor{ScriptureGold}{\textbf{重點不是你知道神，是神知道你。}}

### 二、第九章不是離題

很多人覺得第九章（保羅為自己的使徒權柄辯護）夾在祭偶像之物的討論中間很突兀。

**其實它是一個活的例子**：保羅有權靠福音養生（9:14），卻沒有用過（9:15），理由在 9:12：「免得基督的福音被阻隔。」

**他先講原則（第八章），再把自己擺出來作示範（第九章），然後回到原則（第十章）。**

### 三、曠野的五樣鑑戒

10:6-10 列出以色列人的五樣失敗：貪戀惡事（10:6）、拜偶像（10:7）、行姦淫（10:8）、試探主（10:9）、發怨言（10:10）。

而 10:1-4 先說：他們「都」受了洗、「都」吃了靈食、「都」喝了靈水——**四個「都」，然後 10:5 說「但他們中間多半是神不喜歡的人」。**

\textcolor{ScriptureGold}{\textbf{經歷過恩典，不等於走到終點。}}

### 四、出路的定義

10:13「必不叫你們受試探過於所能受的；在受試探的時候，總要給你們開一條出路，叫你們能忍受得住。」

**留意最後一句：出路不是「不必受試探」，是「能忍受得住」。**

而 10:12 與 10:13 是連著的：先是「自己以為站得穩的，須要謹慎」，才是那個應許。

## 帶著走的問題

1. 我最近一次用我懂的東西，是造就了人，還是壓過了人？
2. 我上一次的試探，那條出路在哪裏？我有沒有走上去？

# 第四部：聚會的次序與恩賜（11-14 章）——凡事都當造就人

## 精義

**四章講聚會，一把尺量到底：造就（οἰκοδομή）。而第十三章夾在中間，是這把尺的來源。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 11:1-16 | 蒙頭的次序 |
| 11:17-34 | 主餐的混亂；分辨主的身體 |
| 12:1-31 | 恩賜的多樣；一個身體許多肢體 |
| 13:1-13 | 愛：最妙的道 |
| 14:1-40 | 方言與先知講道；凡事規規矩矩按次序 |

## 深度探索

### 一、主餐的問題不在儀式

11:20-21：「你們聚會的時候，算不得吃主的晚餐……因為吃的時候，各人先吃自己的飯，甚至這個飢餓，那個酒醉。」

問題是**富人先吃，窮人挨餓**。所以 11:29 的「分辨是主的身體」有雙重意思：**分辨那餅所代表的主的身體，也分辨在座的這一群人就是主的身體。**

### 二、主餐看三個方向

11:26「你們每逢吃這餅，喝這杯，是表明主的死，直等到他來。」

```
回頭看 ─────── 環顧 ─────── 抬頭看
十字架         這個身體      祂再來
```

### 三、神偏袒弱的那一邊

12:23-24：「身上肢體，我們看為不體面的，越發給它加上體面……但神配搭這身子，把加倍的體面給那有缺欠的肢體……」

\textcolor{ScriptureGold}{\textbf{保羅不是勸強的忍耐弱的。他說是神自己把加倍的體面給了有缺欠的那一邊。}}

### 四、十三章的位置

```
第十二章  恩賜的多樣    →  身體只有一個
第十三章  愛            →  沒有愛，恩賜一樣也不算
第十四章  恩賜的次序    →  凡事都當造就人
```

13:1-3 的三個「若……卻沒有愛」，講的正是十二、十四章那些恩賜：方言、先知講道、知識、信心、捨己。

而 13:4-7 的十五個動詞裏，**有八個是否定式**——愛的一大半，是不做某些事。

### 五、五句對一萬句

14:19「但在教會中，寧可用悟性說五句教導人的話，強如說萬句方言。」

比例是兩千比一。**保羅不反對方言（14:5、18、39），他反對聽不懂的敬拜。**

而 14:24-25 給了衡量標準：一個不信的人進來，「他心裏的隱情顯露出來，就必將臉伏地，敬拜神，說：『神真是在你們中間了。』」

## 帶著走的問題

1. 我上一次領主餐，心裏在想甚麼？
2. 如果一個完全不懂信仰的人今天來我們的聚會，他會帶走甚麼？

# 第五部：復活的盼望與收尾（15-16 章）——地基與行程

## 精義

**保羅把復活放在最後，不是因為它最不重要，是因為它托住前面的一切。而全章的結尾不是抒情，是一個非常實際的命令。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 15:1-11 | 福音的內容：死了、埋葬了、復活了、顯現了 |
| 15:12-19 | 若沒有復活，會怎樣 |
| 15:20-34 | 初熟的果子；末後的仇敵是死 |
| 15:35-49 | 復活的身體：血氣的與靈性的 |
| 15:50-58 | 死被得勝吞滅；所以務要堅固 |
| 16:1-24 | 捐項、行程、同工、問安；主必要來 |

## 深度探索

### 一、「最要緊的」

15:3-4：「我當日所領受又傳給你們的：第一，就是基督照聖經所說，為我們的罪死了，而且埋葬了；又照聖經所說，第三天復活了……」

這幾句被公認是新約中最早的信仰告白之一——**保羅說是「領受」的，不是他寫的。**

### 二、五個「若」

15:13-19 用一連串假設推到底：

| 若…… | 結果 |
|------------------------------------------|------------------------------------------|
| 15:13 若沒有死人復活的事 | 基督也就沒有復活了 |
| 15:14 若基督沒有復活 | 所傳的、所信的都是枉然；我們還成了為神妄作見證的（15:15） |
| 15:16 死人若不復活 | 基督也就沒有復活了 |
| 15:17 基督若沒有復活 | 你們的信便是徒然，仍在罪裏；睡了的人也滅亡了（15:18） |
| 15:19 若靠基督只在今生有指望 | 就算比眾人更可憐 |

五個「若」一路推到底。**留意最後一個：復活若是假的，基督徒不只是白信一場，是比不信的人更可憐。**

### 三、初熟的果子

15:20「但基督已經從死裏復活，成為睡了之人初熟的果子。」

利未記 23:10-11 的初熟節，是收割的第一捆——**它證明後面還有一整片田。祂的復活不是孤例，是頭一個。**

### 四、結論是一個命令

15:58：「所以，我親愛的弟兄們，你們務要堅固，不可搖動，常常竭力多做主工；因為知道，你們的勞苦在主裏面不是徒然的。」

\textcolor{ScriptureGold}{\textbf{整章關於復活的論證，落在一個非常實際的地方：不要放棄你手上那件看不見成果的工。}}

### 五、最後一句是亞蘭文

16:22「主必要來！」——μαράνα θά（Marana tha）。

**保羅原封不動地把這句亞蘭文留在希臘文書信裏。那是最早期教會的呼喊，比新約成書更早。**

## 帶著走的問題

1. 如果只有今生，我現在做的哪些事就沒有意義了？
2. 我手上那件看不見成果的服事，15:58 對它說了甚麼？

| 15:22 在亞當裏眾人都死了 | 羅 5:12-21 兩個亞當 |

| 哥林多前書 | 啟示錄 |

# 全書的句號

十六章，十來類問題，一把尺。

而全書最後一句呼喊，是最早期教會的原話——不是保羅寫的，是他們喊的：

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 主必要來！}}\end{center}

## 附：本卷貫穿的幾句話

> **關於恩賜**：一間甚麼恩賜都不缺的教會，可以幾乎每一件事都做錯。恩賜證明不了甚麼。

> **關於自由**：檢驗標準不是「可不可以」，是「誰在作主」。
