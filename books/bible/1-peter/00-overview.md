# 彼得前書概覽 (1 Peter Overview)

## 書卷簡介

| 項目 | 內容 |
|------|------|
| **作者** | 使徒彼得（1:1），由西拉代筆（5:12） |
| **日期** | 約主後 62-64 年（尼祿逼迫加劇之前） |
| **寫作地點** | 「巴比倫」（5:13）——初代教會傳統普遍理解為羅馬的暗語 |
| **收信人** | 本都、加拉太、加帕多家、亞西亞、庇推尼（今土耳其境內）分散寄居的信徒 |
| **章數** | 5 章 |
| **性質** | 一般書信（大公書信之一），寫給散居各地的教會 |

## 本書的卷次架構 (How This Book Is Built)

本書分為**卷首三章 + 正文三卷（五章） + 卷末一章**。卷首先立座標與骨幹，再進正文；卷末把彼得前書接進彼得後書。

### 卷首 · 定位（讀正文之前先讀）

| 序 | 章 | 作用 |
|----|------|------|
| 1 | 概覽（本章） | **地圖**：結構、身分稱號、鑰詞 |
| 2 | **客旅之家——彼得前書站在哪裏** | **座標**：這卷書在正典、在彼得自己的生命裏站在哪 |
| 3 | **「先受苦，後得榮耀」——全書的骨幹** | **骨幹**：這個節奏怎樣貫穿全信 |
| 4 | 全書領受總綱（查經領受） | **方法**：按結構逐部深讀 |

### 正文 · 三卷（五章）

| 卷 | 章節 | 主題 | 配詩 |
|----|------|------|------|
| **卷一** | 1-2章 | **蒙揀選的身分**：活潑的盼望、君尊的祭司 | 詩篇103, 118 |
| **卷二** | 3-4章 | **客旅在世的品行**：為義受苦、火煉的試驗 | 詩篇34, 66 |
| **卷三** | 5章 | **牧養與儆醒**：牧養群羊，直到牧長顯現 | 詩篇23 |

**比例即信息**：五章之中，彼得用了整整兩章（3-4章）正面處理苦難——**這封信的重心不在教義體系，在牧養一群正在受苦的人。**

### 卷末 · 望向那一頭

| 序 | 章 | 作用 |
|----|------|------|
| 末 | **脫下帳棚的日子近了** | 把彼得前書接進彼得後書 |

**為甚麼要有卷末？** 因為彼得前書自己不完全收尾——5:10「必要親自成全你們」的應許，彼得寫下時自己還沒有活著看見完全應驗；他不久後也要走上同一條為義受苦的路（彼後1:13-14）。

## 地理與歷史背景

### 收信的五個行省

```
彼得前書1:1 收信地圖（小亞細亞，今土耳其）

              黑海 (Black Sea)
         ┌─────────────────────────┐
         │ 庇推尼      本都          │
         │ BITHYNIA    PONTUS       │
         │        ┌─────────┐       │
         │ 亞西亞  │加拉太   │加帕多家│
         │  ASIA   │GALATIA │CAPPADOCIA│
         └─────────┴─────────┴───────┘
                地 中 海 (Mediterranean)
```

信封上列出的五個羅馬行省，幾乎覆蓋了整個小亞細亞——這封信很可能是一封「巡迴信」，由送信人依序帶到每一站，朗讀後再往下一站傳遞。

### 五旬節的種子

值得留意：這五個行省裏，有三個（加帕多家、本都、亞西亞）早在五旬節那天，就已經有出身當地的猶太僑民在耶路撒冷聽見福音：

> 「我們帕提亞人、瑪代人、以攔人，和住在米所波大米、猶太、**加帕多家**、**本都**、**亞西亞**……的人……都聽見他們用我們的鄉談，講說神的大作為。」
> — 使徒行傳 2:9-11

**彼得三十年前在五旬節那天親口向這些地方的猶太僑民傳講基督復活（徒2:14-40）；三十年後，他寫信給的很可能正是那批人回鄉後建立、如今已擴展到外邦人的教會。**彼得前書不是寫給陌生人的信，是寫給他自己曾經親口撒種之地的收成。

### 寫作處境：尼祿逼迫的前夕

主後 64 年 7 月，羅馬大火之後，尼祿嫁禍基督徒，展開帝國史上第一波官方主導的逼迫（塔西佗《編年史》15.44 記載此事，是現存最早的羅馬史料對基督徒逼迫的記述）。彼得前書的寫作日期一般定於主後 62-64 年之間——**信中所描寫的敵意（毀謗、被人以為怪、被排斥）看來還是地方性、社會性的敵視，尚未升級為帝國全面的官方逼迫**，但那場更猛烈的風暴，很可能就在彼得寫信之後不久來臨。教會傳統（優西比烏《教會史》2.25，轉引俄利根）記載彼得本人不久後也在羅馬殉道。這封信，很可能是一位即將殉道的使徒，寫給即將面對更大逼迫的教會，教他們預先學會怎樣站立。

## 名家注疏 (Commentary Insights)

> **體例說明**：以下為對麥克阿瑟（John MacArthur, gty.org）一貫解經立場與已知重點的一般性、綜合性歸納，非逐篇逐字引句；各章「歷代注疏」小節將視個別引句是否經查證，分別標明「已核實逐字引句」或「一般性歸納轉述」，詳見附錄〈參考資料〉之逐章說明。

### 約翰·麥克阿瑟 (John MacArthur)

麥克阿瑟一貫指出：彼得前書回答的核心問題，是基督徒該如何面對敵意與不義的苦難——不是逃避，不是苦毒還擊，而是效法基督的榜樣，把自己交託給那位公義審判人的主。他常把彼得前後書對照著看：**彼得前書是為幫助受苦的基督徒而寫，彼得後書是為揭露假教師而寫**——前者面對的是外來的逼迫，後者面對的是內部的腐蝕。麥克阿瑟特別強調4:12-19「火煉的試驗」一段，將受苦分成四個步驟：**預期它**（不要以為奇怪）、**在其中歡喜**（有分於基督的苦難）、**查驗其因**（為義受苦，非為惡受苦）、**交託自己**（將靈魂交於那信實的造化之主）。

## 彼得前書特色 (Distinctive Features)

### 1. 苦難的功課紮根於基督論

彼得前書談苦難的密度居新約書信之冠（見上表），但它從不把苦難孤立成一個獨立主題——每一段受苦的勸勉，最終都指向那位「為你們受過苦，給你們留下榜樣」的基督（2:21）。詳見卷首〈骨幹〉一章「先受苦，後得榮耀」的完整鋪陳。

### 2. 身份的功課：從「算不得子民」到「神的子民」

2:9-10集中了全信最密集的一串身分稱號：

| 稱號 | 經文 | 舊約根源 |
|------|------|----------|
| 被揀選的族類 | 2:9 | 申7:6 |
| 君尊的祭司 | 2:9 | 出19:6 |
| 聖潔的國度 | 2:9 | 出19:6 |
| 屬神的子民 | 2:9-10 | 何2:23 |
| 寄居的客旅 | 1:1, 2:11 | 創23:4（亞伯拉罕自稱「寄居的」） |

### 3. 基督論的完整弧線

- 基督的預知與顯現（1:20）
- 基督寶血的救贖，如同無瑕疵的羔羊（1:18-19）
- 基督為罪受苦，留下榜樣（2:21-24, 3:18）
- 基督藉復活得勝，升天在神右邊（3:21-22）
- 基督榮耀顯現，牧長頒賜冠冕（1:7, 4:13, 5:4）
