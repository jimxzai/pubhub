## 附錄二：主題索引 (Key Themes Index)

| 主題 | 簡述 | 主要章節 |
|------|------|----------|
| 活潑的盼望 | 盼望的根基是基督已經復活的歷史事實，非心理狀態或樂觀猜測 | 01 |
| 先受苦，後得榮耀 | 全信骨幹——1:11基督身上宣告、4:13信徒身上應用、5:1, 10長老與教會身上總結 | 00c、01、02、03、04、05 |
| 客旅、寄居的身分 | 信徒在世卻不屬世的雙重身分，貫穿全信的自我定位 | 00a、01、02 |
| 活石與靈宮 | 基督是活石，信徒被建造成靈宮，作聖潔的祭司 | 02 |
| 四個身分稱號 | 被揀選的族類、君尊的祭司、聖潔的國度、屬神的子民——引自出19:6等舊約經文 | 02 |
| 家庭準則（Haustafeln） | 順服掌權者、僕人順服主人、妻子順服丈夫、丈夫敬重妻子——貫穿2-3章 | 02、03 |
| 基督受苦的榜樣（以賽亞書53章的活化） | 基督的受苦既是代贖，也是可描摹的榜樣（*hypogrammon*） | 02、03 |
| 為義受苦是有福的 | 呼應登山寶訓，苦難若因行善而受，蒙神悅納 | 02、03、04 |
| 心中盼望的緣由 | 護教學的根基經文——常做準備，以溫柔敬畏的心回答 | 03 |
| 傳道給監獄裏的靈（解經難題） | 全信解經爭議最大的一段，本書誠實呈現多種歷代立場，不強行定論 | 03 |
| 火煉的試驗 | 苦難如熬煉信心的火，貫穿1章與4章 | 01、04 |
| 恩賜與管家職分 | 各人照所得的恩賜彼此服侍，作神百般恩賜的好管家 | 04 |
| 審判從神的家起首 | 教會經歷的試煉是管教與煉淨，非定罪；與拒絕福音者的終極審判性質不同 | 04 |
| 造化之主 | 全信僅有一次的稱呼——把神當作創造者、非僅拯救者來信靠 | 04 |
| 牧養：不轄制，乃作榜樣 | 長老牧養群羊的三重對照——甘心非勉強、樂意非貪財、榜樣非轄制 | 05 |
| 將憂慮卸給神 | 卸下憂慮的根基是「祂顧念你們」，非單純的心理技巧 | 05 |
| 抵擋吼叫的獅子 | 儆醒謹守，用堅固的信心抵擋仇敵，且知道普世弟兄也在同樣的苦難中 | 05 |
| 稱義·成聖·得榮 三階段框架（老弟兄） | 1:3-5, 18-19（稱義）、1:14-16與2-4章（成聖）、1:5, 7, 13與4-5章（得榮）——本信「得榮」份量尤重 | 00c、01 |
| 揀選：首尾呼應 | 1:1「被揀選」與5:13「同蒙揀選」——全信以同一字根繫住首尾 | 00c、05 |
| 順服（ὑποτάσσω）貫穿全信 | 對掌權者、僕人對主人、妻子對丈夫、天使對基督、年幼對年長——五種關係共用同一動詞 | 00c、02、03、05 |
