## 一、John MacArthur

各章「歷代注疏 · 當代釋經」及「三大資源深度整合」小節均以「麥克阿瑟指出／認為／一貫強調」的方式轉述其一貫解經立場，未附具體講題、日期或 gty.org 網址，故不宜視為逐字引句。各章論及主題如下：

| 出現章 | 論及經文／主題 |
|------|------|
| 00（overview） | 彼得前書回答的核心問題：基督徒應當如何面對敵意；彼得前後書的對照（前書為受苦的基督徒而寫，後書為揭露假教師而寫）；4:12-19火煉試驗的四步驟框架（預期、歡喜、查驗其因、交託） |
| 01 | 「活潑的盼望」是全信的鑰匙；信心與試煉真確性之間的因果關係 |
| 02 | 2:21「留下榜樣」(*hypogrammon*) 原意是習字底本；2:23「交託那按公義審判人的主」是忍受不義之苦的內心錨點 |
| 03 | 3:15「常做準備」內容準確與態度溫柔缺一不可；3:18-22雖是解經難題，落點清楚指向3:22基督至高的權柄 |
| 04 | 4:12-19苦難四步驟框架（同00-overview）；4:19「造化之主」稱呼的獨特份量 |
| 05 | 5:8「吼叫的獅子」意象的真實迫切性；5:10四個動詞（成全、堅固、賜力量、堅立）疊加顯明神工作的徹底 |

未見任何一章附具體 gty.org 講題連結或講道日期，全書一律以一般性歸納轉述處理，如實記錄。

## 二、John Calvin

各章均以「加爾文一貫強調／指出」轉述其對彼得前書《大公書信註釋》（The Catholic Epistles，收錄彼得前後書、約翰一二三書、雅各書、猶大書；英譯者 John Owen，Calvin Translation Society 版）一貫解經立場的綜合歸納，未附具體卷冊頁碼：

| 出現章 | 論及經文／主題 |
|------|------|
| 01 | 1:3「重生」而非單單「赦罪」——救恩是生命性質的全新開始；1:7「信心被試驗」是煉淨雜質而非懷疑真偽 |
| 02 | 2:9「君尊的祭司」是「信徒皆祭司」教義的核心根據；2:24「因他受的鞭傷」清楚證明基督受苦具代贖性質 |
| 03 | 3:15「常做準備」是「認識的信心」(*fides cognita*) 不可或缺的根據；3:21反對把水禮本身當作自動生效的赦罪媒介 |
| 04 | 4:1「與罪斷絕」是方向性的轉變，非此生完全無罪；4:17「審判從神的家起首」顯明神管教百姓的嚴謹認真 |
| 05 | 5:2-3「不轄制、乃作榜樣」是反對神職體系過度集權的聖經根據；5:7「將憂慮卸給神」的力量全繫於「祂顧念你們」這個事實 |

## 三、Augustine（僅第三章）

3:19-20「傳道給監獄裡的靈」一節，本書列出奧古斯丁在其書信（如《致埃萬吉勒書》Epistle 164）中一貫傾向的立場——基督的靈藉挪亞、在方舟預備期間向當時活著卻不信的世人傳講悔改的信息，而非基督死後親自向已故之人傳道。此為一般性歸納轉述，非逐字引句，未附卷冊頁碼。本書在同一節誠實列出歷代解經三種主要立場（見03章「背景」小節），不強行選定單一立場為定論。

## 四、G. Campbell Morgan——誠實的空白

**本書與羅馬書、提摩太前書附錄最大的不同，在此必須鄭重聲明**：01、02、03、04、05 各章「三大資源深度整合」小節，凡涉及摩根的段落，均**明確附有誠實說明**，坦承截至寫作查證所及，**未能定位摩根一部可逐篇核對之彼得前書專著或講章集**——摩根確曾寫作涵蓋多卷書信的《活的信息》(*Living Messages of the Books of the Bible*) 系列及其他著作，但本書寫作團隊未能找到其中專門、逐節處理彼得前書的獨立篇章可供核校。

因此，01-05 章「摩根深讀」小節的內容，性質上是**「依摩根一貫解經取向所作的推想性整理」**，而非「對其已發表著作內容的歸納轉述」——這是比「一般性歸納轉述」更謹慎的一個層級，各章均以粗體或引用區塊明確標示此點，讀者不宜將這些段落誤認為摩根本人已發表的立場。

**與此對照的重要提醒**：本書 00-overview.md 現存版本中，仍保留舊版（2025年12月初版）遺留的兩句摩根引句——論2:9「君尊祭司」與論2:7「寶貴」的引句，標明出處為《The Letters of Peter》。經本次改版查證，**未能確認此書名為摩根真實出版著作的準確書名**，此二句引文的可信度應被視為**未經核實**，讀者引用時宜格外謹慎，不應視為與其他已標明「已核實」之引句同等可靠。本附錄如實揭露這項落差，作為對讀者的誠實交代，而非掩蓋或逕行刪除。

本書寫作前已查證，老弟兄原始查經筆記中**沒有任何一則以彼得前書為主題的記載**。因此，全書五章「老弟兄查經洞見」與「老弟兄查經 · 深讀」小節的一切內容，**沒有一章**是對某年某月某日原始筆記的逐字引用或核實轉錄；**全部**是以老弟兄一貫的查經方法論與神學框架——救恩三階段（稱義／成聖／得榮）、六層次讀經法（念、找、問、連、住、行）、提問式帶領（先問、再問、追問、落到自己）、以整本聖經為根基、以認識耶穌基督為中心——忠實應用於彼得前書各章經文而成。
