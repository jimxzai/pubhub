# 約翰一書在整本聖經裏的位置 (Where 1 John Stands) {.unnumbered}

## 一、誰寫的：一封沒有署名的信

約翰一書沒有問安、沒有署名、沒有收信人的名字，也沒有結尾的問候。它比較像一篇寫下來的講道，或一位牧人給一群熟悉的會眾的長信。作者是誰，要從兩方面看。

**信裏的證據。**作者以親眼見證人的身分說話：「就是我們所聽見、所看見、親眼看過、親手摸過的」（1:1）。他稱讀者為「小子們」，用一個年長屬靈父親的口吻。他的用字和約翰福音極其接近：生命、光、真理、住、從神生、獨生子、作見證、新命令。兩卷書的寫作目的句幾乎是同一個句型（約20:31；約壹5:13）。

**教會早期的見證。**最早引用這封信的人，離約翰非常近：

- **坡旅甲**（約主後 69-155，傳統上說他是約翰的門徒）在〈致腓立比人書〉第七章寫道：凡不承認耶穌基督是成了肉身來的，就是敵基督——這是約壹 4:2-3 的話。
- **帕皮亞**（二世紀初，希拉波立的監督）據優西比烏記載，曾「引用約翰第一書信的見證」（優西比烏《教會史》3.39.16，NPNF 分段；希臘文本作 3.39.17）。
- **愛任紐**（約主後 130-202，坡旅甲的學生）明說「他（約翰）在他的書信中這樣向我們作見證」，接著引約壹 2:18-19 論敵基督的話（《駁異端》3.16.5）。

加爾文大公書信註釋的英譯者歐文（John Owen，十九世紀加爾文譯本學會的譯者，不是清教徒歐文）在譯者序言裏也說，約翰一書從起初就一致被接納為神啟示的一部分（見附錄〈引用出處總表〉）。本書按教會一貫的認定，以使徒約翰為作者。

## 二、寫給誰、為甚麼寫

信中透露的處境很具體：

1. **有人離開了。**「他們從我們中間出去，卻不是屬我們的」（2:19）。這不是外來的逼迫，是從教會裏面分裂出去的一群人。
2. **他們否認道成肉身。**「凡靈不認耶穌，就不是出於神」（4:3）；真信仰的記號是「認耶穌基督是成了肉身來的」（4:2）。他們也否認「耶穌為基督」（2:22）——把「耶穌」這個人和「基督」分開。
3. **他們自稱屬靈，卻不在乎罪。**約翰引了三句「我們若說」（1:6、8、10）和三句「人若說」（2:4、6、9），這些話很可能就是假教師的口號：我們與神相交、我們無罪、我們認識神。
4. **留下來的人被攪擾。**「我將這些話寫給你們，是指著那引誘你們的人說的」（2:26）。他們開始懷疑：我們真有永生嗎？

二世紀的愛任紐記載，與約翰同時代、同在亞細亞的克林妥教導：耶穌本是約瑟和馬利亞按常例所生；受洗後「基督」降在他身上，受難前又離開，所以受苦的只是耶穌（《駁異端》1.26.1；他與約翰同在以弗所一事，見 3.3.4）。約翰一書沒有點名任何人，我們不能說全書只針對克林妥；但書中所反駁的，正是這一類把耶穌與基督拆開、把靈與肉身拆開、把認識神與順服神拆開的教訓。學者常把它們統稱為「早期的諾斯底傾向」。這是後世的歸類，約翰自己沒有用這個名字。

約翰自己說出寫信的四個目的（2:26 說的是「指著誰」寫，可與 5:13 的確據並看）：

| 經文 | 目的 |
|-----------|-------------------------------------------------------------------------------|
| 1:4 | 「使你們的喜樂充足」 |
| 2:1 | 「是要叫你們不犯罪」 |
| 2:26 | 「是指著那引誘你們的人說的」 |
| 5:13 | 「要叫你們知道自己有永生」 |

麥克阿瑟把它們收成三樣：喜樂、聖潔、確據（見第1章）。

## 三、約翰的三卷書：過去、現在、將來

老弟兄講約翰的著作時，把約翰福音、約翰一書、啟示錄排成一條線（週四查經班講義〈漸進啟示與救贖歷史〉）：

| | 約翰福音 | 約翰一書 | 啟示錄 |
|----|---------------------|--------------------------------------|---------------------------|
| 主題 | 道成肉身 | 道住在我們中 | 道榮耀再來 |
| 時態 | 回顧 | 現在 | 前瞻 |
| 鑰節 | 「道成了肉身」（約1:14） | 「住在愛裏面的，就是住在神裏面」（約壹4:16） | 「是了，我必快來！」（啟22:20） |
| 落點 | 信心的根基 | 愛的生活 | 盼望的實現 |

約翰一書站在中間。它回頭看福音書：那位成了肉身的道，我們摸過。它往前看啟示錄：「主若顯現，我們必要像他，因為必得見他的真體」（3:2）。它最在乎的是現在：那升天的主，今天怎樣住在祂的子民中間？答案是聖靈（3:24；4:13），是祂的道（2:14），是彼此相愛（4:12）。

## 四、在整本聖經的大線上

約翰一書的幾個大字，在整本聖經裏都有一條長線：

- **光。**從「神說：『要有光』，就有了光」（創1:3），到「神就是光」（約壹1:5），到新耶路撒冷「不用日月光照；因有神的榮耀光照，又有羔羊為城的燈」（啟21:23）。
- **生命。**從伊甸園的生命樹，到「生命在他裏頭」（約1:4），到「人有了神的兒子就有生命」（約壹5:12），到啟示錄末了的生命水與生命樹（啟22:1-2）。
- **愛弟兄。**從人類第一次恨弟兄，就是殺人（創4；約壹3:12、15），到主在最後晚餐說「我賜給你們一條新命令，乃是叫你們彼此相愛」（約13:34），到約翰說這是「從起初所聽見的命令」（3:11）。
- **見證。**從申命記「要憑兩三個人的口作見證」的律例，到約翰福音眾多為子作的見證，到約翰一書「作見證的原來有三」（5:8）與「神為他兒子作的見證」（5:9-10）。

## 五、它和約翰福音的對照

| 約翰福音 | 約翰一書 |
|-------------------------------------------|-----------------------------------------------|
| 太初有道（1:1） | 從起初原有的生命之道（1:1） |
| 生命就是人的光（1:4） | 神就是光（1:5） |
| 我賜給你們一條新命令（13:34） | 舊命令……也是新命令（2:7-8） |
| 你們要常在我裏面（15:4） | 你們要住在主裏面（2:28） |
| 保惠師（14:16） | 中保（2:1；同一個字 `{\greekfont παράκλητος}`{=latex}） |
| 有血和水流出來（19:34） | 藉著水和血而來的（5:6；兩處是否相關，見第6章） |
| 叫你們信（20:31） | 叫你們知道（5:13） |

約翰福音是「信」的書，約翰一書是「知道」的書。福音書寫神的兒子把永生帶到世上；書信寫這永生在神的兒女身上怎樣看得出來。

## 六、讀這卷書要避開的兩個誤區

**第一，把試驗讀成考卷。**約翰一書的試驗不是要叫軟弱的信徒失去把握。3:19-20 說：「從此就知道我們是屬真理的，並且我們的心在神面前可以安穩。我們的心若責備我們，神比我們的心大，一切事沒有不知道的。」試驗是用來揭穿假教師，也用來堅固真信徒。

**第二，把「神就是愛」讀成多愁善感。**約翰定義愛，不從人的感覺出發，而從十字架出發：「不是我們愛神，乃是神愛我們，差他的兒子為我們的罪作了挽回祭，這就是愛了」（4:10）。同一卷書說「神就是光」，也說「神就是愛」；光與愛在神裏面從不衝突。
