# 腓立比書概覽 (Philippians Overview)

## 書卷簡介

**作者**：使徒保羅，與提摩太同名問安（1:1）
**寫作日期**：約主後 60-62 年
**寫作地點**：羅馬，第一次被囚期間（1:13「御營全軍」；4:22「該撒家裏的人」）
**收信人**：腓立比教會——保羅在歐洲建立的第一間教會（徒 16:11-15）
**主題**：因基督而有的喜樂，即使在捆鎖與逼迫中；以基督的心為心

### 寫作處境與目的

保羅寫這封信，直接的原因是感謝腓立比教會差以巴弗提送來的餽送（4:10-18），並打發以巴弗提回去報平安（2:25-30；以巴弗提病重幾乎至死，2:27）。但這封「感謝信」寫著寫著，展開成一封論喜樂、論合一、論基督、論竭力追求的完整書信——這正是全書的特色：**最個人、最不帶防衛姿態的一封保羅書信**，沒有像加拉太書那樣要糾正異端，也沒有像哥林多前後書那樣要處理教會紛爭，通篇只是一位在監獄裏、隨時可能殉道的使徒，寫給他所愛、也愛他的教會。

## 核心經文 (Key Verse)

> 因我活著就是基督，我死了就有益處。
> — 腓立比書 1:21（和合本 CUV）

> For to me, to live is Christ and to die is gain.
> — Philippians 1:21 (NASB)

這節經文濃縮了全書的原則：保羅的生與死，都只有一個定義——基督。全書後面三章展開的目的（2:5-11 基督的心）、竭力向前（3:12-14 標竿）、追求（4:8-9 思念這些事），都是這一句話在不同處境下的延伸。**詳見卷首〈全書的骨幹〉一章。**

## 書卷特色 (Distinctive Features)

### 喜樂的書信

「喜樂」與「歡喜」（χαρά, χαίρω）在全書出現超過十次，密度為保羅書信之最：

| 經文 | 內容 |
|------|------|
| 1:4 | 歡歡喜喜地祈求 |
| 1:18 | 無論怎樣，基督被傳開，我就歡喜 |
| 1:25 | 使你們在所信的道上又長進又喜樂 |
| 2:2 | 使我的喜樂可以滿足 |
| 2:17-18 | 即使澆奠，也是喜樂，且要同喜樂 |
| 2:28-29 | 叫你們喜樂 |
| 3:1 | 你們要靠主喜樂 |
| 4:1 | 你們就是我的喜樂 |
| 4:4 | 你們要靠主常常喜樂——再說一次要喜樂 |
| 4:10 | 我靠主大大地喜樂 |

**這封信的處境和它的語氣形成鮮明對比**：寫信的人在羅馬的鎖鏈之中（1:7,13-14），隨時可能被判死刑（1:20-23），卻是新約書信裏「喜樂」密度最高的一卷。這個張力本身就是全書要傳講的信息——喜樂的根基不在環境，在1:21 那句話。

### 全書的骨幹——「存這樣的心思」

φρονέω（phroneō，存心思、定心意）在全書四章裏出現十次（1:7；2:2 兩次；2:5；3:15 兩次；3:19；4:2；4:10 兩次），從原則、目的、竭力向前，一路展開到追求——**這是「人的軌跡」，全書最重要的一條線索。** 與這條線並行的，還有一條「神的次序」：πνεῦμα（聖靈）在前三章各出現一次（1:19供應、2:1聯合、3:3分辨），到第四章隱去不再點名——保羅的心思展開到哪裏，聖靈的工作就先行到哪裏。逐處經文的字族普查、四步結構的完整論證、聖靈次序的逐節核對、與歌羅西書「思念上面的事」的對照，全部集中在卷首〈全書的骨幹〉一章，本節只作提示。

### 基督頌 (2:6-11)——早期教會的讚美詩

腓立比書 2:6-11 被歷代學者公認為新約裏最早、最完整的基督論詩歌之一，結構工整地分為降卑與升高兩段：

| 階段 | 經文 | 內容 |
|------|------|------|
| **降卑** | 2:6-8 | 本有神的形像 → 不以與神同等為強奪的 → 反倒虛己 → 取了奴僕的形像 → 成為人的樣式 → 自己卑微 → 存心順服，以至於死，且死在十字架上 |
| **升高** | 2:9-11 | 神將他升為至高 → 賜給他超乎萬名之上的名 → 萬膝跪拜 → 萬口承認耶穌基督為主，歸榮耀給父神 |

**詳細的原文研讀（μορφή, ἁρπαγμός, ἐκένωσεν）與歷代注疏，見第二章。**

## 使徒行傳對照 (Correspondence with Acts)

腓立比教會的建立記載於使徒行傳16章，這段歷史直接解釋了書信裏的好幾處細節：

| 使徒行傳 | 事件 | 與書信的關聯 |
|----------|------|--------------|
| 徒 16:6-10 | 馬其頓的呼聲 | 福音第一次進入歐洲 |
| 徒 16:11-15 | 呂底亞信主 | 4:2-3 提到的婦女同工，很可能延續呂底亞一類的骨幹信徒 |
| 徒 16:16-18 | 趕出使女身上的鬼 | 保羅在腓立比首次因傳福音而下監的直接原因 |
| 徒 16:19-34 | 保羅、西拉下監，禁卒信主 | 1:13「御營全軍」呼應保羅對囚禁處境的一貫熟悉 |
| 徒 16:35-40 | 保羅表明羅馬公民身份 | 3:20「我們卻是天上的國民」——腓立比是羅馬殖民地，居民以羅馬公民權為榮，保羅借此對比 |
| 徒 20:1-6 | 保羅再訪腓立比 | 教會持續與保羅同工的憑據 |

## 城市背景 (The City of Philippi)

腓立比因馬其頓王腓力二世（亞歷山大大帝之父）命名，主前42年屋大維（後為奧古斯都）在此擊敗布魯圖斯與加西烏，其後成為羅馬殖民地，居民享有羅馬公民權——這正是3:20「我們卻是天上的國民」一句話最貼身的背景：**腓立比人以身為羅馬公民、效忠遠方的羅馬為榮，保羅提醒他們，基督徒真正效忠的國籍在天上。**
