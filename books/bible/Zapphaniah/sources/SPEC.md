# 西番雅書研讀 — 章節撰寫規格（給每位撰寫者；2026-10-31）

先讀：`sources/PLAN.md`（骨幹、單元、已核事實——**數字與詞形以它為準**）、本檔、範例章 `01-i-will-sweep-away-everything.md`（**完整讀一遍，照它的體例**）。
體例＝約翰福音 11 節章節模板。你只寫**分到的章**，不改其他檔、不改範例章、不 commit。

## 一、檔案骨架（11 個 `## `，順序固定，與範例章逐項同構）

YAML 七行（與範例章逐字相同）→ `# 章題 (English Title)` → 參照行（`西番雅書 a:b-c:d`）→ `**經文核對**：[ai-eden.com/bible/zephaniah/N](https://www.ai-eden.com/bible/zephaniah/N?t=CUV,NASB&cols=2)` →
`## 基督焦點` · `## 配詩 (Opening Hymn)` · `@@SCRIPTURE a:b-c:d@@`（單獨一行，代表 `## 經文`）· `## 背景` · `## 原文研讀` · `## 領受要點` · `## 歷代注疏` · `## 詩篇與聖詩` · `## 老弟兄查經` · `## 生命應用` · `## 與其他經文的關聯` · 結尾斜體一行。
**H1 不加真實章節範圍**。`---` 前後必須有空行（否則被 pandoc 吞成 Setext 標題）。

`@@SCRIPTURE a:b-c:d@@` 由 `python3 books/bible/Zapphaniah/sources/scripture/inject_scripture.py <章檔>` 展開成 CUV＋NASB 1995 經文區塊——**你不手打任何經文區塊**；寫完章檔後自己跑一次，確認展開成功（章檔會被改寫，這是預期）。2:1-2 在和合本是併節（2:2 只是佔位字 "a"），腳本會自動印成 `^1-2^`。

**配詩**：由主線統一處理。你的章裏，「配詩」小節只寫一行標記 `@@HYMN NN@@`（NN＝單元序，兩位數，如 `@@HYMN 02@@`）；「詩篇與聖詩」小節裏的聖詩部分也只寫一行標記 `@@HYMNNOTE NN@@`。**不要自己抄歌詞、不要寫聖詩說明**——主線會在全部章節交卷後，依 `sources/hymns/NN-*.txt` 統一展開。詩篇部分（一至二篇，逐字 CUV）仍由你寫。

## 二、基督焦點（必備）

`> **本章鑰詞：<原文> 「中譯」（出處）** \` + `> **全書座標**：啟示的次序·第 N 步——…`＋一至二段 hook。座標句要說出**這章在全書骨幹上的位置與作用**，不可只複述章節大意，不可與別章雷同。

啟示的次序（全書五步，定案，用詞照抄 PLAN.md）：
1. 神先開口，從萬有說起，再縮到祂自己的家（番 1:1-6）
2. 日子近了，神親自巡查（番 1:7-18）
3. 在日子之前先開一道門，再把審判推向四方（番 2:1-15）
4. 回到那座城：她不親近，祂在中間（番 3:1-7）
5. 等候，然後歌唱：祂在你中間，招聚你（番 3:8-20）

單元對步：1→第1步；2、3→第2步；4、5→第3步；6→第4步；7、8→第5步。

貫穿全書的線（用得上就點出，不要硬塞；數字全部已核，見 PLAN.md）：**קרב「近／親近／中間」**（1:7、1:14×2 近 → 3:2 不親近 → 3:3、3:5、3:11、3:12、3:15、3:17 中間）；**יום「日子」**；**בקשׁ「尋求」**（1:6 → 2:3×3）；**1:18＝3:8 同一句火**；**שם「名」**；**רבץ「躺臥」**（2:7、2:14、3:13）。

## 三、不可越過的線（違反即退件）

1. **經文**：正文中任何「」＋（出處）的經文引句，必須逐字出自 `sources/scripture/cuv.tsv`（西番雅書）或 `python3 books/bible/Zapphaniah/sources/scripture/cuv_lookup.py 賽 47 8-10`（他書；zsh 下不要用 for-in 拆字，用 `while IFS='|' read` 或逐條呼叫）。**引句裏不可插括號譯注**。同一節的引句與出處節號必須對得上。**不確定的經節地址，查了才寫；寫「需另核」「待補」之類字樣算退件**。**寫完跑**：`python3 scripts/verify-prose-citations.py books/bible/Zapphaniah --self 番`（0 MISS 才算過）。
2. **注疏引文**：只用已下載來源，**沒有可定位原文就不加引號**。可用來源（皆在 `sources/commentary/`）：加爾文 `calvin-zephaniah.txt`（`calvin-INDEX.md` 有講次↔節對照；**`— Ed.` 編者註腳不是加爾文**）；亨利 `henry-zeph-{i,ii,iii,iv}.txt`（i 導論，ii 第1章，iii 第2章，iv 第3章）；摩根〈The Message of Zephaniah〉`morgan-zephaniah-norm1.txt`（主，已去頁眉、接回斷詞）／`-norm2.txt`——**全書概論，沒有逐節**，只能挑確實切題的句子，頁碼依 OCR 頁眉（pp. 289-301）；合併語料 `corpus.txt`。引文格式與範例章逐字相同：`> "English quote"` 換行 `> — 作者, *書名*, 章節` 空 `>` 行 `> 中譯：…`。引文前一段中文導讀是撮述不是翻譯。**麥克阿瑟：本書沒有，不立該節。** **寫完跑**：`python3 scripts/verify-citations.py books/bible/Zapphaniah --source books/bible/Zapphaniah/sources/commentary/corpus.txt`（OK/DRIFT/MISS 都要看；DRIFT 必須改）。
   - 某位解經者在本章沒有可查的專論，**就不立該節**，不補位、不改寫成像是他說的話。
   - **中文「」包著自己翻的注疏句，是本庫最常犯的錯**：只要不是逐字的英文原文引句（附原文與出處），就不要用「」包——改成不加引號的撮述（「加爾文讀作……」）。
   - **不要把兩位注疏者的話混成一句，不要把一人的立場說成另一人的**。
3. **不杜撰老弟兄的話**：倉庫沒有西番雅書的黃長老／老弟兄第一手材料。「老弟兄查經」一節只用他的**方法**，**不加引號歸給他任何話**；`voice.md` 白名單（`.claude/skills/ask-elder-wong/references/voice.md`）的語錄除外。稱呼一律「老弟兄」。
4. **不編史料**：年代、人名、地名、數字，只用經文與已下載注疏支持的；推測要寫明「推測」。**全稱斷言（「全書只有」「每一次」「從不」「唯一」）必須先用程式數過**（`python3 sources/count_hebrew.py [Strong號…]`、`cuv.tsv`）。字頻要註明依據與計法。
5. **原文研讀**：希伯來詞形一律從 `sources/hebrew/zeph.tsv`（或 `python3 sources/heb.py <Book> <chap> [verse]` 取他書）**複製**，不憑記憶打 niqqud；希伯來字在中文行文裏前後各留一個空格；**只放單一希伯來字**，不放 maqaf（־）或空格連接的多字片語（XeTeX 會排成亂序）；片語用音譯或拆成單字。字義用 `python3 sources/lex.py <Strong號>`（BDB 簡短釋義）或注疏者的說法，並寫明依據；不確定的寫「字面是…」，不靠記憶斷言詞源。
6. **不硬說預表**：新約對照只用經文本身有連結的線；其餘寫「連線，非原文所說」。**不抹平張力**（PLAN.md 已列：1:2 動詞兩讀、3:1 的城是誰、3:8 לעד、3:17 默然、3:18 難句、「耶和華的日子」的歷史層次與末後層次）。
7. **版本**：經文塊只由腳本產生；散文中經文引句用和合本（ai-eden 底本，字形「裏／甚麼／那裏」），英文詞若引 NASB 1995 須與 `nasb1995.tsv` 逐字相同。
8. **不可有**：空洞屬靈套話、AI 腔、emoji、「值得注意的是」這類墊字、同一點在同章講三次以上。「活在今天」不編造 AI／時事案例；寫不出真實觸點就寫具體的生活處境。全章不得出現：`TODO`、`@@`（除單行的 `@@SCRIPTURE …@@` 展開前）、`需verify`、`需另核`、`待補`。

## 四、章節內容規格

- 長度：每章 18–26 KB（含腳本展開的經文區塊）；你寫的部分約 9–13 KB。
- 背景 2–3 個 `###`；原文研讀 6–10 列（每列都能用資料核對）；領受要點 **3–4 條**，各自只屬於本章；
- 歷代注疏：`### 改革宗時期：加爾文`／`### 清教徒時期：亨利`／`### 摩根`——有哪個立哪個，每節 1–3 條逐字引文；體例說明框照範例章逐字抄；
- 詩篇與聖詩：一至二篇詩篇（逐字 CUV 引句）＋「配詩（見上）」一段說明；
- 老弟兄查經：開頭說明框（照範例章）→ `**精義一句話**` → `### 全經連線`（3–5 條，出處對得上、引句逐字）→ `### 提問式對話`（先問／再問／追問／落到自己）→ `### 活在今天` → `### 今天的祭壇`（早晨／晚上／一個行動）→ **`**你看見耶穌了嗎**？`** 一段收尾（只用有經文連結的線）；
- 生命應用：默想問題 ≤3（角度不與提問式對話重複）＋禱告回應（奉主耶穌基督的名，阿們）；
- 與其他經文的關聯：表格 8–12 列。

## 五、寫作流程（避免停滯）

1. 讀範例章與本檔；讀你章節範圍的 `cuv.tsv` 行、`hebrew/zeph.tsv`、加爾文／亨利對應段落、摩根相關頁。
2. **分段寫入**：先 Write 骨架前半（到「領受要點」），再用 Edit 或 Bash append 補後半。**不要一次寫整檔**。
3. 跑：`inject_scripture.py`、`verify-prose-citations.py … --self 番`、`verify-citations.py …`、`python3 scripts/lint-chapter-markup.py <章檔>`、`python3 scripts/check-prose-scripture-quotes.py <章檔>`。全部乾淨才回報。
4. 回報（≤300 字）：檔名、大小、11 節核對、各檢查結果、**你不確定／可能有誤的地方清單**（尤其詞義、字頻、史實、歸屬、全稱斷言）。誠實：做不到的標明，不要含糊帶過。完成後立刻停止，不要動別的檔案。

## 七、已知不可踩的坑（來自全庫歷史）

- 檢查器抓出的常見錯：引句內插括號、節號標錯、引文歸屬錯置、**把自己翻的注疏放進「」**。
- 注疏引文最常見三類錯：查無此句／立場說反／推論相左。不確定就不加引號。
- 配詩說明、書卷結語最容易「說得比來源多」。
- 同章同一個點只講一次；默想問題不要與「提問式對話」重複。
- 專有名詞照 `cuv.tsv` 與和合本：西番雅、古示、基大利、亞瑪利雅、希西家、約西亞、亞們、基瑪林、瑪勒堪、瑪革提施、迦薩、亞實基倫、亞實突、以革倫、基利提、迦南、摩押、亞捫、古實、亞述、尼尼微、錫安。
- 全域替換字詞會切斷專有名詞：不要用批次取代。
- 希伯來字不是用「手打」，是從 `zeph.tsv` 複製；字符串一長就不要放（XeTeX 亂序）。
