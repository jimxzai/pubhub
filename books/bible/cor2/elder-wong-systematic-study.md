# 哥林多後書深度領受 —— 按全書結構，老弟兄查經法

> 這一篇不逐節解經，是把全書當作一個整體來看。
> 先看見骨架，再看見血肉；先看見那位在軟弱中顯出能力的主，再看見祂的僕人。

---

## 全書精義一句話

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 基督因軟弱被釘十字架，卻因神的大能仍然活著；\\ 跟隨祂的人，也是這個形狀。}}\end{center}

13:4 是全書真正的鑰匙節。保羅辯了十二章「我是不是真使徒」，最後把答案放在基督的形狀上：**不是誰更有能力誰就是真的，是誰更像那位被釘的，誰就是真的。**

---

## 卷首：定位與鑰匙

### 這封信為何而寫

保羅在哥林多住了一年半（徒 18:11），建立了那間教會。後來關係破裂——他有過一次「痛苦的探訪」（2:1），寫過一封「流淚的信」（2:4）。他打發提多去，自己在特羅亞等消息，等到「心裏不安」，連傳福音的門開了都無心進去（2:12-13）。

提多帶回好消息（7:6-7）。**這封信就是那口氣鬆下來之後寫的。**

所以它前後語氣落差極大：一到七章是復和後的溫暖，十到十三章卻突然轉為嚴厲——因為問題解決了大半，但那批假使徒還在。

### 全書的鑰匙節

> **12:9**　他對我說：「我的恩典夠你用的，因為我的能力是在人的軟弱上顯得完全。」
>
> **13:4**　他因軟弱被釘於十字架，卻因神的大能仍然活著。我們也是這樣同他軟弱，但因神向你們所顯的大能，也必與他同活。

第一句是**主對保羅說的**，第二句是**保羅對教會說的**。前者是個人的經歷，後者是普遍的原則。

# 第一部：患難中的安慰與坦誠（1:1-2:17）——先把自己的底交出來

## 精義

**保羅要為自己的使徒身分辯護，第一步不是舉證，是承認自己曾經絕望。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 1:1-11 | 安慰的神；亞細亞的患難 |
| 1:12-2:4 | 為改變行程辯白；「流淚的信」的用意 |
| 2:5-11 | 饒恕那犯錯的人 |
| 2:12-17 | 特羅亞的不安；凱旋行列中的香氣 |

## 深度探索

### 一、安慰是流動的

1:3-7 五節之內十次提到「安慰」（παράκλησις 及其動詞）。這個字的字根是「呼召到身旁」。

而 1:4 說明了目的：「叫我們能用神所賜的安慰去安慰那遭各樣患難的人。」

\textcolor{ScriptureGold}{\textbf{神安慰你的份量，往往剛好是你將來要遞出去的份量。你受過的苦若沒有變成別人的安慰，那份苦就白受了一半。}}

### 二、「連活命的指望都絕了」

1:8 是使徒書信裏最赤裸的一句自述。1:9 給了原因：「叫我們不靠自己，只靠叫死人復活的神。」

**注意這句話的邏輯：神不是「容許」他絕望，是「用」絕望達成一件事——把他從自己身上挪開。**

### 三、饒恕是為了不讓撒但得逞

2:10-11：「免得撒但趁著機會勝過我們，因我們並非不曉得他的詭計。」

保羅在 2:6 說懲罰「已經夠了」。\textcolor{ScriptureGold}{\textbf{教會的紀律有一個停止的點。過了那個點還不肯饒恕，做的就不是神的工，是撒但的工。}}

### 四、凱旋行列裏的位置

2:14「感謝神！常帥領我們在基督裏誇勝」——這是羅馬凱旋式的畫面。

但要看清保羅站在哪裏：**凱旋行列裏有將軍，也有被押著走的俘虜。**保羅用的動詞（θριαμβεύω）在原文的語感是「押著遊行示眾」。他不是將軍，他是那個被牽著走的——而他說這是誇勝。

## 帶著走的問題

1. 我最近一次到了盡頭，學到的是「我要更堅強」，還是「我要更靠祂」？
2. 有沒有一個人，我心裏說「我原諒了」，卻從來沒有讓他知道？

# 第二部：新約執事的榮耀（3:1-4:18）——榮光裝在瓦器裏

## 精義

**這是全書領受最密的一段：新約的榮耀遠超舊約，而承載這榮耀的器皿卻是會破的。榮耀與瓦器，同時是真的。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 3:1-6 | 薦信寫在人心上；字句與精意 |
| 3:7-18 | 摩西的帕子；敞著臉，榮上加榮 |
| 4:1-6 | 心眼被弄瞎；創世之光再照一次 |
| 4:7-15 | 瓦器裏的寶貝；四組對句 |
| 4:16-18 | 外體毀壞，內心更新；至暫至輕的苦楚 |

## 深度探索

### 一、薦信

3:1「豈像別人用人的薦信給你們或用你們的薦信給人嗎？」——假使徒帶著文件來。

保羅的回答（3:2-3）：「你們就是我們的薦信……不是用墨寫的，乃是用永生神的靈寫的；不是寫在石版上，乃是寫在心版上。」

\textcolor{ScriptureGold}{\textbf{一個傳道人真正的憑據，是他手下的人變成了甚麼樣子。}}

### 二、字句與精意

3:6「因為那字句是叫人死，精意是叫人活。」

這不是說舊約不好。3:7 稱律法的職事為「屬死的職事」，卻同時說它「有榮光」。**問題不在律法，在人——律法能照出你的病，不能治你的病。**

### 三、帕子的三重意義

| 出現 | 遮的是誰 | 為甚麼 |
|--------------|--------------|------------------------------------------|
| 3:13 | 摩西 | 不叫以色列人定睛看那將廢者的結局 |
| 3:14-15 | 以色列人 | 讀舊約時心上有帕子 |
| 3:16 | 除去 | 「但他們的心幾時歸向主，帕子就幾時除去了」 |

### 四、變化的機制

3:18：「我們眾人既然敞著臉得以看見主的榮光，好像從鏡子裏返照，就變成主的形狀，榮上加榮。」

「變成」（μεταμορφόω）是**現在被動式**——正在被改變，而且是被動的。

\textcolor{ScriptureGold}{\textbf{改變不是靠盯著自己看，是靠看著祂。人會變成他所注視之物的樣子。}}

### 五、四組對句

4:8-9 用四組「卻」把整個處境擺清楚：

| 是真的 | 也是真的 |
|------------------------------------------|------------------------------------------|
| 四面受敵 | 卻不被困住 |
| 心裏作難 | 卻不至失望 |
| 遭逼迫 | 卻不被丟棄 |
| 打倒了 | 卻不至死亡 |

**保羅沒有否認前半。他不是說苦難是假的，他是說苦難不是最後一句話。**

## 帶著走的問題

1. 如果有人要從我身上「讀」出基督，他會讀到甚麼？
2. 我最近在盯著甚麼看？我正在變成那個樣子嗎？

# 第三部：永恆的盼望與和好的職分（5:1-7:16）——使者與心腸

## 精義

**保羅把眼光拉到永恆（帳棚與房屋、審判台），再從永恆拉回一個具體的差事：作和好的使者。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 5:1-10 | 帳棚與房屋；聖靈作憑據；基督台前 |
| 5:11-21 | 愛的催逼；新造的人；和好的職分 |
| 6:1-13 | 「現在正是拯救的日子」；患難清單；心地寬大 |
| 6:14-7:1 | 不要同負一軛；潔淨自己 |
| 7:2-16 | 提多帶來的消息；敬虔的憂愁 |

## 深度探索

### 一、憑據

5:5「神……又賜給我們聖靈作憑據。」

ἀρραβών（憑據）是訂金——**是同一批貨的第一筆，不是另外的東西。**聖靈今天的工作，與將來的榮耀是同一種東西的先付。

### 二、和好的方向

5:19-20：神「藉著基督使我們與他和好……我們替基督求你們與神和好。」

留意方向：**不是求神與人和好（神那邊已經做完了），是求人與神和好。**

而 5:21 給出機制：「神使那無罪的替我們成為罪，好叫我們在他裏面成為神的義。」\textcolor{ScriptureGold}{\textbf{罪不是被忽略了，是被轉移了。這一節被稱為新約裏最偉大的一次交換。}}

### 三、兩種憂愁

7:10「因為依著神的意思憂愁，就生出沒有後悔的懊悔來，以致得救；但世俗的憂愁是叫人死。」

| 世俗的憂愁 | 依著神的意思憂愁 |
|------------------------------------------|------------------------------------------|
| 停在「我完了」 | 走向「我要去把它處理好」 |
| 向內塌陷 | 向外行動 |
| 焦點是自己的名聲 | 焦點是得罪了神 |
| 結果是死 | 結果是得救 |

7:11 列出七個果子：殷勤、自訴、自恨、恐懼、想念、熱心、責罰。**真悔改是有動作的。**

## 帶著走的問題

1. 我最近一次為自己的錯難過，結果是去做了甚麼，還是只是難過了幾天？
2. 我有沒有一樣東西，是「除了這個都可以交給神」的？

# 第四部：捐輸的恩典（8:1-9:15）——錢跟著人走

## 精義

**保羅用兩章講捐款，卻一次也沒有從「需要」講起。他從基督講起，從馬其頓人講起，最後才講到方法。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 8:1-9 | 馬其頓的榜樣；基督成了貧窮 |
| 8:10-24 | 辦成這事；三人同行的財務安排 |
| 9:1-7 | 預備妥當；樂意捐的人 |
| 9:8-15 | 神能將各樣的恩惠多多加給你們；說不盡的恩賜 |

## 深度探索

### 一、馬其頓人的次序

8:2-5：「在患難中受大試煉的時候，仍有滿足的快樂；在極窮之間還格外顯出他們樂捐的厚恩……並且他們所做的，不但照我們所想望的，更照神的旨意**先把自己獻給主**。」

\textcolor{ScriptureGold}{\textbf{先給的是人，錢跟著人走。次序若倒過來，給多少都只是交易。}}

### 二、基督的貧窮

8:9「他本來富足，卻為你們成了貧窮，叫你們因他的貧窮，可以成為富足。」

動詞 ἐπτώχευσεν 是「成了貧窮」——不是「本來窮」。**祂是自己走下來的。**這一節是全書講奉獻的唯一根據。

### 三、財務的透明

8:18-21 記載保羅安排三個人同行經手捐款，理由寫在 8:20-21：「這就免得有人因我們收的捐銀很多，就挑我們的不是。我們留心行光明的事，不但在主面前，就在人面前也是這樣。」

**他不是怕自己出錯，是把制度設計成「就算有人想挑，也挑不出來」。**

### 四、樂意

9:7「各人要隨本心所酌定的，不要作難，不要勉強，因為捐得樂意的人是神所喜愛的。」

「樂意」（ἱλαρός）字面是「歡然、明亮」——英文 hilarious 由此而來。**神看重的不是金額，是那顆給出去的心是不是自由的。**

## 帶著走的問題

1. 我上一次的奉獻，是從「還剩多少」算的，還是從「祂給了多少」算的？
2. 我有沒有一件曾經真心答應神的事，到今天還停在「有願做的心」？

# 第五部：使徒權柄的辯護（10:1-13:14）——用傷痕作履歷

## 精義

**語氣在這裏急轉。前面九章是對已經復和的多數人說的，這四章是對還在被假使徒影響的少數人說的。**

## 內部結構

| 段落 | 內容 |
|------------------------------------------|------------------------------------------|
| 10:1-6 | 屬靈的兵器；奪回人的心意 |
| 10:7-18 | 量自己的尺；指著主誇口 |
| 11:1-15 | 貞潔的童女；另一個耶穌、另一個靈、另一個福音 |
| 11:16-33 | 愚妄的自誇；患難清單；筐子裏逃走 |
| 12:1-10 | 第三層天；那根刺；恩典夠用 |
| 12:11-13:14 | 第三次來；自己省察；三一祝福 |

## 深度探索

### 一、戰場在思想裏

10:4-5：「我們爭戰的兵器本不是屬血氣的，乃是在神面前有能力，可以攻破堅固的營壘，將各樣的計謀，各樣攔阻人認識神的那些自高之事，一概攻破了，又將人所有的心意奪回，使他都順服基督。」

「奪回」（αἰχμαλωτίζω）是把俘虜押回來。\textcolor{ScriptureGold}{\textbf{不是把念頭消滅，是把它押到基督面前受審。}}

### 二、量錯了尺

10:12「他們用自己度量自己，用自己比較自己，乃是不通達的。」

**自己量自己，永遠量得剛剛好。**所以 10:18：「因為蒙悅納的，不是自己稱許的，乃是主所稱許的。」

### 三、倒過來寫的履歷

11:23-33 是新約裏最不尋常的一份自傳。別人的履歷寫成就，保羅寫：鞭打、棍打、石頭打、船壞、危險、飢渴、赤身、寒冷。

而清單的最後一項（11:33）是：從城牆上被人用筐子縋下去逃命。

\textcolor{ScriptureGold}{\textbf{他故意把最不體面的放在壓軸。羅馬軍中最高的榮譽是第一個攀上敵城牆的「城牆冠冕」；保羅的「城牆故事」是被人從牆上放下來逃走。}}

### 四、那根刺

12:7-9 是全書的高峰：

- 刺是甚麼——經文沒有說。**神刻意沒有說，好叫每一個帶著刺的人都能對號入座。**
- 刺是誰給的——同一節裏說是「撒但的差役」，也說是「恐怕我過於自高」。**同一根刺，撒但要用它毀他，神用它保守他。**
- 主怎麼回答——「我的恩典夠你用的。」用的是**完成式**（εἴρηκέν μοι）：話已經說了，一直有效。
- 刺有沒有被拿走——**經文從頭到尾沒有說它離開了。**

### 五、最後把鏡子轉過去

13:5「你們總要自己省察有信心沒有，也要自己試驗。」

辯了十二章「保羅是不是真使徒」，最後一章他說：**先驗你們自己。**

而 13:14 的三一祝福是全新約最完整的一句：「願主耶穌基督的恩惠、神的慈愛、聖靈的感動，常與你們眾人同在！」

## 帶著走的問題

1. 我那根一直沒有被拿走的刺，這些年攔住了我甚麼？又保守了我甚麼？
2. 如果我要誠實地寫一份「軟弱清單」，第一項會是甚麼？

# 跨書貫通

## 一、與哥林多前書——兩封信合成一個牧者

| 哥林多前書 | 哥林多後書 |
|------------------------------------------|------------------------------------------|
| 對付教會的問題 | 對付教會對牧者的懷疑 |
| 「你們要傚法我」（林前 11:1） | 「除了我的軟弱以外，我並不自誇」（12:5） |
| 論愛的詩章（林前 13） | 愛的實踐：被傷了仍然敞開（7:2-4） |
| 復活的長篇論證（林前 15） | 復活的個人版：外體毀壞，內心更新（4:16） |

## 二、與腓立比書——同一個「倒空」

| 腓立比書 | 哥林多後書 |
|------------------------------------------|------------------------------------------|
| 2:7 反倒虛己，取了奴僕的形像 | 8:9 他本來富足，卻為你們成了貧窮 |
| 3:10 曉得和他一同受苦，效法他的死 | 4:10 身上常帶著耶穌的死 |
| 4:13 我靠著那加給我力量的 | 12:10 我甚麼時候軟弱，甚麼時候就剛強了 |

## 三、與約翰福音——榮耀的定義

約翰福音說十字架是「得榮耀的時候」（約 12:23-24）。哥林多後書把這個定義應用在僕人身上：

| 約翰福音 | 哥林多後書 |
|------------------------------------------|------------------------------------------|
| 一粒麥子落在地裏死了（12:24） | 死是在我們身上發動，生卻在你們身上發動（4:12） |
| 我是世界的光（8:12） | 神已經照在我們心裏（4:6） |
| 人子得榮耀的時候到了（12:23） | 因軟弱被釘，卻因大能活著（13:4） |

# 全書的句號：你看見耶穌了嗎？

哥林多後書把基督放在幾個很不一樣的位置上：

| 位置 | 經文 |
|------------------------------------------|------------------------------------------|
| 一切安慰的源頭 | 1:3 |
| 神應許的「是」 | 1:20 |
| 凱旋行列中的得勝者 | 2:14 |
| 神的形像、榮耀的光 | 4:4-6 |
| 替我們成為罪的那一位 | 5:21 |
| 本來富足卻成了貧窮的 | 8:9 |
| 恩典夠用的那一位 | 12:9 |
| **因軟弱被釘、因大能活著的** | **13:4** |

最後一項是全書的落點。

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 你要跟隨一位因軟弱被釘的主，\\ 就不要指望自己一路都是剛強的。}}\end{center}

## 附：本卷貫穿的幾句話

> **關於安慰**：安慰不是儲存的，是流動的。你受過的苦若沒有變成別人的安慰，那份苦就白受了一半。

> **關於瓦器**：裂縫是設計，不是失敗。詩人看見的是器皿破了，保羅看見的是破口讓光透出來。

> **關於改變**：人會變成他所注視之物的樣子。所以問題不是「我要多努力」，是「我在看甚麼」。

> **關於奉獻**：先給的是人，錢跟著人走。

> **關於那根刺**：主沒有回答保羅的請求，主回答了保羅這個人。
