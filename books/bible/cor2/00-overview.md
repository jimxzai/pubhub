# 哥林多後書概覽 (2 Corinthians Overview)

## 書卷簡介

| 項目 | 內容 |
|------------------------------------------|------------------------------------------|
| 作者 | 使徒保羅（1:1「奉神旨意作基督耶穌使徒的保羅」） |
| 寫作日期 | 主後 55-56 年 |
| 寫作地點 | 馬其頓（2:13；7:5） |
| 對象 | 哥林多教會，以及亞該亞全境的眾聖徒（1:1） |
| 篇幅 | 13 章，257 節 |
| 主題 | 十字架形狀的事奉——軟弱中的能力 |
| 核心真理 | 能力出於神，不出於我們（3:5；4:7；12:9） |

---

## 核心經文 (Key Verse)

> **12:9**　他對我說：「我的恩典夠你用的，因為我的能力是在人的軟弱上顯得完全。」所以，我更喜歡誇自己的軟弱，好叫基督的能力覆庇我。
>
> *And He has said to me, "My grace is sufficient for you, for power is perfected in weakness." Most gladly, therefore, I will rather boast about my weaknesses, so that the power of Christ may dwell in me.* (NASB)

## 一、這卷書自己說明自己

保羅在信裏多次交代他為甚麼寫，不必外求：

| 經文 | 他自己說的理由 |
|------------------------------------------|------------------------------------------|
| 1:8 | 「我們不要你們不曉得……我們在亞細亞遭遇苦難」——他要他們知道實情 |
| 2:4 | 「要叫你們知道我格外地疼愛你們」——解釋那封流淚的信 |
| 7:8-9 | 「如今我歡喜，不是因你們憂愁，是因你們從憂愁中生出懊悔來」 |
| 8:8 | 「要試驗你們愛心的實在」——說明捐輸的用意 |
| 12:19 | 「我們……乃是在基督裏當神面前說話。親愛的弟兄啊，一切的事都是為造就你們」 |
| 13:10 | 「我不在你們那裏的時候，把這話寫給你們，好叫我見你們的時候不用嚴厲的待你們」 |

\textcolor{ScriptureGold}{\textbf{最後一句最要緊：這封嚴厲的信，是為了不必嚴厲地見面。}}

## 二、使徒行傳背景：這間教會是怎麼來的

> **徒 18:9-10**　夜間，主在異象中對保羅說：「不要怕，只管講，不要閉口，有我與你同在，必沒有人下手害你，因為在這城裏我有許多的百姓。」

| 事件 | 經文 | 意義 |
|--------------------------------|--------------|--------------------------------|
| 保羅從雅典來到哥林多 | 徒 18:1 | 從哲學之城到商業之城 |
| 與亞居拉、百基拉同住做工 | 徒 18:2-3 | 織帳棚為業，自養傳道 |
| 每逢安息日在會堂辯論 | 徒 18:4 | 向猶太人與希臘人作見證 |
| 西拉、提摩太從馬其頓來 | 徒 18:5 | 保羅為道迫切 |
| 猶太人抵擋，轉向外邦人 | 徒 18:6 | 福音戰略的轉折 |
| 管會堂的基利司布全家信主 | 徒 18:8 | 許多哥林多人信而受洗 |
| 主在異象中親自說話 | 徒 18:9-10 | 「在這城裏我有許多的百姓」 |
| 住了一年零六個月 | 徒 18:11 | 扎實建立根基 |

**這就是保羅寫信的對象——他親手建立、用一年半的時間澆灌的教會。**所以後書裏流露的眼淚與心腸不是修辭，是真實的牧者之愛。

哥林多是當時的商業大城，港口城市，人口混雜，道德敗壞到「哥林多化」（Corinthianize）在希臘語中成了「放蕩生活」的代名詞。\textcolor{ScriptureGold}{\textbf{神在那樣的城裏說「我有許多的百姓」——這句話說在他們信主之前。}}

## 三、關係的時間線

```
主後 50-51   保羅建立教會（徒 18:1-18，住了一年半）
      │
主後 54-55   哥林多前書（從以弗所寫，處理教會的問題）
      │
主後 55      痛苦的探訪（2:1，短暫到訪，遭遇衝突）
      │
主後 55      流淚的信（2:4，已佚失）
      │
主後 55-56   提多帶回好消息（7:6-7，教會悔改了）
      │
主後 55-56   哥林多後書（從馬其頓寫）
      │
主後 57      第三次探訪成行；羅馬書在哥林多寫成
```

\textcolor{ScriptureGold}{\textbf{留意最後兩行：這封信化解了那段關係，保羅才得以安然回到哥林多——而羅馬書就是在那裏寫成的。}}

## 四、書卷特色

### 4.1 一封信，兩種語氣

一到七章溫暖，十到十三章嚴厲，八到九章談捐輸夾在中間。歷代有人因此主張這是兩封信被合編的。

但更簡單的解釋是：**問題解決了大半（多數人已經悔改），但那批假使徒還在。**保羅先對已經復和的多數人說話，再轉向仍被影響的少數人。

### 4.2 最個人的一封

| 別的書信 | 哥林多後書 |
|--------------------------------|------------------------------------------|
| 保羅是使徒、教師、父親 | 保羅還是一個會累、會怕、會哽咽的人 |
| 論證嚴整 | 情緒推動，前後跳接 |
| 講「你們該怎麼活」 | 講「我裏面發生了甚麼」 |

1:8「連活命的指望都絕了」、2:4「多多地流淚」、7:5「身體也不得安寧」、11:29「有誰跌倒，我不焦急呢」。

### 4.3 「軟弱」是全書的骨幹

ἀσθένεια（軟弱）及其同源詞在這卷書出現的密度，高過保羅任何一卷書。全書在 13:4 收束：**「他因軟弱被釘於十字架，卻因神的大能仍然活著。」**

## 研讀資源

**本書整合三方資源**：週四查經班的第一手教導；John MacArthur 在 gty.org 的逐節解經；G. Campbell Morgan 的屬靈組織分析法（*The Corinthian Letters of Paul*, 1946）。

**經文**：中文以和合本（1919，公有領域）為準，英文對照為 NASB（1995）。逐節核對透過 ai-eden.com 進行，書卷代碼為 `2-corinthians`。

**注疏體例**：各章「歷代注疏」條目均為編者按該作者著作要旨所作的中文撮述，非逐字翻譯；引文行只標明出處，供讀者自行查證。
