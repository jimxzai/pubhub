# Appendix B: Key Themes 主題索引

## 全書兩部 The Book’s Two Parts

| 部分 Part | 經文 Passage | 主題 Theme |
|---|---|---|
| **聖靈中的新約事奉 Ministry in the New Covenant** | 1-7章 | 保羅的見證：患難中的安慰、聖靈的職事、和好的職分 |
| **十字架能力的見證 The Power of the Cross** | 8-13章 | 保羅的辯護：恩典的奉獻、屬靈爭戰、軟弱中的能力 |

## 核心領受主題 Key Themes of Reception

|              |                                           |
|:-------------|:------------------------------------------|
| 患難中的安慰 | 1:3-11 — 神安慰我們，使我們能安慰別人     |
| 瓦器中的寶貝 | 4:7-12 — 莫大的能力是出於神，不是出於我們 |
| 和好的職分   | 5:11-21 — 大交換：無罪者替我們成為罪      |
| 永生神的殿   | 6:14-7:1 — 分別為聖，因聖靈內住           |
| 恩典的奉獻   | 8:1-9:15 — 基督本是富足，為你們成了貧窮   |
| 身上的一根刺 | 12:1-10 — 我的能力是在人的軟弱上顯得完全  |
| 三一的祝福   | 13:14 — 全書以三位一體的祝福作結          |

## 希臘文關鍵詞 Key Greek Terms

|                             |                               |
|:----------------------------|:------------------------------|
| **paraklēsis** (παράκλησις) | 安慰 — 患難中神所賜的安慰     |
| **thlipsis** (θλῖψις)       | 患難 — 貫穿全書的處境詞       |
| **doxa** (δόξα)             | 榮耀 — 從榮耀到榮耀的更新     |
| **katallagē** (καταλλαγή)   | 和好 — 神與人、人與人的和好   |
| **charis** (χάρις)          | 恩典 — 從恩典的奉獻到恩典夠用 |
| **astheneia** (ἀσθένεια)    | 軟弱 — 能力顯明之處           |
