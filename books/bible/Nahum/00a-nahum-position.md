# 那鴻書在整本聖經裏的位置 (Nahum in the Whole Bible)

## 三章，四十七節

那鴻書在我們的聖經裏是第三十四卷，夾在彌迦書和哈巴谷書中間，是「十二小先知書」的第七卷。三章，四十七節；按 OSHB 的斷詞，希伯來文共 558 個詞（OSHB 的 562 個 `<w>` 含 4 組 ketiv/qere 重複）。它不像約拿書那樣有故事，沒有一個先知個人的經歷被記下來，連先知的籍貫「伊勒歌斯」在哪裏，歷來也沒有定論。可是它整卷都在說同一座城：尼尼微。

加爾文開講的時候，第一句就誠實承認：

> "The time in which Nahum prophesied cannot with certainty be known."
> — John Calvin, *Commentaries on Jonah, Micah, and Nahum*, tr. John Owen, "Calvin's Preface to Nahum"
>
> 中譯：那鴻是甚麼時候作先知，無法確定。

## 尼尼微的來歷

要讀這卷書，先要認識尼尼微是誰。這條線，起點在創世記，終點在啟示錄：

| 時期 | 經文 | 發生了甚麼 |
|--------------|------------------------|----------------------------------------------------------|
| 建城 | 創10:11-12 | 「他從那地出來往亞述去，建造尼尼微、利河伯、迦拉……這就是那大城」 |
| 約拿 | 拿1:2；3:3 | 「他們的惡達到我面前」；「這尼尼微是極大的城，有三日的路程」 |
| 亞述攻取北國 | 王下17:6 | 亞述王攻取撒瑪利亞，將以色列人擄到亞述 |
| 神手中的棍 | 賽10:5-12 | 「亞述是我怒氣的棍」；神成就工作之後，「必罰亞述王自大的心」 |
| 西拿基立 | 王下19:35-36；賽37:36-37 | 耶和華的使者在亞述營中殺了十八萬五千人，西拿基立「拔營回去，住在尼尼微」 |
| 那鴻 | 鴻1-3 | 判決、圍城、罪名、前例、傷口 |
| 西番雅 | 番2:13-15 | 「耶和華必伸手攻擊北方，毀滅亞述，使尼尼微荒涼」 |
| 覆亡 | （經文以外） | 主前612年，巴比倫與瑪代聯軍攻陷尼尼微（巴比倫編年史所載，學界通說） |
| 新約 | 太12:41；路11:32 | 尼尼微人要在審判時起來，定這世代的罪 |
| 末日的大城 | 啟17-18 | 以妓女的圖像，與那鴻3:4 的畫面相呼應（編者連線，見下表說明） |

這條線上有一個讀者很容易漏掉的細節：**約拿書和那鴻書講的是同一座城，隔著約一百年（亨利與摩根的說法；加爾文英譯本的編者註作約150年，兩說並存）。**摩根的講法是：神在長久忍耐之後才毀滅尼尼微；約一百年前，祂曾差遣一位不情願的先知去預告她的厄運；尼尼微悔改了，後來卻又為自己的悔改而後悔（*Living Messages of the Books of the Bible*，p. 268）。

## 與約拿書的關係

約拿書與那鴻書，引的是同一段神的自我宣告（出34:6-7；民14:18），各引一半：

| 經文 | 引的是 |
|--------------|----------------------------------------------------------------------------------|
| 拿4:2 | 「你是有恩典、有憐憫的神，不輕易發怒，有豐盛的慈愛」（拿4:2 接著還說「並且後悔不降所說的災」，那一句與出34 不同，近於珥2:13 的說法） |
| 鴻1:3 | 「耶和華不輕易發怒，大有能力，萬不以有罪的為無罪」 |
| 出34:6-7 | 兩者的出處：「有憐憫有恩典的神，不輕易發怒，並有豐盛的慈愛和誠實……萬不以有罪的為無罪」 |

兩卷書各取了這段宣告的一部分：**約拿書取「有恩典、有憐憫、不輕易發怒、有豐盛的慈愛」，那鴻書取「不輕易發怒」與「萬不以有罪的為無罪」。**這不是說一卷書是另一卷的續集——它們的時間、作者、文體都不同。這是整本聖經把同一個神，在同一座城身上，說了兩遍。

## 與彌迦書、哈巴谷書的相鄰

按聖經的次序，那鴻書前面是彌迦書。彌迦書5:5 說：「這位必作我們的平安。當亞述人進入我們的地境，踐踏宮殿的時候……」；那鴻書1:15 說的，是報「平安」的腳登山。彌迦說，從伯利恆出來的那位掌權者（彌5:2），必作我們的平安（彌5:5）；那鴻說，平安的腳步已經在山上。兩卷書的「平安」是同一個字（שָׁלוֹם）。

那鴻書後面是哈巴谷書；哈巴谷問神：「惡人吞滅比自己公義的，你為何靜默不語呢？」（哈1:13）兩卷書相鄰，可以並讀：那鴻書說神對亞述的決定（鴻1:15「那惡人不再從你中間經過」），哈巴谷書問神對下一個強權的作為。

## 與啟示錄的關係

那鴻書的幾個畫面，在啟示錄裏可以找到回聲（以下是編者列出的連線，不是說啟示錄在引用它）：

| 那鴻書 | 啟示錄 |
|----------------------------------------|--------------------------------------------------------|
| 1:6「誰能立得住呢？」 | 6:17「誰能站得住呢？」→ 7:9「站在寶座和羔羊面前」 |
| 2:13「你使者的聲音必不再聽見」 | 18:22-23「在你中間決不能再聽見」 |
| 3:4「藉淫行誘惑列國，用邪術誘惑（原文是賣）多族」 | 17:1-5；18:23「萬國也被你的邪術迷惑了」 |
| 3:4 把列國「賣」了 | 18:13 貨單的最後一項：「奴僕、人口」 |
| 3:7「有誰為你悲傷呢？」 | 18:20「天哪，眾聖徒、眾使徒、眾先知啊，你們都要因她歡喜」 |
| 3:19「必都因此向你拍掌」 | 19:1-2「哈利路亞！……他的判斷是真實公義的」 |

## 讀這卷書的三個限制

這卷書留下了三個沒有答案的問題，讀之前先承認它們，會讓後面的每一步都更誠實：

1. **年代與作者不明。**經文自己劃出的兩端：底比斯已經陷落（3:8-10，約主前663年），尼尼微尚未覆亡（主前612年）。這兩端之間，先知是誰、哪一年說的，經文沒有說。本書按經文自己劃的界線讀。
2. **「挪亞們」（No-amon）是哪一座城。**加爾文當作亞歷山大城（英譯者註：猶太拉比與早期教父也這樣看）；英譯者引 Henderson 的話，說後來的注釋家多取底比斯。本書按後者，並載明前者。
3. **「報仇」的神，與「慈愛」的神，是同一位嗎？**那鴻書全卷沒有「慈愛」二字，也沒有「憐憫」「恩典」。這些字不在這卷書裏，不等於這位神不是。本書如實指出這卷書的選擇：它先說祂的能力與公義，把慈愛放在第7節的「本為善」。
