# 附錄五：基督頌與家庭秩序的結構分析
## Appendix E: Structural Analysis of the Christ Hymn and Household Code

---

## 引言

歌羅西書裡有兩段經文，分別以極不相同的文學形式，承載著全書最重要的教導：1:15-20是一首高度濃縮、對稱工整的詩體宣告，講「基督是誰」；3:18-4:1是一段條理分明、按身分配對排列的倫理教導，講「所以你當怎樣活」。這篇附錄要把這兩段經文各自的**文學結構**攤開來細看——不只是讀懂它們說了什麼，更要看見它們**怎麼說**，因為形式本身，往往就是意義的一部分。

---

## 第一部：基督頌的結構(1:15-20)

### 兩節詩節的整體佈局

多數解經家（包括加爾文以降的傳統解經）都留意到，1:15-20在文氣上明顯不同於前後文——句式工整、用詞高度重複、邏輯對稱，帶著詩歌或信仰宣告(confession)的特徵。學者普遍認為，這段經文很可能反映了初代教會早期已經存在、會眾共同頌唱或誦念的基督頌詞，保羅或是直接引用，或是仿照這個既有的頌詞體裁自己寫成——究竟是「引用」還是「仿寫」，學界沒有定論，但「這是一首詩，不是一段散文論述」這一點，是廣被接受的共識。

整段可以清楚分成兩個平行的詩節，以19-20節作結束的橋段：

| | 第一詩節 | 第二詩節 |
|---|---|---|
| **經文範圍** | 1:15-17 | 1:18-20 |
| **開頭公式** | 「他是」(ὅς ἐστιν, hos estin)——15節「愛子是那不能看見之神的像」 | 「他是」(καί ἐστιν αὐτὸς, kai estin autos)——18節「他也是教會全體之首」 |
| **主題領域** | 基督與**創造**(cosmos)的關係 | 基督與**教會**(ecclesia)的關係 |
| **「首生的」用法** | 「首生的」(prōtotokos)，15節——首生於**萬有**（創造之先的地位） | 「首生的」(prōtotokos)，18節——首生於**死人**（復活之先的地位） |
| **「萬有」焦點** | 「萬有都是靠他造的……又是為他造的」（16節）；「他在萬有之先，萬有也靠他而立」（17節） | 「便藉著他叫萬有……都與自己和好了」（20節） |
| **收束句** | （隱含）他在萬有之上居首位 | 「使他可以在凡事上居首位」（18節下，全段的樞紐句） |

### 「他是」(ὅς ἐστιν)公式：兩次宣告，一個身分

這首頌歌最鮮明的結構標記，是兩次以「他是」開頭的宣告句（15節、18節）。這種「他是……」的句式在希臘文詩歌與早期信仰宣告中相當典型——先確立主詞的身分，再展開這身分帶出的果效。兩次「他是」把整首頌歌切成清楚的兩半，卻不是兩個互不相干的主題，而是同一位基督在兩個不同領域（創造/教會）裡的同一種居首地位。

### 「萬有」(τὰ πάντα)的反覆迴響

「萬有」一詞在短短六節經文裡出現四次以上（16節兩次、17節、20節），是貫穿整首頌歌的鑰匙詞。留意它出現的位置精準地對應著兩個詩節的主題：第一詩節裡，「萬有」是被造、被托住的對象（16-17節）；第二詩節裡，「萬有」是被和好的對象（20節）。保羅（或這首頌詞原本的作者）刻意用同一個詞，把「創造的萬有」與「被和好的萬有」焊接成一句宣告：**造萬有的那一位，也是叫萬有和好的那一位**——創造與救贖，在這首詩裡從來不是兩件事。

### 「首生的」(prōtotokos)的雙重平行

「首生的」(πρωτότοκος)在全段只出現兩次，卻是整首頌歌結構上最精巧的一組平行：

- **15節**：「首生的，在一切被造的以先」——首生於**萬有**，指向創造領域裡的優先地位。
- **18節**：「元始，是從死裡首先復生的」——原文同樣是「首生的」(πρωτότοκος ἐκ τῶν νεκρῶν)，首生於**死人**，指向新造（復活）領域裡的優先地位。

這個詞在兩處都不是指「時間上的第一個」，而是指「地位上的優先者」——正如加爾文所指出的，基督被稱為首生的，不是因為祂在時間上先於萬有存在，而是因為萬有是「藉著祂」被造的（見第三章所引）。兩次出現的「首生的」，把「創造」與「新造」這兩個原本各自獨立的領域，用同一個詞縫合成同一位基督的兩重首位。

### 結構本身就是領受的宣告

把上面幾點合起來看，這首頌歌的結構本身，就已經在傳遞它的核心信息：

1. 兩次「他是」——同一位格，兩個領域皆居首位。
2. 兩次「首生的」——創造之先、復活之先，兩個「先」都指向同一個尊榮地位。
3. 反覆的「萬有」——創造與救贖共用同一個對象，暗示它們共有同一位成就者。
4. 全段以「使他可以在凡事上居首位」（18節下）收束——這句話不只是第二詩節的結尾，更是整首詩（甚至整卷書）的主旨句：不是「在某些領域」，是「在凡事上」。

換句話說，這首詩不是隨意排列的形容詞清單，而是一份精心設計的文學建築——用對稱的結構，把「基督居首位」這件事，從創造的起頭一路唱到教會的救贖，不留一絲縫隙容納歌羅西異端所主張的任何「中介」或「補充」。

## 第二部：家庭守則的結構(3:18-4:1)

本書第十一章已經處理過這段經文的核心背景——古希臘羅馬倫理著作中確實存在一種常見的文學體裁，德文學者稱之為 *Haustafel*（家庭守則表），亞里士多德《政治學》討論「家政管理」(oikonomia)時，便是圍繞著主人/奴僕、丈夫/妻子、父親/兒女這三組關係展開；斯多噶學派的倫理手冊也有類似的教導模式。這篇附錄不重複那段背景介紹，而是從**結構與比較**的角度，更深入地拆解這段經文的文學佈局，以及它與同類體裁的具體差異何在。

### 三組配對的結構佈局

| 配對 | 下位者（先受教導） | 上位者（後受教導，附帶限制） | 貫穿詞 |
|---|---|---|---|
| 第一組：婚姻 | 「你們作妻子的，當順服自己的丈夫」（18節） | 「你們作丈夫的，要愛你們的妻子，不可苦待他們」（19節） | 「在主裡面是相宜的」 |
| 第二組：親子 | 「你們作兒女的，要凡事聽從父母」（20節） | 「你們作父親的，不要惹兒女的氣」（21節） | 「這是主所喜悅的」 |
| 第三組：主僕 | 「你們作僕人的，要凡事聽從你們肉身的主人」（22-25節） | 「你們作主人的，要公公平平的待僕人」(4:1) | 「敬畏主」「像是給主做的」「你們也有一位主在天上」 |

留意這個結構本身的兩個特徵：第一，**每一組都是「下位者先，上位者後」**的順序——這在當時的家庭守則文獻裡並非常規（下一節詳述）；第二，**每一組都以「主」為收束詞**——八次「主」字(kyrios)分佈在六句命令之中，像一條看不見的絲線，把三組截然不同的社會關係縫成同一塊布。

### 與亞里士多德式/斯多噶式家庭守則的比較

古代的家庭守則文獻（如亞里士多德《政治學》卷一論家政管理）有幾個共同特徵，值得與保羅的版本逐項對照：

| 比較項目 | 亞里士多德式/斯多噶式家庭守則 | 保羅在西3:18-4:1的版本 |
|---|---|---|
| **說話對象** | 幾乎只對「一家之主」（丈夫/父親/主人）說話，教導他如何治理家中的妻子、兒女、奴僕——後者是被談論的對象，不是被稱呼的對象 | 直接向「下位者」本人說話——「你們作妻子的」「你們作兒女的」「你們作僕人的」，每一句都是對他們發出的第二人稱命令 |
| **下位者的地位** | 被視為家主「治理」的對象，缺乏獨立的道德主體性——他們的順服被視為理所當然的社會秩序，不需要單獨被賦予理由 | 被當作有道德責任、能自主回應呼召的行動者；他們的順服/聽從有明確的屬靈理由（「在主裡面是相宜的」「主所喜悅」），不是單純基於社會位階 |
| **上位者的權柄** | 權柄本身很少被限制或究責——丈夫、父親、主人的管治權在這類文獻裡多半被視為自然而然、無需附加條件的秩序 | 每一組上位者的命令都附帶明確的限制與究責：丈夫「不可苦待」妻子；父親「不要惹兒女的氣」；主人被要求「公公平平」，且被提醒「你們也有一位主在天上」——上位者同樣要向這位「天上的主」交帳 |
| **權柄的最終根源** | 家主的權柄根源於自然秩序、社會習俗、或城邦治理的需要 | 每一段關係的權柄與順服，根源都不在人的位階本身，而在「主」——一個外於這整個社會結構、卻要審視每一方的更高權柄 |

### 保羅的三重顛覆

把上面的比較收攏成三點，可以看見保羅在借用當時讀者熟悉的文學體裁時，做了三件在同類文獻裡幾乎聞所未聞的事：

1. **把下位者當作道德主體來稱呼**——這不只是修辭上的差異。當保羅直接對妻子、兒女、奴僕本人說「你們要……」，他等於在宣告：這些在羅馬社會裡地位最卑微、最缺乏法律人格保障的群體，在基督的教會裡，是能夠獨立向主負責的信仰主體，不是丈夫、父親、主人的附屬品。
2. **要求上位者承擔真實的責任，甚至被究責**——「不可苦待」「不要惹兒女的氣」「公公平平」，這些命令在一個丈夫、父親、主人的權柄幾乎不受法律限制的社會裡（尤其奴隸制度下，主人對奴僕擁有近乎生殺予奪的權力），格外醒目。保羅沒有廢除當時的社會結構，卻把每一段關係都放進一位共同的主權之下衡量。
3. **把每一組命令的根基，從「社會位階」挪到「在主裡」**——古代家庭守則的權柄根源是自然秩序或城邦習俗；保羅版本的權柄根源，是六次重複、八次出現的「主」字。這個挪移看似只是措辭上的加註，實則從根本上重寫了整段關係的座標系——不再是「因為你地位比較高/低，所以你該如何」，而是「因為你我共同的主看著，所以你該如何」。

### 篇幅分配透露的重點

三組配對中，主僕教導的篇幅（22-25節，4:1）明顯長過婚姻（18-19節）與親子（20-21節）兩組合起來的份量。這個篇幅分配並非偶然——奴僕與主人同席敬拜，是初代教會裡地位落差最懸殊、也最需要被重新界定的一組關係，而歌羅西書3:22-4:1「無論做甚麼，都要從心裡做，像是給主做的，不是給人做的」這一句，正是全段結構上的高潮句，也是與腓利門書所記載的真實個案（阿尼西母與腓利門）直接呼應的一句話（詳見附錄四）。

## 兩段結構的共同精神

把1:15-20與3:18-4:1這兩段文學形式截然不同的經文並排來看，能看見一個貫穿全書的共同結構：**基督頌以「他是」開始、以「萬有」為關鍵詞，宣告基督在創造與教會兩個領域都居首位；家庭守則以六種不同的身分開始、以「主」為關鍵詞，宣告基督在婚姻、親子、主僕三種最日常的關係裡也居首位。**一首詩把基督放在宇宙的正中央，一段倫理教導把同一位基督請進了廚房與職場——兩者用完全不同的文學形式，說著同一件事：祂在凡事上居首位(1:18)，不只是在天上，也在你家裡。

---

## 帶著走的問題

1. 這首基督頌用「他是」的公式，兩次確立基督的身分，才展開祂的作為——你今天思想信仰問題時，通常先問「我該做什麼」，還是像這首詩一樣，先問「祂是誰」?

2. 保羅借用了當時讀者熟悉的家庭守則體裁，卻在關鍵處徹底顛覆——這對你今天「借用世界的形式，卻裝進不一樣的內容」這件事，有什麼提醒?你的生活裡，有沒有一種看似尋常的形式（工作方式、關係模式），其實可以裝進完全不一樣的、以基督為中心的內容?

3. 家庭守則裡，每一位「上位者」都被要求向「天上的主」交帳——如果你手上握有某種權柄（職場上、家裡、教會裡），這個結構對你有什麼具體的提醒?
