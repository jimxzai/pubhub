# 歌羅西書深度領受 —— 按全書結構，老弟兄查經法

> 這一篇不是逐節註解，是把全書當作一個整體來看。
> 先看見骨架，再看見血肉；先看見那位元首，再看見祂身上的肢體。

---

## 全書精義一句話

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 基督是元首——萬有的元首，也是教會的元首；\\ 你們在祂裡面「已經」得了豐盛，不必再加甚麼。}}\end{center}

歌羅西書全部的重量壓在兩個字上：**「已經」**。

假教師說：你信了耶穌，很好，但還要再加一點——加點禁慾（2:21）、加點節期（2:16）、加點天使敬拜（2:18）、加點深奧的智慧（2:8）。保羅的回答不是「那些東西不好」，而是：**「你們在他裡面也得了豐盛」（2:10）——那個動詞是完成式，事情已經成了。**

---

## 卷首：定位與鑰匙

### 這封信為何而寫

保羅沒有去過歌羅西（2:1「並一切沒有與我親自見面的人」）。這間教會是以巴弗建立的（1:7）。以巴弗到羅馬探望被囚的保羅，帶來兩個消息：一個好的——「你們在基督耶穌裡的信心，並向眾聖徒的愛心」（1:4）；一個壞的——有一種新道理正在教會裡蔓延。

**保羅寫這封信，是隔著千里回應一個他沒有親眼見過的危機。**

### 那個危機是甚麼

經文本身沒有給它命名。我們只能從保羅反駁的內容倒推出它的形狀：

| 線索 | 出處 | 指向 |
|--------------------------------|-------------|------------------------------------------|
| 「理學和虛空的妄言」 | 2:8 | 一套自稱高深的思辨體系 |
| 「人間的遺傳和世上的小學」 | 2:8, 20 | 訴諸傳統與基本元素的權威 |
| 飲食、節期、月朔、安息日 | 2:16 | 帶著猶太律法的色彩 |
| 「故意謙虛和敬拜天使」 | 2:18 | 需要中介者才能靠近神 |
| 不可拿、不可嘗、不可摸 | 2:21 | 苦修禁慾 |
| 「不持定元首」 | 2:19 | **問題的核心診斷** |

\textcolor{ScriptureGold}{\textbf{保羅的診斷只有四個字：不持定元首。無論它自稱多高深，凡是把基督從中心挪開一寸的，都是同一個病。}}

### 全書的鑰匙節

> **1:18**　他也是教會全體之首。他是元始，是從死裡首先復生的，使他可以在凡事上居首位。
>
> **2:9-10**　因為神本性一切的豐盛都有形有體地居住在基督裡面，你們在他裡面也得了豐盛。

第一句是**祂是誰**，第二句是**你們有甚麼**。全書就掛在這兩句上。

# 第一部：感謝與代求（1:1-14）——先跪下，再開口

## 精義

**保羅要對付一個嚴重的錯誤，卻先用十四節感謝和禱告。他不是在暖場，他在示範：對付錯誤的第一步，是為錯誤中的人跪下。**

## 內部結構

| 段落 | 內容 | 動作 |
|--------------|----------------------------|------------------------|
| 1:1-2 | 問安 | 認人 |
| 1:3-8 | 感謝 | 數算他們有的 |
| 1:9-12 | 代求 | 求他們還缺的 |
| 1:13-14 | 轉折——遷入愛子的國 | 說明他們憑甚麼有這些 |

## 深度探索

### 一、信、望、愛出現在第一段

1:4-5：「因聽見你們在基督耶穌裡的**信心**，並向眾聖徒的**愛心**，是為那給你們存在天上的**盼望**。」

留意保羅怎麼排：信心和愛心，是**因為**天上的盼望。**盼望不是三樣裡最弱的一樣，它是另外兩樣的地基。**一個對將來沒有把握的人，今天的信和愛都撐不久。

### 二、禱告的內容不是處境，是認識

1:9「求神……使你們在一切屬靈的智慧悟性上，滿心知道神的旨意」。

保羅知道歌羅西教會正被假道理搖動，他求的不是「求神把假教師趕走」，是**求他們認識得更深**。\textcolor{ScriptureGold}{\textbf{對付黑暗的方法不是罵黑暗，是開燈。}}

### 三、四個分詞——認識之後長甚麼樣

1:10-12 在原文是四個分詞，掛在「行事為人對得起主」底下：

| 分詞 | 中文 | 面向 |
|--------------|------------------------|------------------------|
| καρποφοροῦντες | 結果子 | 向外 |
| αὐξανόμενοι | 漸漸多知道神 | 向上 |
| δυναμούμενοι | 力上加力 | 向內 |
| εὐχαριστοῦντες | 感謝父 | 向後（回頭看恩典） |

### 四、「遷到」是帝國的動作

1:13 的 μεθίστημι，是古代帝國把整批人口從一地遷往另一地所用的字。

**這不是你搬家，是有人把你遷走了。**主詞從頭到尾是神。

## 帶著走的問題

1. 我為那個讓我最生氣的人禱告時，求的是甚麼？是「改變他」，還是「叫他認識」？
2. 1:12「感謝父，叫我們能與眾聖徒在光明中同得基業」——我今天憑甚麼站在光裡？

# 第二部：基督的超越（1:15-23）——全書的心臟

## 精義

**這一段若成立，假教訓就沒有立足之地；這一段若不成立，後面三章全是空話。保羅不逐條駁斥，他把基督舉起來，讓所有東西在祂面前顯出自己的尺寸。**

## 內部結構

1:15-20 是一首詩，兩節（strophe）對稱：

| | 第一節 (15-17) | 第二節 (18-20) |
|--------------|----------------------------|----------------------------------|
| 身分 | 是那不能看見之神的像 | 是教會全體之首 |
| 首位 | 是首生的，在一切被造的以先 | 是從死裡首先復生的 |
| 範圍 | 萬有都是靠他造的 | 藉著他叫萬有與自己和好 |
| 目的 | 萬有也靠他而立 | 使他可以在凡事上居首位 |

\textcolor{ScriptureGold}{\textbf{左欄是創造，右欄是新創造。同一位基督，在兩個世界裡都居首位。}}

## 深度探索

### 一、「首生的」不是被造的第一個

πρωτότοκος（1:15）在舊約希臘文譯本裡，用來指**地位**而非時序。詩篇 89:27：「我也要立他為長子，為世上最高的君王。」大衛不是耶西的長子（撒上 16:11），神卻立他為「長子」。

而 1:16 緊接著給出理由：「**因為**萬有都是靠他造的」——祂若是被造的，就不能是造萬有的那一位。

### 二、詩的正中央

三十六個希臘字之後，是詩的正中心：

> **1:17**　他在萬有之先；萬有也靠他而立。

συνέστηκεν（靠他而立）是完成式：**萬物此刻仍靠祂維繫著。**不是造完就撒手，是每一秒都在托住。

### 三、和好的範圍與方法

1:20：「既然藉著他在十字架上所流的血成就了和平，便藉著他叫萬有——無論是地上的、天上的——都與自己和好了。」

範圍極大（萬有），方法極小極具體（十字架上的血）。\textcolor{ScriptureGold}{\textbf{宇宙性的和好，是在一根木頭上做成的。}}

### 四、1:21-23 把宇宙拉到你身上

詩唱完，保羅立刻說：「你們**從前**與神隔絕……**但如今**他藉著基督的肉身受死，叫你們與自己和好。」

**從前——但如今——只要**（1:23「只要你們在所信的道上恆心」）。第三個詞是給讀者的：這不是給你看的風景，是要你站住的地方。

## 帶著走的問題

1. 我信的基督，是「幫助我的一位」，還是「托住萬有的那一位」？這兩種信法會活出不同的日子嗎？
2. 1:22 說要把我「引到自己面前」——聖潔、沒有瑕疵、無可責備。這是將來的事，還是神此刻看我的眼光？

# 第三部：奧祕的執事（1:24-2:5）——為看不見的人流汗

## 精義

**保羅為一群他沒見過的人「盡心竭力」。奧祕已經揭曉了，但揭曉之後有人要付代價把它送出去。**

## 內部結構

| 段落 | 內容 |
|--------------|------------------------------------------|
| 1:24-25 | 為教會受苦，作教會的執事 |
| 1:26-27 | 奧祕的內容：基督在你們心裡 |
| 1:28-29 | 傳的目標：把各人完完全全地引到神面前 |
| 2:1-5 | 為沒見過面的人爭戰 |

## 深度探索

### 一、奧祕不是難懂，是曾經隱藏

μυστήριον 在保羅筆下從來不指「玄妙難解」，而指「原先藏著、如今揭曉了」。1:26：「這道理就是歷世歷代所隱藏的奧祕，但如今向他的聖徒顯明了。」

而 1:27 直接給出答案：**「這奧祕就是基督在你們心裡成了有榮耀的盼望。」**

假教師賣的是「更高的知識」。保羅說：真正的奧祕早就公開了，而且已經在你們裡面。

### 二、「補滿基督患難的缺欠」怎麼講

1:24 是全書最難的一節。要看清兩件事：

**第一，用字。**保羅用 θλῖψις（患難、壓力），**不是** πάθημα（贖罪之苦）。新約從不用 θλῖψις 指基督的贖罪受苦。

**第二，全書的一致性。**1:20 說十字架已經成就了和平，2:14 說字據已經釘在十字架上——保羅不可能在四節之後說贖罪還沒完成。

因此這裡講的是：**基督的身體在世上仍要受的那份苦，還沒有受完；保羅在其中領了一份。**

### 三、傳道的三個動作與一個目標

1:28：「我們傳揚他，**勸戒**各人，用諸般的智慧**教導**各人，要把各人在基督裡**完完全全地引到神面前**。」

三次「各人」（πάντα ἄνθρωπον）。假教師分等級——有初階的，有進階的。**保羅說沒有等級，每一個人都要被完完全全地帶到神面前。**

### 四、2:1 的「盡心竭力」是競技場用語

ἀγών（爭戰）是運動場上的搏鬥。保羅在監獄裡，動不了，卻在為老底嘉和歌羅西「搏鬥」——用禱告。

4:12 說以巴弗也在做同一件事，用同一個字。\textcolor{ScriptureGold}{\textbf{禱告是使徒與一個小城傳道人共同的競技場。}}

## 帶著走的問題

1. 我有沒有為一個我從未見過的人，認真禱告過？
2. 1:28 說「把各人完完全全地引到神面前」——我身邊有沒有一個人，是我正在往那裡帶的？

# 第四部：豐盛與假教訓的對決（2:6-23）——已經，不必再加

## 精義

**假教訓的公式永遠是「基督 + 某某」。保羅的回答不是攻擊那個「某某」，是指出加號本身就是問題——祂裡面已經是全部了，全部之外沒有東西可加。**

## 內部結構

| 段落 | 內容 | 語氣 |
|--------------|----------------------------|------------------------|
| 2:6-7 | 正面：怎樣接受，就怎樣行 | 立根基 |
| 2:8 | 警告：謹慎，恐怕有人擄去 | 拉警報 |
| 2:9-15 | 論據：你們已經得了豐盛 | 給彈藥 |
| 2:16-19 | 應用一：影兒與實體 | 打節期律法 |
| 2:20-23 | 應用二：禁慾的無效 | 打苦修主義 |

## 深度探索

### 一、2:9 是全新約最重的一節基督論

> 「因為神本性一切的豐盛都有形有體地居住在基督裡面。」

四個限定詞疊在一起：
- **神本性**（θεότης，神格本身，不是「神性的屬性」）
- **一切的**
- **豐盛**（πλήρωμα）
- **有形有體地**（σωματικῶς，指道成肉身的實體）

**保羅把能加的限定詞全加上去了，就是要堵死一切「基督只有部分神性」的說法。**

### 二、緊接著的那半節才是重點

2:10：「**你們在他裡面也得了豐盛。**」

πεπληρωμένοι 是**完成式被動分詞**——已經被充滿了，而且狀態持續。

\textcolor{ScriptureGold}{\textbf{豐盛在祂裡面（9），你們在祂裡面（10）——所以豐盛在你們裡面。這是一個三段論，不是一句安慰話。}}

### 三、十字架的三個動作

2:14-15 用三個動詞描寫十字架做成的事：

| 動詞 | 中文 | 對象 |
|--------------|------------------------|------------------------------|
| ἐξαλείφω | 塗抹 | 律法上有礙於我們的字據 |
| προσηλόω | 釘在十字架上 | 那張字據 |
| θριαμβεύω | 誇勝、示眾 | 執政的、掌權的 |

θριαμβεύω 是羅馬凱旋式的用字——得勝的將軍押著俘虜遊街。**保羅說：十字架看起來是基督被示眾，其實是祂押著仇敵示眾。**

### 四、影兒與實體

2:17：「這些原是後事的影兒；那形體卻是基督。」

σῶμα（形體、身體）與 σκιά（影兒）相對。影子證明有實體，但沒有人抱著影子取暖。

**舊約的節期不是壞的——它們是影子，而影子的價值就在於指向那個實體。實體來了還抱著影子，才是問題。**

### 五、禁慾為甚麼無效

2:23 是保羅最冷的一句評語：「這些規條使人徒有智慧之名，用私意崇拜，自表謙卑，苦待己身，其實在克制肉體的情慾上是毫無功效。」

**因為禁慾管的是「不可拿、不可嘗、不可摸」（21）——全是外面。而問題在心（3:5「貪婪就與拜偶像一樣」）。**

## 帶著走的問題

1. 我心裡的「基督 + ______」，那個空格填的是甚麼？
2. 我有沒有一種屬靈操練，做起來很辛苦、看起來很像樣，卻從來沒有碰到我真正的問題？

# 第五部：新生命的實際（3:1-4:1）——教義走進家門

## 精義

**「你們若真與基督一同復活」——這個「若」不是懷疑，是推論。既然是真的，那麼：思念上面的事，脫去這些，穿上那些，一路穿到夫妻、父子、主僕之間。**

## 內部結構

| 段落 | 內容 |
|--------------|------------------------------------------|
| 3:1-4 | 根據：與基督一同復活、一同藏在神裡面 |
| 3:5-11 | 脫去：五樣加五樣，並「不分」的新人類 |
| 3:12-17 | 穿上：五件衣服 + 愛心的帶子 + 三樣管理 |
| 3:18-4:1 | 家規：三組關係，六條命令 |

## 深度探索

### 一、「思念上面的事」不是逃避

3:2 的 φρονέω 不是「偶爾想一想」，是「以此為心思的取向」——腓立比書 2:5「你們當以基督耶穌的心為心」同一個字。

**這不是叫你不管地上的事，是叫你從上面的角度管地上的事。**證據就在後面：緊接著講的是脫去淫亂、貪婪，講夫妻父子主僕——全是地上最實際的事。

### 二、脫與穿是同一個動作的兩面

3:9-10：「已經脫去舊人和舊人的行為，穿上了新人。」兩個都是**不定過去式分詞**——已經發生的事實。

然後 3:5「治死」、3:12「穿上」是**命令式**。

\textcolor{ScriptureGold}{\textbf{事實在前，命令在後。神先把你換了，才叫你活得像換過的人——不是你活得像了，祂才換你。}}

### 三、五件衣服的次序

3:12：憐憫、恩慈、謙虛、溫柔、忍耐。

**前二是心腸（對人的感覺），中間一是對自己的估量，後二是受壓時的反應。**次序是從裡往外：心裡先軟，才可能在被得罪的時候還忍得住。

### 四、愛心是「帶子」

3:14：「在這一切之上要存著愛心，愛心就是聯絡全德的。」

σύνδεσμος 是「捆綁的帶子」——2:19 用同一個字講身體的「筋節」。**愛不是第六件衣服，是把前五件束在一起的那條腰帶。**

### 五、家規的雙向性

3:18-4:1 三組關係，**每一組都有兩條命令**：

| 對象 | 命令 |
|--------------|----------------------------------|
| 妻子／丈夫 | 順服／愛，不可苦待 |
| 兒女／父親 | 聽從／不要惹氣 |
| 僕人／主人 | 從心裡做／公公平平 |

而 4:1 收在一句話上：「因為知道你們**也有一位主**在天上。」

\textcolor{ScriptureGold}{\textbf{凡是只引用一半家規的人，都在用聖經替自己撐腰。}}

## 帶著走的問題

1. 3:3 說「你們的生命與基督一同藏在神裡面」。如果我的生命是藏著的，我為甚麼還這麼在意別人怎麼看我？
2. 家規三組六條，寫著我名字的是哪一條？我這週有沒有花更多力氣去監督別人那一條？

# 第六部：禱告、使命與問安（4:2-18）——落在名字上

## 精義

**一封講「萬有都是靠他造的」的信，最後一個畫面是一隻戴著鐐銬的手，寫下十個人的名字。**

## 內部結構

| 段落 | 內容 |
|--------------|------------------------------------------|
| 4:2-4 | 向上：恆切禱告，求開傳道的門 |
| 4:5-6 | 向外：與外人的智慧與言語 |
| 4:7-9 | 送信的人：推基古與阿尼西母 |
| 4:10-14 | 問安的人：六個名字 |
| 4:15-17 | 交代：傳閱書信，提醒亞基布 |
| 4:18 | 親筆：記念我的捆鎖 |

## 深度探索

### 一、被鎖的人求的是甚麼

4:3：「求神給我們開傳道的門……（我為此被捆鎖）。」

**他不求開牢門，求開傳道的門。**他把自己的處境和神的工作分開了。腓立比書 1:12 說得更明白：「我所遭遇的事更是叫福音興旺。」

### 二、鹽的兩面

4:6：「你們的言語要常常帶著和氣（χάρις，恩典），好像用鹽調和。」

| 只有恩典沒有鹽 | 只有鹽沒有恩典 |
|--------------------------------|----------------------------------|
| 話很好聽，沒有內容 | 話很有力，傷人 |
| 誰都不得罪，誰也沒被幫到 | 立場鮮明，沒有人聽得進去 |

而舊約的鹽是**立約的記號**（利 2:13；民 18:19）——不變質、不失信。所以「用鹽調和的話」不只是有趣的話，是**可靠的話**。

### 三、名單裡藏著兩段故事

**馬可**（4:10）：徒 15:37-39 保羅曾因他中途離開而拒絕再帶他。如今保羅說「你們就接待他」；提後 4:11 更說「他在傳道的事上於我有益處」。

**底馬**（4:14）：此刻與路加並列問安。提後 4:10：「底馬貪愛現今的世界，就離棄我。」

\textcolor{ScriptureGold}{\textbf{同一份名單裡，有人從失敗中被恢復，有人從忠心中滑落。名單是一個時間點的截圖，不是最終判決。}}

### 四、以巴弗的禱告是全書的縮影

4:12 求三件事，正好是全書的三條線：

| 以巴弗求的 | 全書呼應 |
|--------------------------------|----------------------------------|
| 在神一切的旨意上得以完全 | 1:9 |
| 信心充足（πληροφορέω） | 2:2、2:10 |
| 能站立得穩 | 1:23 |

**一個小城的傳道人，在禱告裡把整封信求了一遍。**

# 跨書貫通

## 一、與以弗所書——同一批貨的兩張清單

兩封信同時寫、同一人（推基古）送達（西 4:7；弗 6:21），內容重疊超過三分之一，但重心不同：

| | 歌羅西書 | 以弗所書 |
|--------------|----------------------------|----------------------------------|
| 焦點 | **元首**——基督是誰 | **身體**——教會是甚麼 |
| 寫作動因 | 對付具體的假教訓 | 沒有具體危機，正面陳述 |
| 語氣 | 緊、辯、快 | 寬、頌、慢 |
| 家規 | 3:18-4:1（簡） | 5:22-6:9（詳，加婚姻的奧祕） |

\textcolor{ScriptureGold}{\textbf{歌羅西書從頭往身體看，以弗所書從身體往頭看。兩封信合起來，才是完整的一個人。}}

## 二、與腓利門書——同一趟旅程的兩封信

阿尼西母出現在西 4:9，是腓利門逃跑的奴僕。腓利門住在歌羅西，就坐在收信的會眾裡。

所以西 3:22-4:1 那段最長的奴僕／主人教導，**是當著腓利門的面說的**。保羅沒有在腓利門書裡命令他釋放阿尼西母；他在歌羅西書裡對全教會說「你們作主人的，要公公平平的待僕人」，然後在腓利門書裡請他把阿尼西母當作「親愛的兄弟」（門 16）。

**福音沒有一夜之間廢掉奴隸制度，它做了更徹底的事——它把主人和奴僕放進同一個家，叫他們彼此稱兄弟。制度撐不住這種關係，遲早要垮。**

## 三、與約翰福音——道與元首

| 約翰福音 | 歌羅西書 |
|--------------------------------|----------------------------------|
| 太初有道，道與神同在（1:1） | 是那不能看見之神的像（1:15） |
| 萬物是藉著他造的（1:3） | 萬有都是靠他造的（1:16） |
| 道成了肉身（1:14） | 豐盛有形有體地居住在他裡面（2:9） |
| 從他豐滿的恩典裡，我們都領受了（1:16） | 你們在他裡面也得了豐盛（2:10） |

\textcolor{ScriptureGold}{\textbf{約翰用「道」，保羅用「元首」——同一位基督，兩個入口。}}

## 四、與啟示錄——元首要顯現

西 3:4：「基督是我們的生命，他顯現的時候，你們也要與他一同顯現在榮耀裡。」

歌羅西書的「藏」，在啟示錄裡揭開：

| 歌羅西書 | 啟示錄 |
|--------------------------------|----------------------------------|
| 生命與基督一同藏在神裡面（3:3） | 他們要見他的面（22:4） |
| 他顯現的時候（3:4） | 看哪，他駕雲降臨（1:7） |
| 在凡事上居首位（1:18） | 萬王之王，萬主之主（19:16） |
| 萬有與自己和好（1:20） | 我將一切都更新了（21:5） |

# 生命操練

## 六個層次

| 層次 | 從歌羅西書學甚麼 |
|--------------|------------------------------------------|
| 一、看見祂是誰 | 1:15-20 讀到能背——不是背經文，是背那個次序 |
| 二、認出加號 | 找出你心裡「基督 + ______」的那個空格 |
| 三、認定已經 | 2:10「已經得了豐盛」——不必再賺 |
| 四、換取向 | 3:2 思念上面的事——從上面的角度處理地上的事 |
| 五、換衣服 | 3:12-14 五件衣服 + 一條帶子，一件一件穿 |
| 六、落在名字上 | 4:7-18 數出你的名單，為每一個具體禱告 |

## 按結構的讀經計劃（六週）

| 週次 | 讀 | 一句話追問 |
|--------------|--------------------|------------------------------------------|
| 第一週 | 1:1-14 | 我為那個讓我為難的人，求的是甚麼？ |
| 第二週 | 1:15-23 | 我信的基督，尺寸有多大？ |
| 第三週 | 1:24-2:5 | 我有沒有為看不見的人付過代價？ |
| 第四週 | 2:6-23 | 我的加號填的是甚麼？ |
| 第五週 | 3:1-4:1 | 寫著我名字的是哪一條？ |
| 第六週 | 4:2-18 | 我的名單上有誰？ |

**每週的讀法**：週一到週三讀經文本身，一天讀完整段（不必求快求多）；週四對照本書相應章節；週五挑一件事去做；週六安靜；主日回頭看這一週。

# 全書的句號：你看見耶穌了嗎？

歌羅西書把基督放在六個位置上：

| 位置 | 經文 |
|--------------------------------|-------------|
| 神的像——你看見祂就看見神 | 1:15 |
| 創造的中心——萬有靠祂造、靠祂立 | 1:16-17 |
| 教會的元首——身體只有一個頭 | 1:18 |
| 和好的成就者——在十字架上流血 | 1:20 |
| 豐盛的居所——神格全部住在祂裡面 | 2:9 |
| 你的生命——不是你的幫助，是你的生命 | 3:4 |

最後一項是全書真正的落點。3:4 說的不是「基督幫助我們的生命」，是**「基督是我們的生命」**。

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 若把基督從你的日子裡抽掉，還剩下多少是照舊運轉的？\\ 那個「照舊運轉」的部分，就是你還沒有交給元首的地方。}}\end{center}

## 附：本卷貫穿的幾句話

> **關於加號**：假教訓從不說「不要基督」，它說「基督，還有……」。加號才是敵人。

> **關於已經**：全書的重量壓在「已經」兩個字上。你不是要去得著豐盛，你是要認出你已經在裡面。

> **關於家規**：神給你的功課，永遠是寫著你名字的那一條。

> **關於名單**：你的領受若不能落在名字上，它還在空中。

> **關於元首**：2:19 說得病的人是「不持定元首」。凡是把基督從中心挪開一寸的，無論它自稱多高深，都是同一個病。
