# 卷末：隱與顯，是同一位主 (Hidden and Revealed — the Same Lord)

> 二十七個故事講完了。
> 最後一個問題還是那一個：你看見耶穌是誰？

---

## 老弟兄精義一句話

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 比喻藏起來的，和顯明出來的，是同一位主。\\ 分別不在故事，在聽的人。}}\end{center}

## 一、二十七個故事，一個講故事的人

把全書的比喻按耶穌在其中的身分排一次，會看見一張臉：

| 比喻 | 耶穌是誰 |
|--------------------------------|------------------------------------------|
| 撒種 | 那撒種的 |
| 稗子 | 撒好種的人子（太 13:37） |
| 藏寶與尋珠 | 那變賣一切買下田地的買主 |
| 迷羊 | 那撇下九十九隻去找一隻的牧人 |
| 浪子 | ——那位跑出去迎接的父親所指向的心腸 |
| 好撒瑪利亞人 | 那位看見就動了慈心、包裹傷處的 |
| 大筵席 | 那預備筵席、差僕人去請的主人 |
| 兇惡的園戶 | 那位「他還有一位是他的愛子」的兒子（可 12:6） |
| 十童女 | 那位半夜來到的新郎 |
| 按才幹受託 | 那位要回來算帳的主人 |
| 綿羊與山羊 | 坐在榮耀寶座上的王 |
| 兩種根基 | 那位說「聽見我這話就去行的」的主 |

\textcolor{ScriptureGold}{\textbf{撒種的、牧人、買主、父親、新郎、主人、王——七個身分，一位基督。這就是為甚麼每一章最後都問同一個問題。}}

## 二、約翰福音把謎底寫了出來

符類福音用比喻把答案包起來，約翰福音把包裝拆掉。

| 比喻裡藏著的 | 約翰福音直接說的 |
|--------------------------------|------------------------------------------|
| 撒種、種子自長 | 「一粒麥子不落在地裡死了……」（約 12:24） |
| 迷羊、好牧人的心腸 | 「我是好牧人」（約 10:11） |
| 大筵席、生命的供應 | 「我就是生命的糧」（約 6:35） |
| 葡萄園、園戶 | 「我是真葡萄樹」（約 15:1） |
| 兩種根基、生與死 | 「復活在我，生命也在我」（約 11:25） |
| 門、進入天國 | 「我就是門」（約 10:9） |
| 燈與光、隱與顯 | 「我是世界的光」（約 8:12） |

**約翰福音一個比喻也沒有——因為在那裡，講比喻的人自己成了謎底。**

## 四、為甚麼最後一個比喻是「兩種根基」

登山寶訓講完了，耶穌沒有給結論，祂講了一個比喻：兩個人蓋房子，一個蓋在磐石上，一個蓋在沙土上。

留意祂怎麼分這兩種人：

> **太 7:24, 26**　所以，凡**聽見我這話就去行的**，好比一個聰明人，把房子蓋在磐石上……凡**聽見我這話不去行的**，好比一個無知的人，把房子蓋在沙土上。

**不是「聽見又明白的」，不是「聽見又感動的」——是「聽見又去行的」。**

而兩座房子在風雨來以前，看起來一模一樣。地基是藏著的。

\textcolor{ScriptureGold}{\textbf{這正是全書骨幹的最後一次出現：現在藏著，將來顯明。而「將來」有時就在下一場風雨。}}

## 讓話語住在裡面

**默想**：
二十七個比喻裡，哪一個讀起來最不舒服？

**老弟兄的說法是：那通常就是為你講的那一個。**回去把它再讀一遍，這一次不要問「這是甚麼意思」，問「我是裡面的哪一個人」。

**實踐**：
挑那個比喻裡的一個動作——撒瑪利亞人的包裹、父親的跑出去、管家的機警、聰明人的挖深——這一週做一次。

**太 7:24 說的是「聽見我這話就去行的」。行動比理解更接近那塊磐石。**

## 你看見耶穌了嗎？

拿單對大衛講了一個比喻，講一隻母羊羔。大衛聽了大怒，說「行這事的人該死」。

拿單說了四個字：

> **撒下 12:7**（和合本）你就是那人！

\begin{center}\textcolor{ScriptureGold}{\textbf{\large 比喻的力量就在這裡——\\ 它讓你先做出判斷，再發現你判的是自己。}}\end{center}

而在每一個比喻的盡頭，站著同一位主：那撒種的、那牧人、那買主、那父親、那新郎、那主人、那王。

**阿們。主啊，開我的耳朵，也開我的心。**
