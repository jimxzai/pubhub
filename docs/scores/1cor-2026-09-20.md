## 本輪具體改動

### 1. 分卷扉頁補骨幹標記（`scripts/build-1cor-consolidated.sh`）

五個正文 `add_volume` 描述句尾各加一句「（全書骨幹·十字架的道理·第N步）」（第一步～第五步，對應
卷一～卷五），文字直接取自 `00b-cross-spine.md` 既有的「五卷，五類問題，同一把尺」表格，非新造論點。
未使用 `printf %b`（本卷 `add_volume()` 用 `%s`，新句子不含字面 `\n` 逃脫序列，故未觸發
judges/job/acts 三次踩過的 `%s`→`%b` 坑；已確認）。

### 2. 逐章補「全書座標」行（`ch01.md` – `ch16.md`）

每章「基督焦點」小節原本都有一行「**全書骨幹**：……」＋「（全書骨幹見卷首《十字架——全書的骨幹》）」，
內容已經很扣連骨幹，只是缺 `check-book-spine.py` 認得的關鍵詞「座標」。本輪把標籤從「**全書骨幹**」
改成「**全書座標**」，並在句首加一句「卷N「主題」（章範圍）第M章——」，句子本身的論述文字**逐字保留**，
只換了標籤與前綴。16 章全部同一手法，未改動任何經文或引文區塊。

### 3. 驗證（全部本輪重跑）

`lint-templates.sh 1cor`（乾淨）、`lint-chapter-markup.py`（errors=0）、`lint-scripture-text.py`
（15 條既有候選，未新增）、`check-citation-ledger.py`（帳目相符）、`normalize-commentary-notice.py
--dry-run`（0 需更新，本卷未使用該通知體例）、`driver.sh 1cor`（251→253頁，0缺字/0錯誤/0溢出，
字型全內嵌，baseline 已更新）、分卷扉頁與正文首頁各一張 `pdftoppm` 渲染肉眼核對。

   內部運作正常，但 `check-book-spine.py --all`（不帶明確路徑）會因此**永遠靜默跳過本卷**，本輪是
   手動複製判定邏輯才跑出結果。這是本卷特有、其他書都沒有的工具盲點，下一輪建議把 16 個章節檔改名
   （連帶更新 `build-1cor-consolidated.sh` 的 `add_file "$INPUT_DIR/ch$i.md"` 迴圈），讓

   file rename 牽動 build script 與可能其他隱藏引用，風險高於「手動跑一次判定邏輯」帶來的收益。

   的精簡度或重複率，這方面仍是 08-31 輪的水準，未經本輪重新檢視。
