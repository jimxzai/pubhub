# 以弗所書研讀 — 評分表 (2026-09-14：/proofread 通讀輪)

接續 `ephesians-2026-09-13b-succinct-and-proofread.md`（9.42分）之後的第三輪：三支獨立
校對代理分段通讀全書，專找「機器數字/引文核對」之外的一類缺陷——中文行文品質、段落
邏輯、體例一致性、Markdown格式。163頁，頁數不變（本輪為文字訂正，非結構調整）。

## 這一輪抓到的真缺陷

**最重要的一項——建置腳本本身的bug**：`scripts/build-ephesians-consolidated.sh`處理
`elder-wong-systematic-study.md`時誤用`tail -n +2`（僅跳過檔案第1行），但該檔案實際帶有
7行YAML前言（`---`/title/subtitle/author/date/publisher/`---`）。結果是**YAML中繼資料以
純文字形式，逐字印進了PDF正文**（「title: 全書領受總綱——以弗所書」等六行原樣可見）。
此缺陷不會被任何既有lint腳本發現——因為lint檢查的是原始檔案本身（其YAML本來就合法），
不是combined markdown或PDF成品；這正是本項目一貫的教訓「檢查器讀的是素材不是成品」的
又一例。已訂正為`tail -n +8`並重建確認PDF正文不再出現YAML文字。

**經文地址錯誤**：06章「基督不只是這禱告的中保（**3:14**「藉著他的靈」...）」——核對
本章自己的經文區塊，「藉著他的靈」實際出現在**3:16**，非3:14（3:14原文只有「我在父面前
屈膝」）。已訂正。

**簡體字與異體字**：01章「聖靈是神**应**許的」（簡體殘留，應作「應」）；02章、05章各一處
「奧**祕**」異體字混入作者自撰文字（全書體例以「奧秘」為準，僅CUV經文引句本身用「奧祕」）。
08章「保**羗**」應作「保羅」（人名錯字）；「7-70譯本」應作「七十士譯本」（Septuagint的
訛誤）。均已訂正。

**全書用詞不統一**：09章三處用「身分」指涉「地位先於行為」這條全書主線，與00b、08、11、
跋等處統一使用的「地位」不一致，讀者跨章追蹤這條主線時容易誤讀為兩個不同概念。已統一
改為「地位」。

**標題與內容不符**：01章小標題「三個問安對象，三重身分」實際只討論了收信人的兩種稱呼
加上寄信人身分（並非三個對象），已改為「兩個稱呼，加上寄信人的身分」。

**括號符號不統一**：10章「〈你的行為·行〉」誤用檔名專用的角括號指稱段落標籤，與08、09
兩章的「」不一致，已統一。

**前言自相矛盾**：000-preface.md「與約翰福音、路加福音等卷不同，本卷**同樣**沒有……」——
「不同」與「同樣」在同一句直接矛盾，屬編輯殘留贅字，已刪去「同樣」。

## 查核後判定為非缺陷、維持原樣的項目

- **麥克阿瑟講道日期「1996年2月」（10章，sermon 1946）**：三支代理之一懷疑此日期有誤
  （該系列其餘講道多在1978-79年），但**直接重新fetch gty.org原始頁面核實**，1944-1947
  四篇（God's Pattern for Wives/Husbands系列）確實均標示1996年（很可能是1996年重播或
  補錄），與1951號的1979年並存於同一套講道系列——此為來源本身的真實記載，非訛誤，維持原樣。
- **「教父與改革宗一節」的體例說明措辭**：本書並無獨立的「改革宗」注疏來源，一位代理認為
  此措辭失實。但核對後確認這是本項目跨書卷共用的標準體例用語（約伯記等其他書卷同樣沿用
  此措辭，即便沒有獨立「改革宗」小節），屬既定房規慣用語，非本書獨有問題，未予更動。
- 其餘引文出處格式的細微差異（Homily節數標點「4:1,2」vs「4:1-2」、講道日期精細度到月或到
  日、教會名稱是否重複列出）——均為格式一致性的軟性建議，不影響引文可查證性，本輪未逐一
  處理，留待日後統一體例時一併調整。
