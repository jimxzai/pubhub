## 起點

目錄開始時是空的。本輪建出：27 個研讀單元（耶利米書 52 章 1,364 節）、六卷、卷首 6 檔（前言、總覽、位置、骨幹、啟示的次序、領受總綱）、卷末〈通往啟示錄〉、兩份由程式生成的附錄、跋；27 首聖詩；腳本 `inject_scripture.py`、`gen-jeremiah-appendices.py`、`build-jeremiah-consolidated.sh`；來源資料（和合本三來源、NASB 1995、Sefaria 希伯來文、亨利、加爾文、摩根概論、70 份教父段落、45 份麥克阿瑟講章／文章）。

做法：作者（我）寫範例章 1，並寫規格 `sources/SPEC.md`；13 位代理各寫兩章（2–27）；作者另寫卷首卷末與腳本。

## 骨幹

全書依「神的話與留意」的次序：話先於人（1）→先呼喚、後審判（2–6）→代求被關上，眼淚沒有關（7–20）→審判藉巴比倫，盼望種在審判裏（21–33）→話語勝過刀與火；審判者亦受審；燈未熄滅（34–52）。
可核對的主線：希伯來文 שׁקד 作動詞 5 次、4 節（1:12；5:6；31:28 兩次；44:27）；1:10 的六個動詞在 12:14-17、18:7-10、24:6、31:28、31:40、42:10、45:4 回來；אֲהָהּ אֲדֹנָי יֱהֹוִה 四次（1:6；4:10；14:13；32:17）；「新約」一詞全書只在 31:31。

每位代理分 3 章（另一位分卷首與分卷頁），被告知不信任既有報告、向原始來源重新取證。作者側全綠的檢查（`verify-prose-citations` 0 MISS 等）之後，仍找出：

| 類型 | 例 |
|---|---|
| 把注疏者的話說偏或說反（最多） | 亨利論 7:10、摩根導語、加爾文論 51:20「鎚子」、加爾文論 34:17 說成取其一、麥克阿瑟 42-20、賈斯丁一段把兩位都寫成讀拉瑪為便雅憫境內 |
| 推論超過經文 | 「亡國前四十年」、21–24 章都算西底家、「神先流淚」（8:21 是先知說、9:1 說話者不定）、40:2 的對象寫成被擄的人、基大利「不知道」（40:14 有警告） |
| 引句失真（檢查器看不見的版式） | 44:27、太 16:13、申 15:15 等；`verify-prose-citations` 對部分章回報 0 條可檢，代理改用自寫腳本 |
| 計數錯誤 | מאן 11→12、שֶׁקֶר 九→十、בנו/ונטעו 八→九節、בְּרִית 24→23、「認識我」六→七節、約拿達四件→四不可加一要 |
| 直接／間接混淆 | 來 8:10 引的是 31:33 不是 24:7；路 1:37 對創 18:14；「同一詞組」其實字序相反 |
| 來源資料缺陷 | NASB 來源檔 15 處 `L ORD`、12:1 多一個分號（已修來源與書稿）；聖詩 7 的 OCR 錯字 |
