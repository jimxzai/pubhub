## 第二輪：獨立校對（2026-10-02，9.0 → 9.3）

一位不信任既有核對紀錄的校對代理通讀 00b 與第 1-3 章（其餘兩個代理在本環境 stall，第 4-9 章與卷首卷末由主編依同一清單向原始來源重新取證通讀）。**嚴重：0。** 抓出並已修正的缺陷（中 17、輕 13），全部是機器檢查看不見的類別：

| 類別 | 例 |
|------|----|
| 數字對不上自己的列舉 | 00b「一共四個動作」列了五個；「三次動詞和一次名詞」算成五次（實為四動詞一名詞） |
| 注疏的「或許」被寫成定論 | 普盧默只說低米丟「或許」送信，書稿寫「兩人都認為很可能」；韋斯科特「似乎」是正式聚會 |
| 兩位注疏家被合併成一個說法 | 「普盧默與韋斯科特都認為這個加重的『你』對比丟特腓」——兩人指的不是同一個字，且都有保留 |
| 讀反注疏 | 普盧默說英譯 "prates against us" 難以改進，書稿誤成「拉丁通俗譯本難以譯得更好」 |
| 經文意思說錯 | 啟 22:4「他的名字必寫在他們的額上」是**神的名**，書稿誤讀為信徒的名字被叫出、且稱「得勝的人」；啟示錄並非以 22:4 作結；太 10:42 是「因為門徒的名」不是「為主的名」 |
| 文法與事實 | v8「應該」不是命令式（v11 才是），「全信唯一的命令式」錯；συνεργός 除屬格外也接 εἰς（西 4:11、林後 8:23）；希臘文「口對口」不能「用同一個希伯來片語」；該猶「至少四位」與同段注疏自相矛盾；創 3 皮衣在逐出之前 |
| 無出處的史實 | 「昂貴又名聲不好的客棧」無來源，已刪；改述麥克阿瑟有出處的說法 |
