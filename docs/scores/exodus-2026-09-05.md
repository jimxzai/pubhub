## 本輪最重要的發現：MacArthur引句全數機器覆核，摩根／亨利抓出一處真正杜撰

**背景**：出埃及記卷完稿時，`verify-sermon-quotes.py` 因舊式編號辨識缺口，40條MacArthur引句中僅5條可機器核對。本輪先修正腳本的編號辨識（新增對「編號」「#」「sermon code」等寫法的支援），使**全書45條MacArthur引句達成100%機器覆核**，結果：

```
verified: 45   missing from own transcript: 0   unresolved: 0
```

過程中抓出並修正3處真正的逐字漂移（如「This is magic」應為「It's magic」、遺漏欽定本引文中的「Wherefore」一字、口誤更正「Verse 18, 33.」未標刪節號），詳見 `99-appendix-references.md` 第八節。

摩根與亨利兩家因缺乏單一本地全文可供機器比對，改採人工逐條網路查證，核對21條引句時，**抓出一處真正的杜撰**：第39章一條標示為馬太·亨利逐字語錄的內容（「The tabernacle was a type or emblem of Jesus Christ...」）經廣泛查證（biblehub.com 與 biblestudytools.com 之簡明版／全本，涵蓋第25、26、28、38、39、40章相關頁面）**查無實據**，已依本書一貫的誠實原則改為不加引號的方法性轉述。同一過程也發現並更正一處出處卷冊誤植（第8章「CCEL, mhc2.Exod」——mhc2實為約書亞記至以斯帖記，非出埃及記）。

**這印證了本系列一貫的教訓**：引文查證不能只憑「讀起來像原作者的語氣」就採信——第39章那條被杜撰的引句，文字風格、神學內容都與亨利真實的寫作習慣高度吻合，若非逐字上網核對，幾乎不會被發現。
