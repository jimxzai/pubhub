# 敬拜與禱告手冊 · 牧者審閱表

**用途**：本書的經文（和合本、NASB 1995）與聖詩歌詞都由來源讀出並做過機器核對；**下面這些是編者寫的**，沒有神學審閱。審閱一輪約一小時。
**怎麼用**：每項選一個：通過／修改（在意見欄寫新句）／刪除。審閱人與日期填在最後。把填好的表交回，由編者改入 `build_book.py` 並重建。
