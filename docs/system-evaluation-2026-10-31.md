# 系統評估與升級計劃 · System Evaluation & Upgrade Plan

**Date**: 2026-10-31
**Scope**: 聖經研讀書庫全系統，對照 `docs/study-notes/PRD-gospel-of-john.md` v4.0 的使用者故事（Epic A–F）
**Scale**: 1–10；10 = 該使用者能從頭到尾完成這件事，不需要作者介入，而且結果可信
**Evaluator**: Claude Code（AI 評估；未經人工覆核。依過去紀錄，AI 自評平均偏高 0.5–1 分）

> **更正（同日稍後）**：初版寫「讀者拿不到書」，是錯的。66 卷研讀書已於 2026-10-31 上線 ai-eden.com `/resources`（ai-eden commit `729f36fa`），須登入；PDF 本身公開可下載。下表 C 項與總分已更正。讀者端（網站、讀經器、社群）的整體評估在 ai-eden repo 的 `Docs/system-evaluation-2026-10-31.md`（5.9/10）。

| 面向 | 權重 | 分數 | 一句話 |

## 5. 缺口與 bug 清單 (Gaps & bugs, by severity)

### 🔴 壞掉的
1. `scripts/daily-template.js`、`weekly-summary.js`、`monthly-report.js` 用 `require`，在 `"type": "module"` 下崩潰 → `pnpm new-note`、週報、月報、兩個 GitHub Action 全壞。
2. `package.json` 的 `stats` 指令指向不存在的 `scripts/stats.js`。
3. `.github/workflows/*` 用 Node 18/20；Actions 警告 Node 20 已棄用。

### ⚠️ 需要確認的
4. `app/storage/page.tsx` + `lib/firebase-client.ts`：未登入即可列出、上傳、刪除。Firebase API key 本身可公開，但若 Storage 規則允許匿名寫入，任何人都能刪檔。

### 🟡 內容缺口
5. 撒母耳記上下：撒下 25 個檔案、骨幹 0/4、無建置基準；撒上骨幹 3/4、22 溢出。
6. 骨幹 1/4：彼得前書、彼得後書、希伯來書、以賽亞書、`1philimon`。骨幹 3/4：哥林多後書、馬可、詩篇、羅馬書。
7. 保羅書信 `pauline-epistles/` 巢狀目錄（歌羅西、提摩太前後、提多）骨幹檢查器讀不到。
8. 溢出：genesis 138、ephesians 64、judges 48、ezekiel 32、exodus 24、1-samuel 22、proverb 8、joel 4、pastoral-epistles 4。
9. ~~未提交：malachi、zechariah、西番雅書 sources~~ 已於 `0d1c5e25` 提交；`baselines.tsv` 仍待確認。
10. 已建卷但未做獨立校對的書（依記憶檔）：傳道書、約珥書等，需在總表中逐卷確認。

### 🟡 系統缺口
11. 無書庫總表；無 `check-all`；無發佈管道；無手機閱讀；無帶領者版本；無審核流程。
12. 104 支 build script、106 個模板 → 同一類 bug 重複出現。
13. Setext 標題陷阱（段落後無空行的 `---`）尚未寫進 lint。
14. 目錄命名錯字與大小寫不一（見 §3）。
15. `CLAUDE.md`、`.claude/CONTENT_RULES.md`、`README.md`（簡體、舊架構）與現況不符。

### 關於「10 分」

10 分的意思是讀者、帶領者、審核者都不需要作者介入就能完成他們的事，而且結果經得起人檢查。這需要真的讀者與真的牧者參與，AI 自評不能證明。Phase 0–5 完成後，可信的目標是 **9.0–9.5**，其餘要看人工審核與讀者回饋的結果。
