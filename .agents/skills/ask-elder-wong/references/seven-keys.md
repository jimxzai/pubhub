# 七個查考方向：從經文看見基督

由原 skill 的七把鑰匙整理而來，是查考方向，不是七種必套的答案。
先讀本段的文體、人物、處境與上下文，再看全經連結。下列經文地址是核對入口，
不是本檔已完成逐字引文或全部原文研究的聲明。

## 先分清三個層次

- **經文明示：** 經文本身或新約作者明確作出的引用、連結、解釋。
- **整本聖經的連結：** 有上下文支持的主題延伸，應說清楚如何連接。
- **我們的領受：** 由此而來的默想與應用，不當作唯一原意或新啟示。

## 七個方向

1. **預備與成就。** 查明預表的文本根據；例如約翰福音 3:14 明確連到銅蛇，
   哥林多前書 10:4 明確連到磐石。不是每個器物、數字或人物細節都能自行配對。
2. **詩篇與基督。** 先辨說話者與詩歌處境，再查新約如何引用該篇。
   可從基督的完全與信徒在祂裡面的回應默想；不要因此刪去詩篇原有勸勉，
   也不把「整篇只指祂、不關乎讀者」當成所有詩篇的固定答案。
3. **在主裡認識愛。** 可把主的愛作默想的焦點，同時保留哥林多前書 13 章
   對教會生活的上下文。把主的名字代入作默想，不代表可以更改經文主語或引文。
4. **約翰福音的「我是」。** 區分通常歸納的七組帶比喻宣告，與全卷所有
   「我是」用語。前者不是後者的總出現次數；與出埃及記的連結須按各段說明。
5. **兆頭指向誰。** 觀察約翰如何把所行的事連到主的身分與人的回應，參看
   約翰福音 20:30–31 的寫作目的。先尊重事件本身，再作生命應用；不要用
   屬靈意義取消拉撒路故事中的實際死亡、哀傷與復活。
6. **律法與救恩。** 按加拉太書 3 等具體段落查考律法的功用，不將所有
   誡命縮成「反正做不到」。同時看恩典如何帶來新的生命與順服。
7. **摩西五經與福音書。** 回到新約提及的舊約處境，觀察引用、回應或主題
   延續；不要把現代曆法、字音相似、或吸引人的聯想當作預表的文本證據。

## 寫出連結的理由

用短句說明：本段看到什麼 → 哪處經文回應它 → 我們因此怎樣認識主。
若只有意象相似，稱為默想的聯想，不用「經文證明／必然應驗」拔高。
無法找到可靠連結時，可以停在本段如何預備、塑造或勸勉神的子民；不必硬接啟示錄。

原 skill 的馬太—王、馬可—僕人、路加—完全人、約翰—神子，可作導讀角度，
不是每卷唯一主題。獅子／牛／人／鷹的對應若要提及，須說明是某種傳統讀法，
不可說成經文自己逐卷指定。Matthew、John、Luke 各自的重點應由實際稿件與經文支持。

## 三個檢查問題

這個看見從哪一句、哪個轉折而來？
我們是否分清原意、全經連結與今日回應？
讀者能否從這個連結更認識主，而不是只記住一個新奇說法？
