# 主題查考的領受脈絡

由原 Claude skill 的框架材料重新整理，用來形成查考問題，不替老弟兄建立或
命名一套學說。這些是既有編輯材料中的讀經角度；若要稱為他本人的領受，
仍須追查原記錄。涉及不同讀法時，說清楚本文採用的理解與經文依據。

## 救恩與生命的長進

可從稱義、成聖、得榮來查考神已作的、正在生命中作的，以及將來的盼望。
這些名稱本身可以使用，用清楚語言解釋，不必堆疊術語。
不要把整理表誤作每段經文都使用的同一套時間表，也不要暗示靠表現賺取救恩。

可問：這段強調主已經成就什麼？又如何呼召我們今天回應？
分清經文明說與我們的整理，避免用一句「最大的敵人只有自己」取消其他經文所說的爭戰。

## 靈、魂、體的查考

先讀具體經文，再討論詞語的用法；人的構成有不同理解，不能因一個整理圖就
宣稱所有經文都在教導相同的三分模型。舊材料中的器官比喻可作說明，須註明是比喻，
不是生理結構或可以量測的屬靈診斷。

可問：這個選擇如何回應經文的引導？有沒有把自己的喜好當作神的心意？
不要假裝能從一句話判定某人的決定出於靈、魂、邪靈或疾病。
亞當夏娃犯罪前「身披可見榮光」等推想，若文本未明說，就不能當成經文事實教導。

## 塔與壇：生活方向的對照

可以用高舉自己的名與敬拜神，幫助讀者省察追求的方向；查考時仍回到相應故事。
「塔／壇」是整理意象，不是可以涵蓋全部歷史的唯一解碼方式。
提到巴別與啟示錄巴比倫的連結時，交代經文與推理，不隨意套到當代群體或個人。

可問：這個計劃把誰放在中心？我們如何忠實履行已交託的責任？
交託不等於放棄判斷、承擔或尋求協助，也不是保證每個計劃一定成功。

## 信靠與主權

引導人信靠主、把日常主權交託給祂，並用具體行動回應。
不要把信心寫成操控結果的方法，不把困難、失業、病痛或困惑直接當成不信的證據。
沒有核實出處的舊語錄不加引號歸給老弟兄；可按經文重新整理為我們的默想。

## 保留開放查考的位置

先說明這段經文支持什麼，再說哪些仍是我們有限的領受。
讀者提出異議時一起回到文本，不以「你沒有亮光」壓制核對與討論。
謙卑不是含糊：有把握的經文觀察清楚說，推論和不確定處也清楚標出。
