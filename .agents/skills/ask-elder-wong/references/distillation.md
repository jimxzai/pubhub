# 濃縮精義與全卷主線

保留原 skill 的提煉方法，但把有力的結論建立在可追查的經文觀察上。
精義句是本次查考的濃縮，除非有逐字來源，不署作老弟兄的金句。

## 先看全段，再找一句

1. 快讀全段／全卷，確認誰對誰說、正在處理什麼問題。
2. 找自然轉折、重複詞、主句、人物回應與起訖呼應。
3. 有明示的寫作目的就從它出發；沒有則標明「編者歸納」，不替作者虛造目的句。
4. 分辨中心與次要細節，形成一句能由上下文支持的領受。
5. 回讀整段檢驗：是否漏掉反例、轉折、未解的張力？必要時用兩句，不追求口號。

可以用動作、意象或問題濃縮，但不讓好記超過準確。
不要把「耶穌三次問彼得是否愛祂」改寫為「三次都問同一個比較句」；
引用每次具體措辭須核對約翰福音 21:15–17。
「每次沒有築壇就失敗」等全稱斷言要逐處檢驗；若只是觀察到一條線索，
就按線索表達，不用「每次／全部／只有」加強氣勢。

## 詞頻不能數錯對象

數經文用詞，須先確定書卷範圍、譯本、底本與計數方式。
不能在含注疏、標題、重複引文的整個書稿上數「信」字，再說那是聖經原文的詞頻。
中文單字數不等於詞數，譯文字數不等於希臘文詞形／詞元數。
無法實數就用「反覆出現」，不拿「約／將近」掩飾沒有根據的數字。

## 主線要推進，而不是重複

全卷主線回答：這卷帶我們從哪裡走到哪裡？每一部／每章怎樣推進？
導讀提供方向；分卷扉頁承接前後；章首座標定位；章末以當章內容回應主。
這些位置功能不同，不是把同一句領受複製四次。

沿用原有章序與書稿結構。研究單元號若不同於聖經章號，另列經文範圍，
不要把可變長的經文區間塞進 H1 造成混亂。需要重組時先做一章示範再決定擴展。
刪重保留獨有的經文連結、詩歌、出處、問題與應用；不用縮短百分比衡量深度。

## 六個動作，按需要選用

**讀**：把上下文讀清楚。**找**：觀察詞句和結構。**問**：讓問題帶著查考前進。
**連**：核對全經連結。**住**：留時間默想。**行**：在今天的處境中具體回應。
這是帶領節奏，不是六個每次都要出現的章節。

## 精義句的品質

好的精義具體到本段：讀者能指出支持它的句子，也能看出它與別章不同。
不寫成沒有根據的絕對斷言、不代替逐字經文、不假借老弟兄或神的權威。
一個真實的看見，比三個漂亮卻重複的抽象詞更好。
